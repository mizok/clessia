# 學生

**路徑**: `/teacher/students`
**角色**: Teacher

## 核心目的

查看自己任課班級的學生名單。

## MVP 功能

### 學生列表

- 依開課班分組顯示學生
- 每位學生顯示：姓名、年級
- **A6 版（#1314，2026-10-14）**：橘面數字句「N 個班，共 M 位學生。」（M 數**不重複**的學生，跨班只算一次；N 不含未分班；都不隨搜尋／篩選變）→ 灰帶工具列（搜尋姓名、班級下拉）→ 依班分章：左欄班名＋「N 人」（桌機 sticky），右側姓名（桌機 4 欄網格、年級在姓名下；手機單欄列、年級靠右）。篩選中另有一行「找到 N 位（不重複）＋清除篩選」。
- **載入**：列表 API 單頁上限 100，前端依 `meta.total` 一頁一頁拿到底（剛好 100 筆一次、101 筆兩次）；任何一頁失敗整體失敗，不拿半份名單配完整數字句。
- **稿有、本版沒做**：點名字開學生資訊面板（家長電話、最近到班、成績；稿標新、要 API）、章名下的上課時段與「最近的班排前面」（列表 API 沒給班的時段；要的話後端加欄位，作法同 #1452）。
