# 考試管理

**路徑**: `/teacher/assessments`（**尚未實作** —— 見下方現況）
**角色**: Teacher

> **2026-08-30 校對。** 這一頁的功能範圍經使用者裁決保留：**老師可以自己建考試**，
> 不是只能登錄成績。但原版寫的權限模型與現況有兩處落差，都記在下方。

## 核心目的

建立考試事件、輸入成績。

## 現況（2026-08-30）

- **頁面不存在** —— 老師端目前只有 dashboard / schedule / students / notifications 四頁
- **後端尚未開放給老師** —— `academy-exams` / `school-exams` / `scores` 三支 API 掛在
  `ADMIN_ONLY`，而且**三支裡沒有任何 teacher-scope 程式碼**。把 mount 改成
  `['admin','teacher']` 是不安全的：那會讓任何老師讀寫全校的考試與成績

## 老師的範圍（2026-08-30 裁決）

| 動作           | 範圍                             |
| -------------- | -------------------------------- |
| 建立考試       | 只能建**自己固定任課**的班的考試 |
| 編輯／刪除考試 | 只能動自己任課班的考試           |
| 登錄成績       | 只能登錄自己任課班的學生         |

「自己任課」取 `schedules.teacher_id`（**固定任課，不含代課**），與聯絡簿／教務日誌
共用 `lib/teacher-scope.ts` 的同一套規則。範圍限制**放在伺服器且不看請求怎麼說** ——
前端隱藏不構成授權（c1）。

## MVP 功能

### 分頁設計

- **待處理分頁**（預設）：只顯示尚未完成成績登錄的考試
- **全部分頁**：顯示所有考試，可篩選課程、日期範圍

### 考試列表

- 每筆顯示：考試名稱、課程、日期、完成狀態、進度（例如「8/10 已登錄」）
- 待處理的考試卡片右側顯示暖銅橘小圓點（●）
- 點擊開啟「成績輸入 Popup」

### 完成狀態邏輯

- **自動完成**：所有學生都已輸入分數或標記缺考
- **手動完成**：老師可點擊「標記完成」強制完成
- 已完成的考試仍可編輯成績

### 建立考試流程

1. 點擊「新增考試」按鈕
2. 輸入考試名稱
3. 選擇課程歸屬
4. 選擇課堂關聯（可選，從自己的課堂中選）
5. 若無課堂關聯，輸入考試日期
6. 設定滿分（預設 100）和及格分數（預設 60）
7. 選擇參加範圍（樹狀結構多選開課班，僅顯示自己任課的班）
8. 儲存

### 成績輸入 Popup

- **Popup 標題**：考試名稱 + 日期
- **學生名單表格**：
  - 欄位：學生姓名、開課班、分數輸入框、狀態下拉（正常/缺考/補考）
  - 未輸入分數的學生行底色稍淡
- **操作按鈕**：
  - 「加入其他學生」
  - 「全部標記缺考」
  - 「下載範本」
  - 「匯入成績」
  - 「儲存」
  - 「儲存並關閉」
  - 「標記完成」

### 成績匯入功能

支援 CSV 和 Excel（.xlsx）格式

**匯入流程**：

1. 點擊「下載範本」
2. 範本內容：學生 ID、學生姓名、開課班、分數、狀態
3. 填寫分數欄位
4. 點擊「匯入成績」上傳
5. 系統預覽匹配結果
6. 確認後匯入
