## 畫面區塊

`學校管理` + 副標「管理學生就讀的學校清單，供學生資料填寫時選用」。

（#728 之前這裡是一條麵包屑，見「已知的落差」。）

### 刪除的兩條路

| 條件               | 行為                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `studentCount > 0` | **不開對話框**，只出 warn toast：`無法刪除` /「此學校仍有 N 位學生」（實測）                                           |
| `studentCount = 0` | `confirmationService.confirm()` 的原生 `p-confirmDialog`，訊息「確定刪除「X」？」（**未驗** —— 本機沒有 0 學生的學校） |

> ⚠️ **這一頁的確認框不是共用那一支。** 它用 PrimeNG 的 `ConfirmationService` +
> 模板裡的 `<p-confirmDialog />`，**不是** [[specs/sitemap/_shared/confirm-dialog]]。
> 樣式與按鈕文字都不同一套。
