## 畫面區塊

### 1. 頁首

`營收報表` + 一句 `錢進來多少、還有多少沒收到。`

### 2. 篩選列

日期區間（`readonlyInput`，預設**這個月 1 號到今天**，實測顯示 `2026-09-01 - 2026-09-12`）、
分校下拉、課程下拉（**可搜尋**，`filterBy="label"`）、（有篩選時）「清除篩選」。

- 分校下拉：`全部分校` + **只列 `isActive` 的分校**（實測 12 個）
- 課程下拉：`全部課程` + 全部課程

### 3. 開帳流向帶（橘色）

`這段期間開帳` + 一個大數字，底下一條比例條與三個圖例：

| 圖例     | 意義                                     |
| -------- | ---------------------------------------- |
| 已收回   | `billed − outstanding`                   |
| 應收未收 | `outstanding`                            |
| 其中逾期 | `overdueOutstanding`（疊在應收未收裡面） |

> **這條帶子刻意只用 `billed` / `outstanding` 這一組。** 元件註解說明：
> `received` 看收款日、`billed` 看開帳日，**是不同的集合**，
> 拿 `received / billed` 當收款率是在比不同母體。

### 4. 現金註腳（一行 info）

`這段期間實收 N、退款 M（單獨列，未從實收扣除）。收款看收款日，與上面的開帳區間是不同的集合。`

> **退款不從實收扣除**是刻意的：「收了 100 萬、退了 3.6 萬」與「收了 96.4 萬」
> 是兩個不同的經營訊號。

### 5. 分組統計

標題 `分組統計` + 右側三選一（`分校` / `課程` / `月份`，`allowEmpty=false`）。

表格六欄，**第一欄的標題就是分組方式本身**（分校／課程／月份）：

`<分組>`、`實收`、`退款`、`已開帳`、`應收未收`、`其中逾期`

- 第一欄**不可摺疊**（`appRtColDefCollapsible=false`）—— 註解：窄螢幕上它 minWidth 最大
  會被優先丟掉，結果是一張沒有標籤的數字表
- 第一欄在 `billed > 0` 的列多一條小比例條（`aria-hidden`，純視覺）
- `其中逾期` > 0 的列套 `reports__amount--overdue`
- 月份分組的 key 會被格式化成 `2026 年 9 月`
- **模糊桶**：`（跨分校）` / `（跨課程）` / `（未分類）` 三個 key 會多一顆 info icon，
  tooltip 說明「跨多個分校/課程的帳單不做比例拆分也不重複計入，所以自成一組…這樣小計加起來才等於總計」

資料來源：`GET /api/reports/revenue?dateFrom=&dateTo=&groupBy=`（+ `campusId` / `courseId`）。
**整頁一支請求**，總計與分組一起回。
