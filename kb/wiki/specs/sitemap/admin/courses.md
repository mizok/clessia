## 畫面區塊

### 1. 頁首列

`課程管理` + 副標「層級管理課程與班級，設定上課時間」，右側「操作紀錄」與「新增課程」。

### 2. 待辦橫幅（條件式）

橘底一條：`需介入 N 個課程`，右側箭頭。**只在有需介入的課程時出現。**

### 3. 分校頁籤

`全部` + 每個啟用分校一個頁籤（實測 11 個），裝不下時右側出現 `Next` 捲動鈕。

### 4. 篩選列

全選勾選框、`搜尋課程或班級...`、`篩選` 按鈕。

### 5. 課程分組清單

一個課程一組（`course-group__header`，整列可展開／收合）：
課程名、`分校 · 科目`、`N 個班`、`新增班`、鉛筆（編輯）、垃圾桶（刪除）。

展開後底下是班級列（`class-row`）：勾選框、班級名、`前往班級詳情`、`⋮`，
以及**條件式**的完整度提示（例如 `無未來排程`）。

### 6. 分頁器

`<< < 1 2 3 4 5 > >>`，每頁 20 個課程。

### 動手前先做的反向動作對照 —— 它改變了工作量

**FK 決定了拆解順序**（`information_schema` 查的）：

| 外鍵 | ON DELETE |
| --- | --- |

| `schedules.class_id → classes` | **CASCADE** |
| `academy_exam_classes.class_id` / `class_logs.class_id` | CASCADE |
| `enrollments.class_id → classes` | **RESTRICT** |

### 加入學生是**三步**，不是兩步

`選擇學生` → `確認加入`（+ 可能的衝突閘）→ **`加入結果`**（`已加入 1 人／完成／為這 1 筆開帳`）。
