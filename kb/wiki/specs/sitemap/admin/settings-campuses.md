## 畫面區塊

### 1. 頁首

`分校管理` + 副標「管理您的補習班分校資訊」。右側「操作紀錄」與主要行動「新增分校」。

> 這個 h1 與殼的 h1「系統設定」**同時存在**（殼不會因為子頁有標題就收掉自己的）。

### 2. 工具列

### 3. 統計列（三格）

`N 個分校`、`N 啟用中`、`N 已停用`。**只在非載入中且有資料時出現。**

### 4. 表格

`分校名稱`（含建築 icon）、`地址`、`電話`、`狀態`、每列 ⋮。

- 地址／電話沒填時顯示 `未填寫`
- **電話是 `tel:` 連結**（有填才是連結）
- 狀態 `啟用` / `停用`（`app-status-dot`）
- 有分頁（`pagination()`），本機 12 筆未觸發

### 每列 ⋮ 的動作選單

`PopupMenuComponent`（`.popup-menu__panel`），項目之間有分隔線。

| 該列狀態    | 選單項目                                                             |
| ----------- | -------------------------------------------------------------------- |
| `isActive`  | `編輯`、**`停用分校`**、`刪除分校`（實測）                           |
| `!isActive` | `編輯`、**`啟用分校`**、`刪除分校`（**未驗** —— 本機沒有停用的分校） |

三個確認都走 [[specs/sitemap/_shared/confirm-dialog]]：

| 動作     | 標頭       | 內文                                                    | 主鍵（severity）  |
| -------- | ---------- | ------------------------------------------------------- | ----------------- |
| 停用分校 | `停用分校` | 確定要停用「X」嗎？停用後該分校將無法新增課程。（實測） | `停用`（warn）    |
| 啟用分校 | （未驗）   | 確定要啟用「X」嗎？（讀原始碼）                         | `啟用`（success） |
| 刪除分校 | `確認刪除` | 確定要刪除「X」嗎？此操作無法復原。（實測）             | `刪除`（danger）  |

## 子頁面：分校表單

**開啟方式**：「新增分校」，或列 ⋮ ›「編輯」

- 標題 `新增分校` / `編輯分校`（自畫的 inline 標頭 + ✕）
- 欄位：`分校名稱*`（placeholder `例如：台北分校`）、`電話`（`02-12345678`）、`地址`（`完整收件地址`）

- **`[disabled]`**：主鍵在 `分校名稱` 空白時 disabled（實測：新增時「建立」是 disabled）；
  另外四個控制項在 `loading()` 時全部 disabled（**未驗** —— 要真的送出才看得到）

## 已知的落差（記錄現況，不在這裡修）

**統計列的三個數字不是同一個範圍，於是它們加不起來。**

隱藏停用分校時（預設）畫面同時印著：

```
12 個分校     12 啟用中     1 已停用
```

**12 ≠ 12 + 1。** 按下「顯示停用分校」之後第一個數字變成 13，另外兩個不動。

成因（`routes/campuses.ts:177-195`）：`activeCount` / `inactiveCount` 來自一支
**刻意不套 `isActive` 篩選**的 summary 查詢（那一行的註解寫著「summary 不套用
isActive filter，永遠反映全機構的真實總數」），而同一個物件裡的 `total`
用的是**主清單查詢的 `count`**，那一支**有**套篩選。
`buildCampusSummary(rows, total)` 把兩個範圍拼在一起。

**這個落差一直都在，只是本機從來沒有停用分校，所以三個數字剛好一致。**
→ **已開 issue #751**（未順手修）。
