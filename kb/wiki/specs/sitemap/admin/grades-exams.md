## 畫面區塊

### 1. 頁首

`考試管理` + 副標「管理補習班考試與學校考試，統一查看狀態、進入成績登錄」，右側「新增考試」。

### 2. 待辦橫幅（條件式，兩條）

- `有 N 場 進行中的補習班考試一筆成績都還沒登錄`
- `有 N 場補習班考試登到一半`

**兩條都是按鈕**，而且**都只講補習班考試** —— 學校考試沒有對應的橫幅。

資料來源：`GET /api/academy-exams/todo-count`、`GET /api/school-exams/todo-count`

### 3. 篩選列

- 期間 toggle：`近1月` / `近3月` / `近半年` / `全部`
- 型態 toggle：`補習班考試` / `學校考試`
- 三個下拉：`全部分校` / `全部科目` / `全部狀態`
- 搜尋框：`搜尋考試名稱...`

### 4. 考試清單

一場考試一列。實測欄位（補習班考試）：
`考試名` · `類別（小考…）` · `分校` · `科目` · `型態` · `日期` · `已登錄/總人數` · `狀態`。

學校考試那一列的形狀不同：`段考 · 第二次` · `學校考試` · `日期` · `學校名 · 全科目` · `N 筆` · `狀態`。

實測到的狀態：`進行中`、`已結束`。

資料來源：`GET /api/academy-exams?page=1&pageSize=20`（型態 toggle 切換時換端點）

### 每場考試 ⋮ 的動作選單

`PopupMenuComponent`（`.popup-menu__panel`）。**四項，第三項隨狀態改變**：

| 項目         | 出現條件        | 按了之後                                                                  |
| ------------ | --------------- | ------------------------------------------------------------------------- |
| 進入成績登錄 | 永遠            | 導向 [[specs/sitemap/admin/grades-exams-type-id-scores]]                  |
| 編輯基本資料 | 永遠            | **未驗**                                                                  |
| **結束考試** | 狀態 = `進行中` | **未驗**（會寫入）                                                        |
| **重新開啟** | 狀態 = `已結束` | **未驗**（會寫入）                                                        |
| 刪除         | 永遠            | 開確認對話框（**未驗**，推測是 [[specs/sitemap/_shared/confirm-dialog]]） |

**選單只隨狀態變，不隨考試型態變** —— 三個樣本：
補習班/進行中、補習班/已結束、**學校/進行中**（學校那一場的選單與補習班/進行中逐字相同）。
