## 已知的落差（記錄現況，不在這裡修）

**停課的課堂在今日課表上顯示為「未點名」，而且被算進「還沒點名」的數字。**

`GET /api/workbench/today` 實測回：

```
15:00 國小五年級英文班  eventId=NULL  takenAt=no  status=cancelled
17:00 國三國文 A 班     eventId=yes   takenAt=no  status=scheduled
```

畫面上兩列都顯示「未點名」，大標寫「今天 2 堂課，其中 2 堂還沒點名」，現況「今日課堂 2」。

模板的狀態點是 `session.takenAt ? '已點名' : '未點名'`，**沒有停課的分支**。而那一列同時是不可按的
（`canTakeAttendance` 為 false），所以它是一件「畫面說你還沒做、但你點不下去也永遠做不了」的事。

→ 已開 issue 給計畫席（見驗證紀錄）。**這一頁的地圖記的是現況，不是應該的樣子。**
