## 畫面區塊

**一頁兩個實體**：價目表（org 層定價）與收費期間（機構自訂的具名日期區間）。
兩區塊**各自取數、各自失敗** —— 一邊掛掉不會讓另一邊空白。

### 1. 頁首

`費用方案管理` + 副標「定義收費標準供報名時挑選。這裡只給定價，實際談定的金額寫在每筆報名上。」
右側「操作紀錄」按鈕。

### 2. 價目表區塊

- 區塊標題 `價目表` + 說明「停用的方案不會出現在報名選單，但歷史報名仍看得懂它。」
- 右側「新增價目表」
- 工具列：搜尋框（`搜尋方案名稱...`）+ 一顆 filter chip（顯示／隱藏停用方案）
- 表格四欄 + 一欄動作：`方案名稱`、`計費模式`、`定價`、`狀態`、每列 ⋮
  - 計費模式的顯示字串來自 `BILLING_MODE_LABELS`（實測到 `月繳` / `期繳` / `堂數制`）
  - 狀態是 `app-status-dot`：`啟用中`（done）／`已停用`（inactive）
  - 停用列的方案名稱多一個 `fee-templates__name--inactive` 樣式

資料來源：`GET /api/fee-templates`，帶 `search`（有輸入才帶）與
`isActive=true`（**沒按「顯示停用方案」時才帶**）。**沒有分頁** —— 這個實體是十幾筆的量級。

> 搜尋是 debounce 300ms + 全部取數走同一條 `switchMap`（#661），所以打字快慢都不會有
> 後發先至蓋掉畫面的問題。

### 3. 收費期間區塊

- 區塊標題 `收費期間` + 說明「期繳用的具名日期區間。期間之間可以重疊 —— 新舊制交接時本來就會。」
- 右側「新增期間」（outlined）
- 表格兩欄 + 一欄動作：`期間名稱`、`起訖日期`（`YYYY-MM-DD — YYYY-MM-DD`）、每列 ⋮

資料來源：`GET /api/billing-periods`。**沒有分頁、沒有搜尋。**

### 每列 ⋮ 的動作選單

兩張表用的都是專案自己的 `PopupMenuComponent`（`cdk-overlay-pane.popup-menu__panel`），
**不是 PrimeNG 選單** —— 選擇器見 [[specs/sitemap/README|方法頁]]。

| 表       | 該列狀態    | 選單項目                                                     |
| -------- | ----------- | ------------------------------------------------------------ |
| 價目表   | `isActive`  | `編輯`、**`停用`**、`刪除`（實測）                           |
| 價目表   | `!isActive` | `編輯`、**`啟用`**、`刪除`（**未驗** —— 本機沒有停用的方案） |
| 收費期間 | 永遠        | `編輯`、`刪除`（實測）                                       |

- `編輯` → 開對應的表單對話框（標題變成「編輯…」）
- `停用` / `啟用` → **不開對話框，直接 `PATCH` 寫入** → 本輪未按
- `刪除` → 開 [[specs/sitemap/_shared/confirm-dialog]]（見下）

### 刪除的兩段式確認

1. **第一段（已實測開啟並取消）**：[[specs/sitemap/_shared/confirm-dialog]]，標頭 `確認刪除`，
   內文「確定要刪除「才藝班 10 堂」嗎？此操作無法復原。已經被報名引用過的價目表刪不掉，請改為停用。」，
   按鈕 `取消`（outlined）/ `刪除`（danger）
2. 第二段：後端回 409 `IN_USE` 時**再開一個確認**，標頭 `無法刪除`，
   按鈕 `取消` / `改為停用`（warn）。**只有真的送出刪除才看得到 → 未驗**（讀原始碼）
