## ⚠️ 這一頁有路由守衛，而且是原生對話框

`app.routes.ts` 給這條路由掛了 `canDeactivate`，實作在 `score-entry.component.ts:370-373`：

```ts
canDeactivate(): boolean {
  if (!this.dirty()) return true;
  return window.confirm('有尚未儲存的成績變更，確定要離開嗎？');
}
```

**是 `window.confirm()`，不是應用程式自己的對話框。** 兩個後果：

1. 它長的是**瀏覽器原生的樣子**，不受本專案的樣式與 `_shared` 對話框規範管轄
2. **自動化不能觸發它** —— 原生 modal 會凍住整個瀏覽器擴充，後續指令全部收不到。
   本輪因此**刻意沒有讓它出現**（見驗證紀錄）

**只有 router 導覽會經過它。** 整頁重新載入（改網址列）不會 ——
`beforeunload` 全庫零註冊（`grep -rn beforeunload apps/web/src/app` 無命中），
所以**直接打網址離開，未存的成績會靜靜消失，沒有任何提示**。

## 畫面區塊

### 1. 麵包屑

`考試管理 › 成績登錄`

### 2. 考試資訊卡

- 考試名 + **狀態徽章**（實測 `進行中` / `已結束`）
- 一行麵包屑式描述：`<分校> › <課程> › <班級> · <類別> · <科目> · <日期>`
- 四格統計：`已登錄` / `平均` / `最高` / `最低`（沒有成績時後三格顯示 `—`）

### 3. 成績表格

一位學生一列：`學生`、`年級`、`分數 /100`（數字輸入）、`狀態`（下拉，預設 `正常`）、`備註`（文字輸入）。

**手機版是另一套 DOM**（`academy-score-editor__mo…` 的卡片），桌機寬度下在 DOM 裡但不可見。

### 4. 儲存列

**乾淨狀態下整頁一顆按鈕都沒有。** 模板是：

```
@if (!isClosed() && canSave()) { … <span>儲存成績</span> … }
```

而 `canSave = dirty() && !saving() && !isClosed()`（`score-entry.component.ts:177-179`）。

**所以「儲存成績」只在有未存變更、且考試未結束時存在。**

### ⚠️ 沒有讓 `window.confirm` 出現，這是刻意的

`canDeactivate` 用原生 `window.confirm()`。**原生 modal 會凍住整個瀏覽器擴充**，
之後所有指令都收不到，得由人去瀏覽器手動關掉。所以本輪**沒有製造未存變更後嘗試離開**。

逃生路徑其實是有的（整頁導覽不經過 router guard，且沒有 `beforeunload`），
但既然「儲存成績」本身也沒量到，冒這個險換不到東西。

### 「儲存成績」為什麼沒量到

要讓它出現必須讓頁面進入 `dirty`，而 `dirty` 由子元件的 `dirtyChange` 推上來 ——
**合成的 `input` 事件設不動它**（試過：DOM 的 `value` 變成 88，但沒有任何按鈕出現）。

改用真的點擊 + 鍵盤也沒成功：輸入框**確實可編輯**
（`disabled: false`、`readOnly: false`、`pointer-events: auto`，這是量到的），
但在我的點擊與後續按鍵之間**焦點掉了**（`document.activeElement` 回到 `BODY`）——
這是方法頁坑「探測動作本身會關掉你要看的東西」的一個變形：
**探測用的工具呼叫本身把焦點弄丟了。**

試了三輪就停手（照方法頁「不要鑽洞」）。**條件寫在地圖上是從原始碼讀的，明確標為未驗。**
