## 子頁面：班級考試統計

**開啟方式**：點任何一個班級列。**只有這一頁開得到**（`grep -rl ClassScoresDialogComponent`
只命中 class-view 自己），所以不進 `_shared/`。

- 標頭：班名、年級範圍、`上限 N 人`
- 第一層 toggle：`待登錄` / `全部`
- 考試下拉：選一場考試（實測 `第一次數學小考 (2026-08-26)`）
- 統計區：`平均分數` / `最高分` / `最低分`（實測 67.25 / 91 / 40）
- 第二層 toggle：`全部` / `已登錄` / `缺考` / `補考`
- 結束動作：`關閉`

**唯讀** —— 對話框內沒有寫入動作（要登錄成績走
[[specs/sitemap/admin/grades-exams-type-id-scores]]）。
