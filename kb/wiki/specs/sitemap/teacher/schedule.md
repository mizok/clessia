- 眉標 `教學課務`（來自路由的 group）、大標 `課表`、副標 `2026年8月31日 – 9月6日`

### 2. 週條（`schedule-page__weekbar`）

一列七天，每天一顆按鈕：星期、`M/d`、以及「N 堂」的狀態點或 `—`（沒課）。
左右各一顆上一週／下一週。

> **桌機才顯示**（手機換日靠滑）。**載入中也保留**那兩顆導航鍵（`disabled`）——
> 註解：它們不依賴這週的資料，拿掉會讓骨架寬度跟真正的週條對不上。

### 3. 一日一屏的水平軌道

七個 `section`，每屏一天，靠原生 scroll-snap 換日（**沒有手勢 JS**）。
桌機與手機同構，只是卡片更寬。

每屏標題：`M/d` + 星期 +（有待辦時）一個**聯絡簿未寫的數字**
（`aria-label="N 位學生的聯絡簿還沒寫"`）。

### 4. 課堂卡片

一堂一張，由上而下：

- 時間 `HH:MM–HH:MM`
- 班級名
- 一排 chip：`停課`（`status === 'cancelled'`）、`代課`（`isSubstitute`）、
  `小考`（`examCount > 0`，多場時 `小考 ×N`）、校區名 —— 最後接 `N 人`
- 狀態點（見下）+ **已點名時**多一組 `到 N / 假 N / 缺 N`
- 0～2 顆動作鍵（見下）

資料來源：

| ---------- | --------------------------------------------------------------------------------------- |
| 課堂       | `GET /api/attendance/sessions?dateFrom=&dateTo=&statuses=scheduled,completed,cancelled` |
| 點名設定   | `GET /api/org/settings`                                                                 |

#### 週條的門檻是**容器查詢**，不是視窗斷點

```scss
.schedule-page__weekbar { display: none; }
@container shell-content (min-width: 640px) { .schedule-page__weekbar { display: flex; } }
```

檔案裡的理由：**shell 的側欄在 ≥ 640.02px 吃掉 240px，所以內容區寬 ≠ 視窗寬。**

實測（`main.shell-content` 的 border-box 寬）：

| 視窗 | 側欄  | 容器  | 週條 |
| ---- | ----- | ----- | ---- |
| 639  | `0`   | `639` | 隱藏 |
| 641  | `240` | `401` | 隱藏 |
| 878  | `240` | `638` | 隱藏 |
| 880  | `240` | `640` | **仍然隱藏** |
| 881  | `240` | `641` | **仍然隱藏** |
| 1024 | `240` | `784` | **顯示** |

> **精確臨界沒有收斂，而且知道為什麼**：`@container` 的 `min-width` 比的是
> **content-box**，我量的是 `getBoundingClientRect()` 的 **border-box**，
> 中間差一個 `main` 的左右內距。所以「容器 640 了卻還沒顯示」不是矛盾，
> 是**我量的那個數字回答的是另一個問題**。
> **可以確定的是**：門檻落在視窗 `(881, 1024]` 這一段，而**那正是方法頁說
> 「`(1024, 1280]` 沒人量過」的鄰居** —— 這一頁真正沒被涵蓋的是 `(881, 1024)`。
> 要精確值就去量 `main` 的 content-box，不要再往視窗寬上猜。

> 這一頁在 390 只剩 **3 個**可見元素；會捲動再測的版本量到 **5 個**。
> **這正是方法頁濾網③（捲軸外不等於不存在）要擋的東西，只是換了個軸** ——
> 而濾網③ 的 `scrollIntoView({ block: 'center', inline: 'center' })` 與
> `scroller()`（明文含橫向容器）**已經涵蓋水平**，所以這裡不需要額外的規則，
> 只需要知道**這一頁是水平那一側最尖的實例**。

**390 下可見的 5 個互動元素裡有 4 個低於 44px，而且沒有任何 coarse 規則接住。**

> 值得計畫席看一眼要不要開單。

### 鍵盤可達性

- 全頁**沒有正數 `tabindex`** → Tab 序列 = DOM 序。
- **Tab 序列（390）**：`上一週` → `下一週` → `.schedule-page__track`（軌道本身可聚焦）→ `開始點名` → `寫日誌`。
  **1024 / 1504 多出 7 顆週條鍵與第二組前後週鍵，共 14 個。**
- **軌道本身是 tabbable 的**，而且**這一頁是本輪唯一有自訂 focus 樣式的頁**：
  `.schedule-page__track:focus-visible`（其餘頁面命中的 `:focus` 規則全是 PrimeNG 自己的）。
  **樣式長什麼樣沒量到**（見未驗）。
- **click-only 而鍵盤到不了**：`<main>` 內 **0 筆**（列到的 `span.p-button-*` 都在按鈕裡面）。
