### 補驗了共用頁兩個「未驗」項（而且沒有寫入）

`_shared/announcement-inbox` 留了「一次只能展開一則」與「再按一次收合」兩個未驗，
理由是家長端只有一則公告。老師端有 4 則，**其中 3 則已讀** ——
**展開已讀的那幾則不會產生任何寫入**（未讀才會被標記），所以可以安全地驗：

| 動作                    | 結果                                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------- |
| 展開第 2 則（已讀）     | 內文出現；**未讀徽章仍是 `1 則未讀`、紅點仍是 1 顆** → 沒有寫入 ✓                       |
| 接著展開第 3 則（已讀） | `.announcement-inbox__body` **仍然只有 1 個**，內容換成第 3 則 → **一次只能展開一則** ✓ |
| 對同一則再按一次        | `body` 變 0 個，徽章與紅點不變 → **再按一次是收合** ✓                                   |

發布者那一行也量到了：`—— Demo Admin`。
