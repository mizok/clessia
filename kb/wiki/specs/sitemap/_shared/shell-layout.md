# 外框（ShellLayout）

**元件**：`@shared/components/layout/shell-layout/shell-layout.component`

`/admin/**`、`/teacher/**`、`/parent/**` **全部走這一個外框**（`AGENTS.md` 的角色與授權架構）。
所以它**只寫這一頁**，53 個頁面各自的地圖只寫 `<main>` 裡面的東西。

> **Phase 1 的人請注意**：畫地圖時**不要把左側選單列進頁面的互動元素表** ——
> 那會在 53 份檔案裡複製同一份清單，而它一改就全錯（c11：手抄的清單必然腐化）。
> 頁面地圖只寫 `<main>` 內。

## 畫面區塊

### 1. 頂列

- 左側：`Clessia` 字標
- 右側：角色徽章（`管理員` / `老師` / `家長`）+ 頭像 + 使用者顯示名稱

### 2. 左側選單

第一層是不分組的項目，接著是可展開的群組。**群組數依角色而異**：

| 角色    | 不分組項目       | 群組                                                              |
| ------- | ---------------- | ----------------------------------------------------------------- |
| admin   | 儀表板、通知中心 | 課務管理、學務管理、考務與成績、行政財務、人事管理、系統設定（6） |
| parent  | 儀表板、通知中心 | 學習狀況、行政服務、生活與繳費（3）                               |
| teacher | **未驗**         | 教學課務（1，依 `NavigationGroup`）                               |

選單項目由 `RoutesCatalog` 的 `showInMenu` / `group` / `permission` 決定
（`NavigationService` 會把沒有權限的項目藏起來）。**各路由的值見每一頁地圖的生成區塊。**

## 互動元素

| 元素              | 類型           | 出現條件                                                      | 按了之後         |
| ----------------- | -------------- | ------------------------------------------------------------- | ---------------- |
| 選單項目          | 連結           | `showInMenu === true` 且（若有 `permission`）使用者具備該權限 | 導向該路由       |
| 群組標題          | 按鈕（可展開） | 該群組底下至少有一個可見項目                                  | 展開／收合該群組 |
| 角色徽章          | **未驗**       | —                                                             | —                |
| 頭像 / 使用者名稱 | **未驗**       | —                                                             | —                |

## ⚠️ 收合的群組，它的連結仍然在 DOM 裡

admin 的六個群組在畫面上是收合的（只看得到群組標題），
**但 `read_page` 與 DOM 查詢都會列出底下全部 18 條連結**。

也就是說：**「樹裡有這個連結」不等於「使用者現在看得到它」。**
這是「畫面 ⊆ 地圖」那個方向最容易被灌水的地方 —— 所以頁面地圖不收選單，
而外框這一頁明講這件事。
