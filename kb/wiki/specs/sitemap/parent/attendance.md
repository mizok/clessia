## 子頁面：出勤明細（就地展開）

**開啟方式**：按任何一筆出勤列。**不是對話框也不是浮層** —— 是列底下就地展開的一段
（`.attendance__record-detail`），`aria-expanded` 跟著切換。

**一次只能展開一筆**（`expandedId()` 是單一值）—— **未驗**（本機只有一筆非空紀錄）。

內容三選一：

| 條件                        | 顯示                   |
| --------------------------- | ---------------------- |
| 有 `startTime` 與 `endTime` | `HH:mm:ss － HH:mm:ss` |
| 有 `note`                   | 備註文字               |
| **兩者都沒有**              | `沒有更多資訊`         |

（前兩個不互斥，都有就都顯示。）

**實測**（王柏翰 2026-09-07 那筆）：`aria-expanded` 由 `false` → `true`，
展開內容是 `17:00:00 － 18:30:00`。

### ⚠️ 它是 toggle

`(click)="toggleExpanded(record)"`。按兩次等於沒按 —— 見 [[specs/sitemap/README|方法頁]]坑 1。

## 子頁面：切換孩子

**開啟方式**：按頁首的孩子名字徽章。**是一個下拉面板，不是對話框。**

- 標頭文字：`切換孩子`
- 內容：**目前選中的孩子不在清單裡**，只列其他孩子（實測 3 個孩子時列出 2 個：王柏翰、盧安琪）
- 選一個之後：切換 `childId` 並重新取數（**未驗** —— 未實際選取，避免改變頁面狀態後影響其餘量測）
- 關閉方式：再按一次徽章，或點別處失焦

### 2026-09-12 補驗：換一個有資料的孩子，畫面上多出一個互動元素

**Phase 0 這一頁是用 `林子璿` 量的，而那個孩子在本機的出勤紀錄是 0 筆** ——

| ----------------------- | -------------- | --------------- |
| `<main>` 內可見互動元素 | **4**          | **5**           |

多出來的那個是 `button.attendance__record`
（`2026-09-07 出席 國三數學 A 班 文山旗艦校`，`disabled = false`）。

**這是「空資料讓地圖漏掉元素」的一個實例**，而它的失敗方式是安靜的：
兩向比對的兩邊都看不到那顆按鈕，所以**差異仍然是 0**。
跟 Phase 0 記的 `read_page` 漏報是同一族 —— **比對的兩邊來自同一個看不到它的來源。**

**做法**：畫任何「清單型」頁面之前，先確認手上的資料**能讓每一種列渲染出來**；
