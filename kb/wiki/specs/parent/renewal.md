# 續課資訊

**路徑**: `/parent/renewal`
**角色**: Parent

## 核心目的

預覽即將自動續課的內容，申請異動。

## MVP 功能

### 標題區塊

- 顯示下期適用期間（如「2026 春季」）

### 狀態提示

- 正常狀態：「下期費用將於開學前由補習班開立。」
  > ⚠️ **2026-10-04 改寫（#1121，計畫席裁、使用者可否決）**：原文是「系統將於 [日期] 自動開立繳費單」——
  > 但系統**沒有自動開單**（帳單由行政手動跑 billing-runs），給不出真的日期。
- ~~異動處理中~~：申請異動不在 #1121 範圍（`renewal_requests` 表尚不存在，見 #1100 renewal-change-requests）

### 續課預覽區塊

列出系統預計自動續報的課程，每筆顯示：

- 課程名稱
- 新班級名稱（若有升班，標註「升級」）
- 上課時間
- 預計費用

此處僅供檢視，不可直接勾選或取消

#### 預覽的計算（#1121，API：`GET /api/me/renewal-preview?childId=`）

- **下期** = 機構 `billing_periods` 裡開始日晚於今天的最近一期；沒有 → 顯示「目前沒有即將到來的續課」
- **只列期繳**的在讀報名（月繳每月照開沒有「續」；堂數制不進開單）
- **升班**：原班在下期開始前結束、且有設下一班（`next_class_id`）→ 下期是那個班，標「升級」
- **預計費用**：沿用原班 → 跟期開單同一條（議定價優先、沒有才用報名的範本定價，依下期與報名的生效區間按天比例）；
  升班 → 新班的預設參考價整期（原報名的議定價不一定適用新班），新班沒設 → 顯示「待確認」

### 申請異動 Popup

點擊「申請異動」後開啟：

1. 選擇要異動的課程
2. 選擇異動類型：
   - **轉班**：填寫希望轉入的班級或時段
   - **停課（不續報）**：填寫原因
   - **變更繳費方式**：如改為期繳
3. 填寫備註
4. 確認送出

**送出後**：

- 系統產生「續課異動」任務通知管理員
- 頁面狀態更新為「異動處理中」
- 該生的自動開單流程暫停

### 加選課程連結

- 預覽清單下方顯示：「想加選其他課程？」
- 「瀏覽可加選課程」按鈕 → 導向 `/parent/add-course`

### 無待確認狀態

若目前沒有預定的自動續課：

- 顯示「目前沒有即將到來的續課」
- 顯示下次預計開單日期
