# 分校設定

**路徑**: `/admin/settings/campuses`（系統設定的「分校」分頁）
**角色**: Admin
**分組**: 系統設定

## 核心目的

管理分校資訊與教室。

## MVP 功能

### 分校列表

- 每筆顯示：分校名稱（停用加小字）＋地址｜電話＋出勤模式｜教室數（「N 間教室」／「還沒有教室」）｜⋮
- ⋮：編輯／教室／停用（或啟用）分校／刪除分校

### 新增/編輯分校 Popup

| 欄位         | 類型     | 必填 | 說明                                                                              |
| ------------ | -------- | ---- | --------------------------------------------------------------------------------- |
| 分校名稱     | 文字     | 是   | 例如：台北校、台中校                                                              |
| 地址         | 文字     | 否   |                                                                                   |
| 聯絡電話     | 文字     | 否   |                                                                                   |
| 狀態         | 單選     | 是   | 啟用/停用（新增預設啟用）                                                         |
| 出勤紀錄模式 | 下拉     | 否   | 沿用機構預設／日到班／隨堂點名；要 `manage_org_settings` 才出現（新增、編輯都是） |
| 收款帳戶     | 多行文字 | 否   | 見下方「家長付款帳戶資訊」；要 `manage_finance` 才出現                            |

照 A6 `settings.html#campuses` 的 `campusForm`（#1314 SE3）。A6 把帳戶畫成「收款銀行＋帳號」兩欄，
使用者 10-21 裁不拆（[[architecture/a6-adoption-rules]] R5）。

### 出勤模式設定

| 模式               | 說明                                               |
| ------------------ | -------------------------------------------------- |
| 日到班模式（預設） | 學生打卡到班後，系統自動推算當天所有課堂的出席狀態 |
| 課堂模式           | 每堂課獨立計算出勤，需管理員或任課老師確認         |

### 家長付款帳戶資訊（#1073）

- 多行文字，分校表單（新增、編輯）裡填；**留白＝沿用系統設定裡的機構帳戶資訊**
- 只有「財務管理」（`manage_finance`）權限看得到、改得了 —— 改帳號等於改家長匯款的去向
- 家長端待付款帳單顯示孩子在籍分校的值，見 [[architecture/payment-info]]

### 教室管理（分校 ⋮ › 教室，#1314 SE3）

設計稿與裁定：[[specs/admin/system/campus-classrooms]]。

- 對話框標題「教室：○○分校」，副標列出現有教室「A 教室（30 人）、B 教室」或「這個分校還沒有教室」
- 新增：名稱（必填，分校內不可重名）、容納人數（預設 20，可留空）、設備（選填）；送出後關掉對話框
- 每間教室後的「⋯」：改名／修改（帶進同一組欄位）、刪除（就地確認；指定這間教室的時段改回不指定教室，toast 寫幾個時段）
- 容納人數只顯示，不擋班級人數上限；教室沒有停用狀態，不用就刪
- 權限跟改分校名稱、地址同一個門檻（管理員＋分校範圍），沒有另外的細部權限
- API：`/api/campuses/{id}/classrooms`（GET／POST）、`…/{roomId}`（PUT／DELETE）；分校列表每列帶 `classroomCount`
