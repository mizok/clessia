# 系統設定

**路徑**: `/admin/settings`
**角色**: Admin
**分組**: 系統設定

## 核心目的

全域系統參數設定。

## MVP 功能

> **現況（2026-10-22，#1314 SE2a）**：「一般」分頁 = 出勤紀錄模式、誰負責點名，加上兩個可收合段（A6）——
> **繳費**（預設繳費期限、家長繳費提醒、待開單提醒、連續請假可不收費、家長付款帳戶資訊；只有 `manage_finance` 看得到）
> 與**學期與繳費週期**（只列，增刪改在費用方案頁）。下面的「報名流程」「續課」「學年升級」是 PRD 原規格，
> **系統沒有那些行為**，所以不畫設定（偏離登記在 a6-adoption-rules）：學年升級 #1820、報名審核時效＋試聽跟進 #1821
> 另案；自動續課不做（使用者 10-22 裁）。

### 報名流程設定

| 設定項目         | 說明                       | 預設值 |
| ---------------- | -------------------------- | ------ |
| 報名審核處理時效 | 新申請應在幾天內完成審核   | 3 天   |
| 試聽跟進啟動天數 | 試聽結束後幾天產生跟進任務 | 1 天   |

### 繳費設定

| 設定項目           | 說明                                               | 預設值                            |
| ------------------ | -------------------------------------------------- | --------------------------------- |
| 預設繳費期限       | 建立繳費單時的預設天數                             | 7 天                              |
| 家長繳費提醒時間點 | 到期前 0–30 天或逾期第 1–60 天，最多 6 個（#1660） | 到期前 3 天、當天、逾期第 1、7 天 |
| 連續請假可不收費   | 連續請假滿幾個上課日提醒財務人員（2–30，#1732）    | 3 個上課日                        |

- **家長繳費提醒時間點**（#1626 Q2，#1660）：取代舊的「繳費到期前提醒 3 天」（從未實作）。推播的提醒時間點，
  可新增、刪除；只有 `manage_finance` 看得到、改得了。跟「待開單提醒」（`billing_reminder_days`，行政用）是兩件事。
  見 [[architecture/web-push]]。
- **連續請假可不收費**（#1732）：學生連續請假滿 N 個上課日，提醒有 `manage_finance` 的管理員，由行政手動調帳單或堂數；
  系統不改任何金額。只有 `manage_finance` 看得到、改得了。見 [[specs/admin/finance/leave-streak-waiver]]。
- **家長付款帳戶資訊**（#1073）：多行文字，家長待付款帳單看得到；分校可在分校設定覆寫。
  只有「財務管理」（`manage_finance`）看得到、改得了。見 [[architecture/payment-info]]。

### 續課設定

| 設定項目     | 說明                       | 預設值     |
| ------------ | -------------------------- | ---------- |
| 月繳發送日期 | 每月幾號產生下期繳費單     | 20 號      |
| 期繳發送日期 | 固定日期清單（逗號分隔）   | 1/15, 7/15 |
| 續課寬限期   | 繳費截止後幾天內仍保留名額 | 7 天       |

### 學期/週期定義

可自訂任意數量的繳費週期：

| 設定項目   | 說明                                            |
| ---------- | ----------------------------------------------- |
| 週期名稱   | 自訂名稱（如「春季班」「暑期班」「114上學期」） |
| 起訖日期   | 該週期的開始與結束日期                          |
| 續課通知日 | 在該日期發送續課確認（針對期繳學生）            |
| 是否啟用   | 可暫停不使用的週期                              |

**快速建立模板**：

> **使用者 2026-10-23 裁定（#1100 #35③）**：只做下面三個；名稱帶民國學年（「115 上學期」）；
> 建在「下一個學年」＝今天之後最近的 9/1 那一學年；選了直接建、同名略過，日期之後到費用方案頁改。
> 「三學期制」「學期+暑期班」不做；上表的續課通知日、是否啟用跟自動續課一起暫緩。
> 日期寫在 `apps/web/src/app/features/admin/pages/settings/period-templates.util.ts`。

| 模板名稱                   | 週期設定                                                                         |
| -------------------------- | -------------------------------------------------------------------------------- |
| 傳統二學期制               | 上學期（9/1-1/31）、下學期（2/1-6/30）                                           |
| 學期＋寒暑假               | 上學期（9/1-1/20）、寒假班（1/21-2/10）、下學期（2/11-6/30）、暑期班（7/1-8/31） |
| 上學期＋暑假／下學期＋寒假 | 上學期＋暑假（7/1-1/31）、下學期＋寒假（2/1-6/30）                               |

### 學年升級設定

| 設定項目   | 說明                       | 預設值 |
| ---------- | -------------------------- | ------ |
| 自動升級日 | 每年自動執行學年升級的日期 | 9/1    |
| 升級前提醒 | 升級前幾天通知管理員確認   | 7 天   |
