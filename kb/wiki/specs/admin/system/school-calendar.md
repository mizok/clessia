# 學校行事曆（#1160）

> 設計說明與裁定都在 #1160 的留言（計畫席 2026-11-12 gate：Q1／Q2／Q3／Q5／Q6 全取 (a)）。
> 這頁記的是**為什麼這樣做**，不記實作步驟。

## 用途

補習班主任排每學期課表時，要逐校看「哪天哪些學校放假、哪天學校補課」。政府沒有可用的 API
（教育部公文 → 各縣市 PDF，見 #1076），所以資料是**手填**，每年 7 月照各校公告填一次。

使用者 10-03 的兩則補充決定了形狀：

1. 主要用法是**單校整學期視圖**（選學校 + 期 → 一張表列出開學、休業式、寒暑假、補課、停課）；
   排課頁的疊圖是第二步。
2. 全系統的時間軸**只有機構的「期」**（`billing_periods`，#1076）；行事曆是疊在期裡的各校標記，
   **不是第二條學期軸**。

## 資料（`20261112074026_school_calendar_events.sql`）

`school_calendar_events(org_id, school_id, kind, start_date, end_date, note)`，`kind` 是 enum
`school_calendar_kind`（開學、休業式、寒假、暑假、補課、停課、其他）。

| 決定                                                           | 理由                                                                     | 拒絕的替代方案                                                                    |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **不存學年／學期**，只存日期區間；畫面用期的起訖篩「重疊即列」 | 補充 2：不是第二條學期軸。寒假這種跨 1/31 的區間也不用決定歸哪一學期     | 照 #1160 內文存 `academic_year, semester`：會變成跟 `school_exams` 一樣的第二條軸 |
| 單日事件 `start_date = end_date`                               | 一種形狀涵蓋區間與單日，查詢只有一條重疊條件                             | 另開 `date` 欄給單日                                                              |
| 帶 `org_id`（冗餘）                                            | c1：API 每句帶 `org_id`；值由伺服器從學校列帶，並驗學校屬於本 org        | 照 `school_exam_schedules` 只掛 `school_id`：過濾要 join                          |
| 學校刪除 **CASCADE**                                           | 學校只有「沒學生」才刪得掉，它的行事曆跟著走合理                         | RESTRICT：「刪不掉學校」會多一個畫面上看不見的原因                                |
| audit 記 `resource_type='school'`、action `calendar_event.*`   | 行事曆是學校的資料；不必 drop／重建整串 `audit_logs_resource_type_check` | 新增 `'school_calendar_event'` resource type                                      |

## API

| 方法   | 路徑                                          | 說明                                                                                                                     |
| ------ | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| GET    | `/api/schools/{id}/calendar-events?from&to`   | 該校跟區間重疊的事件（依開始日）；`meta.periods` 帶期的 id／名稱／起訖                                                   |
| POST   | `/api/schools/{id}/calendar-events`           | `{kind, startDate, endDate?, note?, alsoSchoolIds?}`；不給結束日＝單日；一所一筆、自己那所在第一筆                       |
| PATCH  | `/api/schools/{id}/calendar-events/{eventId}` | 部分更新；合併後再驗區間                                                                                                 |
| DELETE | 同上                                          | 硬刪（沒有下游參照）                                                                                                     |
| GET    | `/api/classes/{id}/school-calendar?from&to`   | 疊圖：這班**在讀**（active／pending_payment）學生的學校、跟區間重疊的事件，每筆帶該校在這班的學生數；`meta.studentCount` |

- 權限：行事曆掛在 `/api/schools` 底下（同一個 mount），讀 ADMIN_ONLY、寫 `manage_courses`。
  疊圖走 classes 的 `/:id/*` 分校守門（GET 範圍外回 404，同 #1800）。
- **期的窄讀取（Q6 (a)）**：`/api/billing-periods` 讀寫都要 `manage_finance`，只有 `manage_courses` 的主任
  讀不到期。行事曆 GET 順帶回期的起訖（只有日期、不含金額），不放寬 billing-periods 本身。
- **「同時加到」（Q2 (a)）**：同縣市的寒暑假多半一致，逐校填 30 所會讓人放棄維護。一次寫 N 列、
  各自獨立可改；任何一所不在本 org 就整批不寫（部分成功會讓人得逐校對帳）。
- **疊圖只算在讀學生**：退班、別班的學生不算；同一位學生兩筆報名只算一次；沒填學校的學生
  算進 `studentCount`、不算任何學校。

## 畫面

- **單校整學期視圖**（PR3）：`/admin/settings/schools/:id/calendar`。入口是學校列尾的行事曆圖示鈕。
  頁首有期的下拉選單（預設涵蓋今天的期，沒有就選最近的下一期；機構還沒有期就列全部）、
  摘要行「開學 … · 休業式 …」，下面一張表依日期排序。新增／編輯用共用對話框，單日類型隱藏結束日。
  這一版不做月曆格。
- **產生課堂疊圖**（PR4）：預覽清單每天加一行「寒假：○○國中、△△國小（共 N 位學生）」。
  **只標示、不自動取消勾選**（內文：自動避開之後再談）。這班沒有在讀學生時寫「這班還沒有學生，
  看不到學校行事曆」（Q3 (a)，不改用年級去對同學制的所有學校：那會變成 30 所以上的雜訊）。
  讀取失敗只影響這一行，不擋產生。
- A6 沒有任何學校行事曆的稿：樣式沿用 settings#schools 的章節列與 `A2.form` 對話框，偏離登記在 R5。

## 不做（這一版）

解析縣市 PDF、自動避開或提醒、課表週視圖的日期格標記、家長端或老師端顯示、
用行事曆改成績的學期歸屬（#1076）、月曆格視圖。
