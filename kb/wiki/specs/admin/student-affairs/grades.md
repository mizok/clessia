# 成績查閱

**路徑**: `/admin/grades`
**角色**: Admin
**分組**: 學務管理

## 核心目的

查詢所有學生成績。

## MVP 功能

### 篩選列

- 學生姓名
- 課程
- 開課班
- 日期範圍

### 成績列表

- 可依考試或學生分組（切換按鈕）
- 每筆顯示：學生姓名、考試名稱、課程、日期、分數、狀態（正常/缺考/補考）
- 及格/不及格用顏色區分（依該考試設定的及格線）

### 匯出功能

- 依篩選條件匯出 CSV
- 欄位：學生姓名、開課班、考試名稱、課程、日期、分數、狀態

## API 語意（#1115，2026-10-04）

考試**不掛課程也不掛班**：校內考靠 `academy_exam_classes` 對到班（一場可跨班），段考只有學校與科目、跟班無關。

| 篩選 | 校內考 | 段考 |
| --- | --- | --- |
| `classId` | 考試掛在這班 **且** 學生在這班有報名 | 學生在這班有報名（照「是不是這班的人」，計畫席裁） |
| `courseId` | 展開成它的所有開課班，同上 | 同上 |

- 報名**不分狀態**（含已結束）：成績是當時考的，退班了不該看不到。
- **分校範圍**：只看得到「任一筆報名的班級在範圍內」的學生（同請假、家長範圍，#816）；
  老師另受任課班限制，兩者取交集。
- **每生聚合** `GET /api/scores/students`：同一組篩選、每生一列（校內考總得分／總滿分、段考平均、
  計分／缺考／補考筆數、最新考試日），依姓名筆畫排序。**必帶 `classId`／`courseId`／`studentId` 其一**
  （否則 400 `SCOPE_REQUIRED`）；符合的成績超過一次撈得完的量（1000）時回 400 `TOO_MANY_ROWS`，
  不回被截斷的數字。
