# 「沒有值」的三種寫法

Tester 在 M4 詞彙統一（#425）點出全站有三種「沒資料」的寫法：「—」、「未填寫」、
「無關聯家長」。查證後這**不是同一件事的三種說法，是三種不同語意**，硬統一成一種
會抹平真正的差異。

## 三種語意，各自對應不同情境

| 寫法           | 情境                                                       | 例子                                                                                        |
| -------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `—`（em dash） | **唯讀顯示欄位**，這個欄位本來就可能沒有資料               | `dashboard.component.html` 的 `student.grade ?? '—'`；`invoice-detail-dialog` 的備註/收據號 |
| `未填寫`       | **可編輯的個人資料欄位**，行政還沒填                       | `campuses.page.html`、`students.page.html`、`staff.page.html` 的地址/電話/學校/生日         |
| `無關聯 X`     | **關聯不存在**，不是欄位空白，是這筆記錄沒有連到另一個實體 | `students.page.html` 的「無關聯家長」                                                       |

## 為什麼不能合併

- `—` vs `未填寫`：前者是「顯示層的通用空值符號」，後者是「這個欄位可以被填、現在還沒填」
  ——把可編輯欄位的「未填寫」改成 `—`，使用者會分不清楚這是「唯讀本來就沒有」還是
  「我可以去補上這筆資料」。
- `未填寫` vs `無關聯 X`：前者是欄位層級（這一格空白），後者是關聯層級（這筆記錄跟另一個
  實體沒有連結，不是某個欄位空白）。把「無關聯家長」改成「未填寫」會讓人以為家長欄位
  可以直接編輯打字，但實際上要走「建立關聯」的流程，不是填欄位。

## 判準

新增「沒有值」的顯示時，先問：

1. 這個欄位**能不能編輯**？能編輯又還沒填 → `未填寫`；唯讀顯示 → `—`
2. 沒有值的原因是**欄位空白**還是**關聯不存在**？關聯不存在 → `無關聯 X`（X 是缺的那個實體）

**不要因為「看起來都是沒資料」就統一寫法** —— 統一之後這裡列的區分理由就沒有地方記錄了，
下一個人會照著錯的方向去「修一致性」。
