# 聯絡簿規則

> 來源：2026-08-29 內部人訪談（[[summaries/interview-insider-2026-08-29]]）
> 與同日補充（raw/sources/interview-insider-2026-08-29-part2.md）。
> 2026-08-29 拍板納入範圍（[[roadmap]]），P1 要含它的 schema。現況是紙本。

## 0. 「聯絡簿」是兩個東西共用一個名字

|      | 國小模式（本頁）       | 國中模式（[[rules/teaching-log-rules]]） |
| ---- | ---------------------- | ---------------------------------------- |
| 實體 | 每生一本，小孩帶回家   | 分校×年級一本，所有科目老師合寫          |
| 內容 | 該生當天狀況（不分科） | 各科教學紀錄 + 作業安排                  |
| 家長 | 簽名                   | 現實中**完全看不到**（沒有小孩私群權限） |

班級的 `uses_contact_book` 開關就是模式選擇：國小班開、國中班關。
兩個開關正交 —— 別的補習班要「國中也寫個人評語」只是開關組合，不用改結構。

## 1. 每生每日唯一一則

- unique (student, date)。內容是**自由文字**：該生今天上課狀況的敘述，**不分課堂科目** —— 紙本現實就沒有科目維度。
- 一天上多個班也是同一篇。

## 2. 班級層級 opt-in

- 有的班用（低年級）、有的班不用（國中以上）→ 班級加「使用聯絡簿」開關。

## 3. 撰寫：帶班老師，可共編

- 帶班老師寫（老師端 P3 要有入口）；多位老師碰同一篇 = 共同編輯一則，記**最後編輯者**即可，不做分段作者。

## 4. 家長簽收

- 紙本要簽名，電子版也要：家長端一顆「已閱簽收」按鈕，記**誰、何時**（家長帳號 + timestamp）。不做手寫簽名畫板。
- **老師端要看得到家長已讀/已簽**（列表帶簽收狀態欄），管理端能看「哪些還沒簽」。
- 「有新聯絡簿」是 LINE 推播的天然觸發點。
- **國中家長的「已閱」做成 org 層開關**（grilling 定案）：現實中國中家長從不簽名，
  預設關；開了就在家長端對教務日誌作業顯示已閱按鈕，簽收記在
  `log_acknowledgements(log_id, student_id, acknowledged_by, at)`（log × 學生，
  兩個小孩修同一班各簽各的）。
