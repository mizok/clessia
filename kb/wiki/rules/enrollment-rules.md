# 報名與繳費規則

本文件整理 PRD 8.9 的報名規範。**繳費相關規則於 2026-08-29 依內部人訪談全面修訂**，
與 [[rules/billing-rules]] 對齊 —— 兩份文件衝突時，**以 billing-rules 為準**。

## 1. 報名申請基本規則

1. 家長提交申請後，狀態為 `pending`（待審核）。
2. 管理員審核通過後：
   - 建立繳費單。
   - 建立 Enrollment（狀態 `pending_payment`）。
   - 申請狀態轉 `awaiting_payment`。
3. 家長付款後通知補習班，管理員確認收款。
4. 首次收款（含部分繳費）時，若尚未建立主資料，系統需自動建立家長與學生資料。
5. 確認收款後更新：
   - 繳費單狀態（部分或全額）。
   - 申請狀態（已繳清可轉 `completed`）。
   - Enrollment 狀態轉 `active`（可依實務分批啟用）。

## 2. 計費模式規則（2026-08-29 修訂）

- 報名層級選擇 `billing_mode`：`monthly`（月繳）/ `period`（期繳，機構自訂日期區間）/
  `session_pack`（堂數制）。~~`semester`~~ 已由 `period` 取代 —— 「期」不是寫死的學期概念。
- 同一學生不同班可有不同模式；同一班可同時有月繳生與期繳生。
- 模式決定開單時機（見 [[rules/billing-rules]] 規則 1）。

## 3. 繳費狀態（2026-08-29 修訂）

**帳單狀態不是存起來的欄位，由收款累計推導**（billing-rules 規則 4）：
未繳 / 部分繳 / 繳清 = Σ收款 − Σ退費 vs Σ明細。「欠繳」= 過了 `due_date` 未繳清。

~~原六種狀態（pending / partial_paid / paid / overdue / void / refunded）~~ 已廢止：

- ~~`overdue` / `void` 的二階段寬限期~~ → 單一 `due_date`（org 設定預設天數，對齊
  「發收費袋後兩三週沒回音才催」的實際節奏）。**逾期不影響任何權限** —— 訪談定案
  「從未停課」，欠繳只做可見性（欠繳清單 + 催繳記錄），追討是人對人的事
- ~~`refunded` 狀態~~ → 退費是一筆負向收款記錄（kind = refund），不是帳單狀態
- **報名的 `void` 狀態仍存在但語意不同**：它是行政**手動作廢**報名（誤建、資料修正），
  是人的決定 —— 不是「逾期自動失效」。系統裡沒有任何自動停權路徑

## 4. 繳費期限（2026-08-29 修訂）

1. 開帳時設定 `due_date`（預設 = 開帳日 + org 設定天數，可逐張修改）。
2. 過 `due_date` 未繳清 → 進欠繳清單，行政以 LINE / 電話催繳並記錄。
3. ~~寬限期、自動失效、人工重啟~~ —— 整套機制不存在，見上節。

## 5. 費用計算與調整（2026-08-29 修訂）

1. 應繳金額：報名的 `agreed_amount`（議定價）優先，未設則依 `fee_template` 定價。
2. 期中插班按剩餘比例試算（按天或按堂），**試算是開單時的建議值**，行政可改。
3. 金額調整必須填寫調整原因（自由文字）。~~早鳥、兄弟姊妹折扣等結構化折扣類型~~
   不存在 —— 訪談定案「折數看老闆當下心情，每個客人可能不一樣」，折扣是議價不是規則。

## 6. 管理員直接報名規則

1. 管理員可跳過申請流程直接建 Enrollment。
2. 可同時指定計費模式與議定金額，並決定是否立即開帳。
3. 適用現場報名、老生加報、特殊例外案件。

## 7. 通知規則

| 事件               | 通知對象 | 方式         | 重點內容               |
| ------------------ | -------- | ------------ | ---------------------- |
| 新報名申請         | 管理員   | 站內         | 有新申請待審核         |
| 建立繳費單         | 家長     | 電話 / email | 金額、期限、付款方式   |
| 報名被拒絕         | 家長     | 電話         | 拒絕原因               |
| 即將到期（3 天前） | 管理員   | 站內         | 提醒跟進催繳           |
| 繳費完成           | 家長     | email        | 帳號資訊與報名成功通知 |
| 申請過期           | 管理員   | 站內         | 單據已過期             |
