# 報名與繳費規則

本文件整理 PRD 8.9，定義報名審核、繳費狀態、寬限期、直接報名與通知規範，供報名與財務流程實作統一依循。

## 1. 報名申請基本規則

1. 家長提交申請後，狀態為 `pending`（待審核）。
2. 管理員審核通過後：
   - 建立繳費單。
   - 建立 Enrollment（狀態 `pending_payment`）。
   - 申請狀態轉 `awaiting_payment`。
3. 家長付款後通知補習班，管理員確認收款。
4. 首次收款（含部分繳費）時，若尚未建立主資料，系統需自動建立家長與學生資料。
5. 確認收款後更新：
   - 繳費單狀態（部分或全額）。
   - 申請狀態（已繳清可轉 `completed`）。
   - Enrollment 狀態轉 `active`（可依實務分批啟用）。

## 2. 繳費週期規則

- 報名可選 `monthly`（月繳）或 `semester`（期繳）。
- 同一學生不同課程可有不同週期。
- 週期會影響續課通知與開單時機。

## 3. 繳費狀態定義

| 狀態           | 定義                 | 對上課權限影響                               |
| -------------- | -------------------- | -------------------------------------------- |
| `pending`      | 剛建立，尚未付款     | 可依 Enrollment 設定與寬限期處理             |
| `partial_paid` | 已付部分金額         | 視為有效報名，可正常上課，不因逾期自動失效   |
| `paid`         | 全額繳清             | 正常上課                                     |
| `overdue`      | 超過期限但仍在寬限期 | 權限不受影響，但需催繳                       |
| `void`         | 超過期限 + 寬限期    | 報名失效，停止入班/點名                      |
| `refunded`     | 已付款後退款         | 對應 Enrollment 應改 `withdrawal` 並撤銷權限 |

## 4. 繳費期限與寬限期

1. 審核通過建立繳費單時設定繳費期限（預設 7 天）。
2. 超過繳費期限進入 `overdue`。
3. 超過「期限 + 寬限期（預設 7 天）」轉 `void`。
4. 已失效案件可由管理員人工重啟（延長期限或重新啟用）。

## 5. 費用計算與調整

1. 應繳金額預設依 Fee Template 計算。
2. 若方案支援按比例，學期中加入可按剩餘課堂數計算。
3. 管理員可調整金額，但必須填寫調整原因（如早鳥、兄弟姊妹折扣）。

## 6. 管理員直接報名規則

1. 管理員可跳過申請流程直接建 Enrollment。
2. 可同時指定繳費週期，並決定是否建立繳費單。
3. 適用現場報名、老生加報、特殊例外案件。

## 7. 通知規則

| 事件               | 通知對象 | 方式         | 重點內容               |
| ------------------ | -------- | ------------ | ---------------------- |
| 新報名申請         | 管理員   | 站內         | 有新申請待審核         |
| 建立繳費單         | 家長     | 電話 / email | 金額、期限、付款方式   |
| 報名被拒絕         | 家長     | 電話         | 拒絕原因               |
| 即將到期（3 天前） | 管理員   | 站內         | 提醒跟進催繳           |
| 繳費完成           | 家長     | email        | 帳號資訊與報名成功通知 |
| 申請過期           | 管理員   | 站內         | 單據已過期             |
