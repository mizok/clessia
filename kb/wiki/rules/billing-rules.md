# 計費與收款規則

> 來源：2026-08-29 內部人訪談（[[summaries/interview-insider-2026-08-29]]）。
> 這些是 P1 金流 schema（`fee_templates` / `invoices` / `payment_records`）的設計輸入。

## 1. 計費模式：三種，掛在報名上

| 模式   | 定義                                                       | 備註                                                                                                                                 |
| ------ | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 月繳   | 每月一張帳單                                               |                                                                                                                                      |
| 期繳   | 機構自訂的具名日期區間（如「2026 上學期+暑假」＝2/1–8/31） | 「期」**不是 enum** —— 受訪公司是一年兩期（上學期+暑假／下學期+寒假），但其他機構可能一年一期或學期制，所以期是 admin 自建的日期區間 |
| 堂數制 | 買 N 堂慢慢上完                                            | 小型才藝班用。需要「剩餘堂數」概念，出席扣堂；效期為**可選欄位**（受訪公司不設效期，通用設計留空間）                                 |

- **計費模式是學生報名層級的選擇**，不是班級屬性 —— 同一班可同時有月繳生與期繳生。
- 堂數用完不硬擋上課：剩餘 ≤ 0 時警示行政追補買（從寬預設）。

## 2. 金額：定價 + 人工覆寫，沒有折扣引擎

> 「期繳有比較便宜，折數看老闆當下心情，每個客人還有可能不一樣。」 — raw/sources/interview-insider-2026-08-29.md

- `fee_template` 只給**定價**；每張帳單存「定價、實收、調整原因（自由文字）」。
- **不做**結構化折扣（兄弟姊妹折、續讀折、早鳥折）—— 現實裡不存在這些規則，只存在議價。

## 3. 插班與退班：同一套比例試算，方向相反

- 期中插班：按當期**剩餘比例**收；退班：按剩餘比例退。
- 比例基準二選一：**剩餘天數** 或 **剩餘堂數**（堂數按該生實際修的班級課表算，sessions 資料已存在）。
- 試算是**開單時的建議值**，不是死規則 —— 行政可改（規則 2 的人工覆寫涵蓋）。
- 退費記為負向收款（refund），留原因與經手人。

## 4. 帳單與收款：一對多

- 一張 invoice 可對多筆 payment_record（分期實務存在：「偶爾有家長要求分期」）。
- 帳單狀態由累計實收推導：未繳 / 部分繳 / 繳清。**不做**排程式分期計畫。
- 多子女合繳：**拆開記**（每筆收款屬於單一帳單），備註同筆轉帳。UX 之後可加「一筆金額分配到多張帳單」輔助，schema 不變。

## 5. 付款方式與憑證

- method enum：`cash` / `transfer`（現況約 50/50 現金略多）。線上金流**延後而非排除** —— enum 加值即可擴充。
- 轉帳對帳靠家長回傳截圖：transfer 收款支援**附一張憑證圖** + 備註（後五碼）。不做銀行對帳單自動對帳。
- 收款開**收據**（有編號、瀏覽器列印）。電子發票**延後而非排除**：收款記錄存齊發票所需資料（金額、日期、付款人、品項），不做串接。

## 6. 欠繳：可見性，不強制

- 受訪公司用 LINE／電話追繳，**從未停課** —— 不做欠繳自動停課。
- 系統提供：欠繳清單（誰、欠多少、欠多久）+ 催繳記錄（何時、何管道）。LINE 推播可當提醒管道。

## 7. 缺課不退不抵

- 月/期繳：缺課不補償；特例走「下期帳單人工調整」（規則 2）。
- 堂數制唯一的結構化決定：**「請假那堂扣不扣堂」是一個設定值**（org 或班級層級）。
