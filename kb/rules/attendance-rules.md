# 出勤與請假規則

本文件整理 PRD 8.3-8.4，定義出勤模式、系統推算邏輯、人工修改權限與請假處理規則，作為到班/點名模組的核心行為準則。

## 1. 出勤模式規則

### 1.1 日到班模式（預設）

- 學生打卡後，系統自動將當天符合條件課堂推算為出席（或遲到）。
- 適合學生整天在補習班的場景。

### 1.2 課堂模式

- 打卡僅記錄到班時間，不直接完成課堂出勤。
- 需由管理員或老師逐堂確認。

## 2. 通用出勤規則

1. 學生到班後，系統行為取決於分校設定的出勤模式。
2. 「有報名」判斷條件：
   - 學生已報名該開課班。
   - 當天日期落在 Enrollment 生效期間內。
3. 若課堂出勤已被人工修改，系統推算不得覆蓋。
4. 課堂結束後仍無任何出勤紀錄，系統自動標記為 `absent`。

## 3. 出勤修改權限

| 角色   | 權限邊界                       |
| ------ | ------------------------------ |
| 管理員 | 可修改所有課堂、不限日期       |
| 老師   | 僅可修改自己任課課堂，且限當天 |

超過老師可修改時限的修正，一律由管理員處理。

## 4. 請假規則

1. 請假只能由管理員建立。
2. 允許事後補請。
3. 建立請假後，對應課堂出勤狀態需改為 `leave`。
