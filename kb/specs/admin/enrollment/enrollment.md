# 學生報名

**路徑**: `/admin/enrollment`
**角色**: Admin
**分組**: 報名管理

## 核心目的

管理員直接將學生加入開課班（跳過申請流程），適用現場報名、老生加報、特殊例外。

## 直接報名流程

1. 選擇學生（可搜尋）
2. 選擇開課班
3. 設定繳費週期（月繳 `monthly` / 期繳 `semester`）
4. 設定生效起迄日期
5. 選擇是否建立繳費單：
   - **是**：建立繳費單（`invoices`），狀態 `pending`；Enrollment 狀態設為 `pending_payment`
   - **否**：直接建立 Enrollment，狀態設為 `active`（現場已收款或特殊免費情況）
6. 確認 → 系統建立 Enrollment，學生立即進入課堂名單（若 `active`）

## 報名狀態與轉換條件

| 狀態              | 說明     | 轉換條件                                        |
| ----------------- | -------- | ----------------------------------------------- |
| `pending_payment` | 待付款   | 建立時選擇「建立繳費單」；收款確認後轉 `active` |
| `active`          | 正式生效 | 直接報名不建繳費單，或確認收款後                |
| `suspended`       | 停權     | 管理員手動操作，需填寫原因                      |
| `withdrawal`      | 退選     | 學生退出，需填寫原因                            |
| `void`            | 失效     | 繳費期限 + 寬限期到期未繳，或管理員操作         |

**狀態變更規則**：

- 變更為非活躍狀態（`suspended`、`withdrawal`、`void`）時，**必須填寫原因**
- `pending_payment` 的學生在寬限期內可出現在課堂名單，標記「待繳費」

## 報名列表管理

- 篩選：學生、開課班、狀態、日期範圍
- 每筆顯示：學生姓名、開課班、生效期間、繳費週期、狀態
- 操作：
  - 編輯（修改生效期間、繳費週期）
  - 終止報名（轉為 `withdrawal`，需填原因）

## 費用計算邏輯

- 預設依對應 Fee Template 計算應繳金額
- 若開課班支援按比例計算，學期中加入可按剩餘課堂數計算
- 管理員可調整金額，但必須填寫調整原因（如折扣、優惠）

## 資料依賴

| 操作 | 資料表                                                |
| ---- | ----------------------------------------------------- |
| 讀取 | `enrollments`, `students`, `classes`, `fee_templates` |
| 寫入 | `enrollments`, `invoices`（可選）                     |

## 報名發起入口

管理員可從兩個地方發起報名，邏輯相同，入口不同：

| 入口                                 | 適用情境                                         |
| ------------------------------------ | ------------------------------------------------ |
| `/admin/enrollment`（本頁）          | 以「班級」或「報名管理」為主體操作，批次處理多筆 |
| 學生詳情頁 → 在籍班級 → 「加入班級」 | 以「學生」為主體，快速將單一學生加入班級         |

學生詳情頁的加入班級目前為**簡化版**：直接建立 `active` enrollment，不處理繳費週期與繳費單，適合快速操作。完整繳費設定仍應透過本頁流程。

## 實作註記

- 學生沒有報名開課班就不會出現在任何課堂的學生名單中
- 同一學生可報名多個開課班，各自有獨立的繳費週期
- 直接報名不建繳費單時，屬人工例外流程，系統不追蹤繳費狀態
- Enrollment response 包含 `courseId`、`courseName`，方便前端直接顯示課程資訊
