# 學生資料

**路徑**: `/admin/students`
**角色**: Admin
**分組**: 學務管理

## 核心目的

查詢、新增與編輯學生基本資料。學生資料有兩種來源：

- **公開報名**：家長透過報名頁填寫，繳費完成後自動建立
- **管理員手動新增**：管理員直接在後台建立，適用於內部人員子女入學、現場報名等情境

> ⚠️ **待實作**：手動新增學生功能尚未完成，目前只有編輯。

## MVP 功能

### 學生列表

- 篩選：姓名搜尋、年級、分校（依報名的開課班所屬分校）
- 每筆顯示：姓名、年級、學校、關聯家長、報名課程數
- 點擊 row 進入詳情頁（整行可點擊，hover 有提示）

### 新增 / 編輯學生表單

| 欄位       | 類型     | 必填 | 說明                |
| ---------- | -------- | ---- | ------------------- |
| 姓名       | 文字     | 是   |                     |
| 年級       | 下拉選單 | 是   | P1-P6, J1-J3, S1-S3 |
| 就讀學校   | 文字     | 是   |                     |
| 生日       | 日期     | 否   |                     |
| 性別       | 單選     | 否   | 男/女/不透露        |
| 電話       | 文字     | 否   | 學生本人電話        |
| 地址       | 文字     | 否   |                     |
| 緊急聯絡人 | 文字     | 否   | 姓名+電話           |
| 備註       | 長文字   | 否   |                     |

新增時可選填關聯家長（選擇現有家長帳號），也可留空之後再補。「學生必須有家長帳號」的限制**只適用於公開報名流程**，管理員不受此限制。

### 學生詳情頁

- 基本資料（點「編輯資料」開啟表單）
- 關聯家長列表
- **在籍班級**：顯示 `active` / `pending_payment` 的 enrollments，含課程名稱、班級名稱、狀態
  - 點擊班級 row → 導航至班級詳情頁
  - 「加入班級」按鈕 → 開啟班級選擇器（ClassPickerDialog），選擇後直接建立 enrollment
- 出勤統計摘要（待實作）
- 成績統計摘要（待實作）
