# 請假管理

**路徑**: `/admin/leave`
**角色**: Admin
**分組**: 學務管理

## 核心目的

建立和查詢請假紀錄。請假只能由管理員建立，支援事後補請。

## 請假建立規則（重要）

1. 請假**只能由管理員**建立，老師和家長無此權限
2. **允許事後補請**（已過去的課堂也可以補建請假）
3. 建立請假後，系統**自動將對應課堂的出勤狀態改為 `leave`**
4. 若該課堂出勤已被標為其他狀態（`present`/`late`/`absent`），建立請假後仍需覆蓋為 `leave`
5. **刪除請假後**：出勤狀態不自動還原（需管理員手動修正出勤），避免誤覆蓋人工修改

## MVP 功能

### 分頁切換

- **待處理分頁**：今天或未來的請假申請（需跟進或確認的）
- **全部分頁**：所有請假紀錄，可篩選

### 篩選列（全部分頁）

- 日期範圍
- 學生姓名
- 課程
- 開課班

### 請假列表

每筆顯示：

- 學生姓名
- 請假日期
- 課堂（課程名稱 + 時間）
- 請假原因
- 建立時間
- 建立者

點擊可展開編輯或刪除

### 新增請假 Popup

1. 選擇學生（可搜尋）
2. 選擇請假日期
3. 系統顯示該學生當天「有報名且在生效期間內」的課堂列表，勾選要請假的課堂（可多選）
   - 若當天無符合課堂，顯示「該日無排課」提示
4. 輸入請假原因（可選）
5. 確認建立
6. **系統副作用**：自動將所選課堂的出勤狀態更新為 `leave`

### 批次請假

- 選擇一個課堂 → 勾選多個學生 → 批次建立請假
- 適用場景：全班校外教學、颱風停課補假等
- 批次建立後同樣觸發每位學生對應課堂出勤改為 `leave`
