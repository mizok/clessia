# 出勤紀錄

**路徑**: `/admin/attendance`
**角色**: Admin
**分組**: 學務管理

## 核心目的

查看和修正學生出勤狀態。管理員擁有不限時間、不限課堂的修改權限。

## 出勤模式（分校層級設定）

本頁面行為受分校出勤模式影響（詳見 [出勤與請假規則](../../../rules/attendance-rules.md)）：

- **日到班模式（預設）**：學生到班後系統自動推算課堂出勤，來源標記為「系統推算」
- **課堂模式**：到班僅記錄事件，需管理員或老師逐堂人工確認

## 出勤狀態

| 狀態 | 說明 |
|------|------|
| `present` | 出席（準時到班） |
| `late` | 遲到（超過課堂開始寬限期到班） |
| `leave` | 請假（需有對應請假紀錄） |
| `absent` | 缺席（課堂結束後仍無任何出勤紀錄，系統自動標記） |

## 修改權限規則（重要）

| 角色 | 可修改範圍 |
|------|-----------|
| 管理員 | 所有課堂、不限日期 |
| 老師 | 僅自己任課課堂，且限當天 |

**系統推算優先權**：
- 若課堂出勤已被人工修改，系統推算**不得覆蓋**
- 修改後來源標記為「人工修改」，後續到班掃碼不影響此紀錄

## MVP 功能

### 篩選列

- 日期範圍（預設今日）
- 課程
- 開課班
- 出勤狀態（全部 / 有異常）

### 課堂列表

- 按日期排序（最近在上）
- 每筆顯示：日期、時間、開課班名稱、老師、出勤摘要（例如「10 出席 / 1 遲到 / 1 缺席」）
- 有缺席或遲到的課堂加標記提醒（視覺區分）
- 點擊展開該課堂的學生出勤列表

### 展開列表（課堂詳情）

- 列出該課堂所有報名學生的出勤狀態
- 每筆：學生姓名、出勤狀態、來源（系統推算 / 人工修改）、到班時間（若有）
- 可直接在展開區域修改出勤狀態並儲存
- 修改後來源自動標記為「人工修改」

### 出勤狀態修改邏輯

1. 管理員選擇學生 → 選擇新狀態
2. 若改為 `leave`，需先確認該課堂已有請假紀錄；若無，系統提示先去建立請假
3. 儲存後記錄稽核 log（誰、何時、從哪個狀態改為哪個狀態）
