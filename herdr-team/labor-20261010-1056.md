## 一、別人的 server 佔了 4200／8787 時，自己另起一組的做法

web 的 API 網址寫死在 `apps/web/src/environments/environment.ts`（`localhost:8787`），所以換 port 要動三處：

1. `apps/api/.dev.vars`（gitignore）的 `BETTER_AUTH_URL`；`wrangler dev --port 8887 --inspector-port 9339 --var WEB_URL:http://localhost:4300 BETTER_AUTH_URL:http://localhost:8887`
2. `nx serve web --port 4300`
3. **臨時**把 `environment.ts` 的 `8787` 改成 `8887`

**第 3 項不能 commit，也不能留到回合結束**：`system-clock.service.spec.ts` 寫死 `http://localhost:8787/api/system-time`，留著改動 Stop hook 會報「弄壞 1 支測試」。做法＝要開瀏覽器才改、離開前 `git checkout` 還原（dev server 會因此重編、指回 8787，所以截圖前再改一次）。登入連結用 `WEB_URL=http://localhost:4300 LOGIN_EMAIL=… npx tsx apps/api/src/scripts/login-link.ts`（先 `set -a; . apps/api/.dev.vars`）。`vd.mjs` 內寫死 1008 的 A6 路徑與快取目錄，複製過來要改。

## 二、spec 的坑

- **頁面自己 `providers: [DialogService]` 時，只在 TestBed `providers` 放 mock 蓋不掉**，要 `TestBed.overrideProvider(DialogService, { useValue })`。學生檔案頁原本的 spec 其實一直在用真的 DialogService（沒人發現，因為沒有 spec 去斷言 `open`）。
- 往 `describe` 末尾附加新 `it` 前先確認那個 `});` 是哪一層：請假對話框 spec 有兩個頂層 describe，各有各的 mock，我第一次附加掉進了別人的 scope（找不到 `dialogRefMock`）。
- `vi.fn` 物件加欄位時型別會擋（TS4111 index signature）：`Record<string, ReturnType<typeof vi.fn>>` ＋ `['x']` 存取。

## 三、這一頁的設計決定（#1483）

- **到班區間** `attendanceRange`：API 的區間上限是**整段 366 天**，所以「最早報名起到今天＋21」要把起日夾到「迄」往前 365 天，不能夾到「今天」往前（那樣加上 21 天會超限回 400）。
- **紀錄時間軸前端組**（`buildLog`）：UTC 時間戳一律先換台北日期（`taipeiDateString`），`slice(0,10)` 會讓晚上 8 點後的事件差一天。
- **工具列的「收款」讀帳單章的 signal**（`viewChild(StudentBillingChapterComponent)`，章公開 `invoices`／`totalOutstanding`／`collect()`）而不是頁面再打一次 API；同一份資料兩處用不會互相漂掉。代價：頁面的 `outstandingTotal` 在章渲染前是 0。
- **請假對話框的 `data.student`**＝預帶學生（學生唯讀、不載入分校）；跟 `data.leave`（編輯）同一種「學生固定」，共用 `fixedStudentName()`。
- 托盤主鈕**不要放圖示**：`收款 NT$ 94,590` 加圖示在 360 會折兩行，A6 是單行。
- 摺疊列元件 `app-student-fold` 是這個 feature 內的（只有學生檔案用）；帳單章是同一個形但自己有資料與對話框，沒併進去。

## 四、實機驗證的限制

- **PrimeNG 日期選擇器很難自動化**：對話框 autofocus 會自動展開日曆，`click`、`fill`、`pressSequentially` 都沒能讓「送出」啟用（動畫中元素「not stable」）。我放棄在實機按「送出請假」，改由 spec 覆蓋 `create` 帶預帶的 studentId，PR 明寫「沒按成」。下一個要驗請假送出的人，建議直接用 API 驗寫入，UI 只驗對話框開得起來。
- 關對話框的通用寫法：先 `Escape` 收掉日曆浮層，再點 mask 內的「取消」（`.p-dialog-mask` 還在就重複）。
- 對帳腳本形狀見 1008 charter §三；這一輪我對的是：格數＝`days.length`、每格 `title` 結尾對 `state`、`came／due`、`absentDates` 個數、報名列的 `classSchedule`、待收帳單中最早 `dueDate`。
