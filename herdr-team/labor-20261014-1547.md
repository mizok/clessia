## 一、手滑與環境（這輪各踩一次）

- **`git checkout <檔案>` 會丟掉沒 commit 的實作。** 突變腳本跑完我用它「還原」，結果連同整支儀表板實作一起回到 main（#1577）。**突變前先 commit（WIP 也行）**，還原才能用 `git checkout`；沒 commit 就只能靠腳本自己的 `finally`。
- **`sed -i` 在 macOS 要 `-i ''`**；而且 **BSD sed 的 `\{` 是區間運算子**，改含 `{ }` 的 TS 用 python。
- **prettier 會重排 class 屬性**：我寫好的 python 取代字串（`<div class="…">`）在 prettier 之後就對不上，**第二輪取代要用 class 字串本身、不帶標籤**；`assert old in s` 一定要加，否則「取代了 0 處」不會報錯、spec 卻因為舊 class 還在而紅得莫名。
- **本機 API 與 web 的 port**：8787 常被別席佔（它跑的是**它那個 worktree 的程式碼**，你取證看到的欄位是它的版本，不是你的）。自己 `npx wrangler dev --port 8790 --inspector-port 9340`、web `--port=4207`，暫改 `apps/web/src/environments/environment.ts` 的 8787→8790 取證，**commit 前 `git checkout` 還原**（它會讓 `system-clock.service.spec` 變紅）。取證用 `.pw-regression/` 腳本、登入態用 `~/.cache/clessia-visual-diff-1910/state-admin.json`。
- **`TMPDIR` 路徑尾巴有雙斜線**，`mkdir -p $TMPDIR/l` 後再用會找不到；暫存一律放 scratchpad。

## 二、API 的「兩條都成立才算」與 DB-campus（儀表板）

- **帳單的分校歸屬判準只有一份**：`apps/api/src/lib/invoice-campus-scope.ts` 的 `invoiceInScope`（學生任一報名在範圍＋有班的明細**全部**在範圍）。純餐費單不被排除 → **跨校學生的純餐費單兩校都算，各校逾期加總會大於全部**；跨校明細單選 A、選 B 都不出現，加總小於全部。儀表板那一行「另有 N 張跨校帳單」的 N ＝ **逾期、有班明細同時在範圍內外、未作廢**（`GET /invoices/summary` 的 `crossCampusOverdue.count`，後端席做的），純餐費不計。
- **示範庫沒有逾期的跨校帳單**（13 間分校逐一查 N 全是 0）→ 要看到數字只能攔截 summary 回應改值，PR 要明寫「這是攔截取得的」。
- **儀表板的取數模式**：`bind(reset, load, apply, refresh?)`＋`switchMap`；**換分校才 reset（清成「還不知道」），`refresh` 只重查不清**。頁面內沒有路徑能在不換分校時重打 summary，所以「失敗不清值」的突變是**等價突變**（#1585 二讀確認），不要為它硬造測試。
- **spec 裡 `toObservable` 的 effect 要 `fixture.detectChanges()` 才會跑**：`signal.update` 之後直接斷言 mock 呼叫數會少一次（#1577 第一版）。

## 三、突變驗證又學到的三種「綠」（接 1404 §一）

- **模板的 `@if (x; as n)` 會把 0 當 falsy 吞掉**：邏輯上寫了 `count > 0`，改成 `>= 0` 卻全綠，因為 `n=0` 在模板就不畫。**0 的判斷只留一處、模板明寫 `!== null`**（#1585）。
- **「這一頁已載入列」的分章要斷言章頭數字**：只斷言有沒有章，`[count]="ch.rows.length"` 改成整頁列數仍綠（#1574）。**測的是畫面哪個東西，就斷言那個東西**。
- **p-popover 的 `onShow`／`onHide` 回寫沒有任何東西在守**：拿掉 `(onHide)="filtersOpen.set(false)"` 全綠。要測：點篩選鈕**真的開浮層**，`popover.onShow.emit()` 補發（jsdom 沒有動畫結束事件），`popover.hide()` 才會發 `onHide`；**在沒開的浮層上 `hide()` 不會發事件**。
