### conformance：`noSubDeviations(pop, title, sub, { deleted, extra })`（config.mjs）

每個彈出物一行，涵蓋副標搬走的連帶差：

- 標頭變矮（h2、✕ 上下位移）
- h2 不再被副標撐寬
- 同一個彈出物裡的部件只上下位移（`Δx 0、Δy ±N`）
- 原副標段落的位置／尺寸／樣式／文案；A 類刪掉時用 `deleted: true` 吃「缺」

`title`／`sub` 是 regex 片段（`{分校}`、`#` 是工具的文案模板）。稿的 form 自帶內距、form 又被推下去的（教室、停用開課班），用 `extra` 補一條 form 的位置。

⚠ **插偏離要找 `export const PAGES` 之後的那個頁**：`FORM_DIALOGS` 裡也有 `staff:`、`courses:` 等同名鍵，第一個 match 不是頁面（#2400 第一輪把 staff 的偏離插進了 students）。

## 四、這次學到的

1. **疊單 squash 進 main 後，後一張 merge main 會把同一個方法留兩份**（#2393 `private confirm()`）：
   - 不只 config 的偏離區塊會這樣，ts 方法也會
   - 解完要 grep 方法名數，並跟已推分支 diff 那支檔要是 0
2. **`p-dialog` 的投影內容關著時就建好**：殼的 `appDialogTitle` 找不到外框，名稱是空的（compare 抓到）。殼要包在 `@if (visible)` 裡
3. **ng-template 的 context 別傳方法參考**：`save: saveDisplayName` 呼叫時丟 `this`。改傳 key，由一個分派方法呼叫
4. **有 `<form>` 的換殼對話框**：送出鈕 `type="submit" form="<id>"`、不綁 `(click)`
   - spec 要數 `save` 不數 `create`：save 進去會設 saving，第二次被擋，數 create 看不出重送
   - 要做「把 (click) 加回去」的突變確認會紅
5. **harness 的 44px 檢查只看靜態 `class`**：`[class]="常數"` 會被判成沒有下限，按鈕 class 要寫靜態
6. **compare 第一次配上某個彈窗時，冒出的待修多半是原本就有的內容差**（標題、h2 對上才配得到），PR 要寫清楚來源，不要當回歸。h2 只有字寬多半是少了稿的副標（標頭內容區靠副標撐寬）
