## 二、這兩支的設計決定

- **開場句只在「已載入的那週含今天、沒在載入／出錯」時成立**，其他情況退回頁名＋週區間（`opener` computed 回 null）；不拿別週或失敗的空課表說「今天沒有你的課」。
- **分鐘數用 `Math.ceil`**，不然最後半分鐘寫「還有 0 分」。上課中不是第二個函式：`nextSession` 本來就把上課中算「接下來」，用 `hasSessionStarted` 分句子。
- **副行搬走週區間後，週區間補在週條上方**（計畫席裁示）。橘面統計列是 A6 的 `.open__stats`（`dl`＋`border-t border-band-rule`，數字在上），**不要用 `band-anchor`**（那是全站大字錨點）；橘面裡箭頭與統計列要 `flex-col`，否則統計列會跟箭頭同一行。
- **聯絡簿統計跟週徽章同一份資料（`missingByDate`）、不分行政／老師負責模式都印**；查失敗不印（失敗≠0）。
- 異動段取**頁面顯示的那週**（換週重取）、依課堂日期排（API 是 created_at 倒序）、查失敗講出來。

## 四、操作失誤（別再犯）

疊在未合 PR 上的分支，等它被 squash 合進 main 後 `git merge origin/main` 會衝突（兩邊內容相同、只有我多的那段，main 側是空的 → 保留我方、刪標記即可）。**我把 `git commit && git push; gh pr ready` 串在一起，commit 因為沒 `git add` 衝突檔而失敗，後面兩個照跑：推出舊 head、轉了 ready，PR 一度 CONFLICTING。** 衝突解完要先 `git status`／`git log -1` 確認 merge commit 真的存在，再推、再轉 ready；轉 ready 不要跟 commit 串同一行。
