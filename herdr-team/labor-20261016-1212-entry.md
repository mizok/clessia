## 二、公開殼的結構（改它之前先知道）

- **手機兩面＝一條 2 × `--window-width` 寬的 fixed 軌道，用 `left` 平移，不用 `transform`。**
  transform 會讓軌道變成 `position: fixed` 後代的定位基準 —— 選身分的遮罩與彈窗會跟著兩倍寬的軌道跑位
  （A6 稿的註解先踩過）。
- **哪一面在畫面上完全由網址決定**（`PublicShellComponent.isRight`）：`#form`、登入的 `?error=`／`?reason=`、
  `/select-role`。所以重新整理、瀏覽器返回鍵不用另外處理。
  返回列：入口連結用 `[state]="{ publicForm: true }"` 推歷史，返回列看到這個記號就 `location.back()`，
  沒有（深連結進來）就 `replaceUrl` 換掉網址。**不要用「有沒有上一個導航」判斷** —— 上一個可能是別頁。
- **登入的底部面板住在 `LoginComponent`，觸發鈕在殼裡**，靠 `popovertarget="login-sheet"` 的 id 連起來
  （同一份 document、沒有 shadow DOM 才成立）。面板裡的 LINE 鍵跟表單面那顆是同一個 `ng-template`，
  共用 `submitting` 與錯誤。
- **斷點是 1024，不是全站殼的 `wide:`（861）。** 公開殼照 A6 `.ps` 的 1024；861–1024 之間公開頁是手機版。
  所以這裡的「桌機縮回」寫 `min-[1025px]:`，不是 `wide:`。

## 三、會再撞到的坑

1. **Tailwind variant 的順序會吃掉 `motion-reduce:`。** `max-[1024px]:transition-[left]` 排在
   `motion-reduce:transition-none` 後面，減少動態時照樣平移。要寫成 `max-[1024px]:motion-reduce:transition-none`。
   **逐幀取樣抓到的，看畫面看不出來**（reduced-motion 要在 Playwright 開 `reducedMotion: 'reduce'` 量）。
2. **A27 gate 只看靜態 `class`，看不到 `[class]="tsConst"`。** 把共用 class 字串放 TS 常數會被報
   「可點但沒有 44px」。改成一支 `@for` 渲染、class 寫死在 template。
   A27 要的是**手機優先**：基底 `min-h-11`，桌機再用 variant 縮（`min-[1025px]:min-h-0`）；反過來寫 `max-*:min-h-11` 不算。
3. **PrimeNG `.p-dialog-content` 會裁掉焦點框。** 把內距從內容區搬到卡片本身（為了對 A6 的 padding）之後，
   `outline-offset: 2px` 的焦點框被內容區的捲動裁切切掉兩側。內容不需要捲動時給 `overflow: visible`。
4. **DynamicDialog 在 `showHeader: false` 時不掛 `aria-labelledby`**（config 的 `ariaLabelledBy` 也不用）。
   由內容元件 `afterNextRender` 往上找 `[role="dialog"]` 補。
5. **按鈕的行高是 `normal`，不繼承 body 的 1.5。** 本 repo 沒有 Tailwind preflight，A6 稿的按鈕有繼承；
   conformance 會報 `lineHeight 21px → normal`，按鈕上加 `leading-normal`。

6. **`[inert]` 擋得住 top layer 裡的 popover。** 面板 `showPopover()` 進了 top layer、畫面上看得見，
   但它在 DOM 裡的祖先若是 inert（手機停在品牌面時的 `<main>`），整棵子樹照樣點不到、拿不到焦點，
   點擊穿到後面的元素（#1639 二讀抓到：點 LINE 鍵變成點到 nav 的「我要報名」）。
   **住在會被 inert 的區域裡的彈出物，要搬到 `<body>`**（`afterNextRender` append、`DestroyRef` 自己 remove）。
   **量動態不等於驗互動**：這次逐幀取樣全綠，因為取樣只看位置與 opacity，沒有實點面板裡的鍵。
7. **jsdom 的 `el.inert = true` 不會反映成 `inert` 屬性**，`closest('[inert]')` 找不到 → 守 inert 的 spec 永遠綠。
   用 `setAttribute('inert', '')`，並**突變驗證**（拿掉修正看它會不會紅）。
8. **本機 api 沒有 LINE 金鑰**：`/api/auth/sign-in/social` 回 404。要驗「點 LINE 鍵會導去 LINE」，
   api 用 `--var LINE_CLIENT_ID:dummy-local --var LINE_CLIENT_SECRET:dummy-local` 起，Better Auth 就會組出 authorize 網址。

## 四、量測方法（conformance 工具還在 a6tool 席的分支）

- 自己起 api／web：`npx wrangler dev --port 8790 --inspector-port 9340 --var WEB_URL:http://localhost:4207 --var BETTER_AUTH_URL:http://localhost:8790`；
  web `nx serve web --port=4207`，**暫改** `environments/environment.ts` 的 8787 → 8790，commit 前 `git checkout` 還原。
- a6tool 席的登入態檔（`~/.cache/clessia-a6-conformance/state-multi.json`）換 api port 照樣能用：cookie 不分 port，session 在同一個 DB。
- **工具量頁高時會把視窗撐到最高的捲動區**。表單面多出一截捲動（例如登入頁 `min-h-full` 加上返回列）就會讓整張圖變高、
  所有 Δy 跟著歪。先修掉多餘的捲動，再讀位置差。
- **依賴的 PR 還沒合時量動態**：把對方分支的 `styles.css` diff 存成 patch，`git apply` 套上、量完 `git apply -R`，
  再 `cmp` 確認還原。不要 merge 對方分支進自己的。
- 逐幀取樣：在頁內用 rAF 記 `getBoundingClientRect()`、`opacity`、`::backdrop` 的 opacity，比截圖連拍準、也比影片好比對。
  腳本形狀：先 `page.evaluate` 起取樣（回 Promise），**再**點按鈕，最後 await 那個 Promise。
- 證據放 `~/.cache/clessia-a6-conformance/…`，**不要放 `/private/tmp`**（重開機會清，10-16 就清過一次）。
