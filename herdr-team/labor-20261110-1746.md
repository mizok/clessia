## 三、這次學到的

1. **整頁宿主的寫法**（全文在 `dialog-frame.md`「L4 整頁怎麼寫」）：同一支表單元件兩種宿主，頁面在自己的 `providers` 換上 `PageDialogRef`（`close()`＝站內 `location.back()`、直接打網址回 `fallback`）與空的 `DynamicDialogConfig`，**資料到了才渲染表單**（表單在建構時讀 `config.data`）。表單不分兩份、只多唯讀 `hasChanges()`。開窗端用 `dialogStepsActive()` 在點擊當下分流
2. **實測抓到的 bug，spec 抓不到**：殼的底部列是 `background: inherit`，對話框裡繼承 `.p-dialog` 的白，**頁面裡外層沒底色就透明**，捲動中的欄位從底部列下面透出來。390 寬 playwright 截圖才看到。頁面 host 要 `[&_.dialog-frame]:bg-white`。版面載體換了，「繼承來的」東西都要實看一次
3. **`app.routes.ts` 靜態 import 的東西全進 initial bundle**：guard 跟 `PageDialogRef extends DynamicDialogRef` 同檔時，`primeng/dynamicdialog` 被拉進 initial，896.74 kB 超過 800 kB 預算（#2414 CI build 紅；本機 spec、typecheck 全綠看不出來）。guard 拆到 `form-page-leave.guard.ts`（只 `import type`）後回到 767.69 kB。**路由檔 import 新東西前，送審前跑一次 `npx nx build web --configuration=production` 看 Initial total**
4. **回到來源頁會丟掉列表狀態**：整頁回去時來源頁元件重建，篩選、頁碼、展開都只在元件裡的話全部重設。課程頁本來有 `CoursesFilterStateService`（補了展開）；學生、家長列表新加。家長頁的頂欄分校那條第一次發出會先把頁碼歸 1 —— 要還原頁碼得在那裡套
5. **開窗端在 `onClose` 發的回饋，整頁不會跑**（toast、頁內 notice）：改由頁面宿主在 `close(result)` 時發。`<app-toast>` 在 app.component、`MessageService` 是 root，換頁不會消失。家長名這類開窗端才知道的東西用 `router.navigate(..., { state })` 帶，宿主讀 `history.state`
6. **突變要測得出「基準重設」**：審核席 #2413 突變 4 個存活 —— fixture 讓伺服器回的時段跟開窗時一樣，拿掉「讀完詳情重設基準」也綠。fixture 要讓重讀**真的換掉**內容（多一段未來時段）；「不看 key」要用「刪一列再加回同內容」才測得到。#2414 「config.data 少一欄」要斷言**表單上看得到的效果**（分校名進 `dialog-context`、全部班進「下一階班級」選項）
7. **疊單 squash 合併後**：上層分支 merge main 會在同一條（例 `dialog-frame.md`「版面」）出現新舊兩版的衝突 —— 那是同一條的兩個版本，取完整的那版，不是兩條都留；R5 表頂端則是真的兩列，都留。合完 grep 各關鍵句次數、`LC_ALL=C` 量 R5 重複。base 分支合掉後要 `gh pr edit --base main`，PR 的 diff 才對
