## 二、會再撞到的坑

1. **兩支各自綠的 PR squash 後可能讓 main 紅**（#1790）：型別加了必填欄位，另一支的 spec fixture 沒有。開分支前先
   `npx nx test web --include=…` 一次，建置錯是 main 的就另開救火 PR，別混進自己的單。
2. **Angular 事件綁定的值是 `false` 會自己 `preventDefault`**：`(evt)="cond && $event.preventDefault()"` 在 cond=false 時反而全擋（#1786）。寫成方法。
3. **CSS grid：有明確 row 的項目先放、自動的後放**。`row-start-1` 不配 `col-start-*` 的格子會搶到第一欄（班級列的平均曾跑到最左）。要在桌機改位置就把欄也釘死。
4. **列表 API 預設排序要看**：`academy-exams` 預設 `date_desc`；要「最早那場」得帶 `order:'date_asc'`（#1792 審核席擋點）。
5. **API 替身要真的照條件過濾列**，授權面的突變（拿掉分校過濾、拿掉任課過濾）才紅得起來；只記「有沒有下 `.in`」會在下錯查詢時也綠。範本：`academy-exams.spec.ts` 的 todo-by-class 段。
6. **本機契約測試**：`npm run test:contract -- src/contract/list-endpoints.contract.ts`（唯讀 GET，從 OpenAPI 取端點），新 GET 端點先在本機打一次 200。
7. **A6 conformance 前後比對**：`A6_API_URL=http://localhost:8797 node tools/a6-conformance/run.mjs compare <頁> --base origin/main --head <sha>`，
   要 commit 後才能比；列一有內容就會多出大量「新增待修」，多半是 seed 資料差（年級範圍、考試名），分開看。搜尋框照學生頁
   `clessia-filter-search`＋`p-iconfield` 寫，A27 讓按鈕 36→44 是已知偏離。
8. **p-popover 在 jsdom 可測**：點開觸發鈕後浮層掛在 `document.body`，`whenStable` 後 `onShow` 會回寫 `aria-expanded`。
9. **zsh**：`--include=*.ts` 要加引號；`git checkout -- <檔>` 會把同檔的正確修改一起退掉 —— 突變用 `cp` 備份還原。
10. 我的本機 API 在 8797（`wrangler dev --port 8797 --inspector-port 9361 --var WEB_URL:http://localhost:4210 --var BETTER_AUTH_URL:http://localhost:8797`）；8787／4200 是別席的。
