## 四、這次學到的

1. **compare 用的是「啟動當下」工作目錄裡的工具**：背景排隊等鎖時切了分支，跑起來就是別張單的 config（#7 第一次 compare 作廢）。要嘛等它真的開跑再切，要嘛另開 worktree 做下一張。本席後來 API 單、餐費單都在獨立 worktree 做
2. **compare 中途拋例外（API ECONNRESET）不會收掉自己起的 web server 與臨時 worktree**（已排 1610 #1962）。本席一度累積 6 個殘留 dev server＋一串 wrangler 孤兒 esbuild，機器 load 到 45；契約 `beforeAll` 10 秒逾時就是這樣來的。清法：照 cwd 找 `~/.cache/clessia-a6-conformance/wt/<自己的 sha>-*`，**別人的不要動**
3. **wrangler inspector proxy 遇大訊息會退出**（[probe] 日誌）；用重起迴圈撐，但上一個沒收乾淨會佔住 9351，新的就一直綁不上埠
4. **「先撈 id 再 `.in()` 回去」是 #1928 型**：幾百個 uuid 進 GET URL 就 414，撈名單又會被 max_rows 截斷。分校範圍一律用 embed（`scope_student:students!inner(enrollments!inner(classes!inner(campus_id)))`）＋`.in(分校)`，URL 只有分校 id。body 帶一批 id 的寫入要分段（`lib/org-scope.ts` 的 `ID_CHUNK`）
5. **harness A7c 只掃字面有 `campus_id` 的路由**：以學生／家長為主體的路由（meals）不在範圍裡，所以授權漏洞一直綠（#2139）
6. **harness 的 API 參數覆蓋 gate 是靜態讀 `params: { … }` 物件字面**：三元式 `campusId ? {…} : {…}` 讀不到，改成 `{ date, ...(campusId ? { campusId } : {}) }`
7. **頂欄分校接法**（#2143 起的共同寫法）：constructor 裡 `use()`、`ReferenceDataService.loadCampuses()`、`toObservable(campusCtx.id).pipe(filter(Boolean))` 觸發載入；第一次載入不再放 `ngOnInit`。spec 用 `{ id: signal('campus-1'), use: vi.fn() }` 替身，換分校後 `TestBed.tick()`
8. **seed 的使用者只有 127 位、家長一人一帳號、c2 不建 ba\_\***：要測「很多家長」湊不到 300 位。改成攔 `fetch` 斷言送出去的 URL 形狀，比靠人數觸發 414 更直接
9. 量測代表列取「最常見的那種」：稿多數已讀、seed 多數未讀，字重差就會出現 —— 判讀前先看兩邊代表列是哪一種狀態
