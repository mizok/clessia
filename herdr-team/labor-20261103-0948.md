## 四、這次學到的

1. **全套測試輸出的第一組是 api、第二組才是 web**（`nx run-many` 先跑 api：248 檔／3033 條）。我前四張 PR 把兩邊標反，事後更正。看數字要對 `nx run <project>:test` 那行，不要看順序猜
2. **wrangler 父行程會把被殺的 workerd 重起**：只殺 port 上的 workerd 沒用，要 `ps -o ppid=` 找到 wrangler 的 node 父行程一起 `kill -9`，再確認 8748／9248 都沒人聽。只殺子行程時會留下一個佔著 port、卻不回應的 workerd（curl 卡住）
3. **PrimeNG overlay 的淡入動畫**：開下拉後馬上截圖，面板看起來像壓在抽屜底下。等 800ms 再拍，或用 `elementFromPoint` 判斷疊層
4. **p-dialog 自訂 `#header` 時，aria-labelledby 的 id 要從 template context 拿**（`let-labelId="ariaLabelledBy"`），寫死 id 會指到不存在的元素；`[closable]="false"` 會連 Esc 一起關掉（`closeOnEscape && closable`）。要 Esc、不要 ×，就保留 closable、用 styleClass 把 × 藏起來
5. PrimeNG 的 Esc／捲動收起都看疊層與 `overlayOptions.listener`；抽屜裡的下拉開著時按 Esc，只會關下拉
