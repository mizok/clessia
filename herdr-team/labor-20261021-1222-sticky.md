## 二、會再撞到的坑

1. **靜態幾何量不到 sticky**：`capture` 把視窗撐到內容全高，什麼都不捲。黏住要看 `diff` 表頭那行「黏住行為檢查：提名 N、一致 M」
   與 `A6_OUT/<頁>/sticky-<d|m>.json` 的逐項結果（`A6`／`APP` 的 `visible`／`natural`／`short`／`at`）。**提名 0 不等於沒差** —— part 沒配上就不會提名。
2. **sticky 會扣掉捲動容器的 padding**：容器有 pb，黏底的東西就浮在離底 pb、底下露內容。#1768（請假）、#1774（form-dialog）都是這個。
   **底部留白要交給黏住的那一列自己撐**，容器 pb 歸 0。
3. **app 頂欄在殼層捲動區外**：稿的 `top: 80px` 含它自己在捲動區裡的 56px 頂欄，照抄會黏在視窗 136px。app 用 24px（token `--spacing-sticky-chapter`）。
   週視圖欄頭稿 top 56 → app top 0。**比 sticky 一律比落點（離視窗邊），不比 CSS 值**。
4. **稿也有 bug**：meals `.savebar` 外面包了只有它自己高的 div，捲動時不會動。工具會列「稿宣告了 sticky 但沒黏住」，裁定後登記偏離。
5. **PrimeNG 動態彈窗不吃 Escape**：遮罩會擋住後面每一次點擊。工具 `closePop` 已改成點根裡的取消／關閉；手寫 Playwright 腳本也要這樣關。
   Playwright 選擇器**不要把 `>> visible=true` 放進逗號串**，解析會錯 —— 用 `locator(root).locator('a, b').filter({ visible: true })`。
6. **PrimeNG 的遮罩 `align-items` 與彈窗 `width` 是 inline style**，全站覆寫只能 `!important`（同 `roster-sheet`）。
7. **Angular inline template 的註解裡不能有反引號**（會截斷 template 字串，編譯錯得很遠）。prettier 換行後會把反引號拆到下一行，再檢查一次。
8. **兩張各自綠的 PR 合起來可能讓 main 紅**（#1773 型別加必填欄位 × #1753 spec 手寫替身，main verify 連紅、deploy 被 skip，#1790 修）。
   merge main 後自己的 CI 紅在別人的檔：先查 main 的 verify，**修之前問計畫席有沒有人已經在修**（本席與 #1790 撞單，開了重複的 #1791 後關掉）。
9. **squash 合的上游 → 下游 merge main 必衝突**（add/add 或內容衝突）。上游檔一律取 main，自己加的東西再補回；merge 完確認相對 main 只剩自己的檔。
10. **在跑 API（wrangler）的 worktree 裡切分支會讓 wrangler 熱重載掛掉**（錯誤訊息是空的）。量測用的 web／api 起在一個不切分支的 worktree，
    修正放另一個 worktree（node_modules 用 symlink 借：根目錄與 `apps/api/node_modules` 兩層都要，**借本席 worktree 的，不要借主 checkout 的** —— 主 checkout 的缺 `@tailwindcss/postcss`）。
11. **jsdom 不套 Tailwind／全域樣式**：拿掉 sticky 畫面照樣對。守法是讀原文（`skeleton-shimmer.spec` 慣例）：`chapter-sticky.spec`、
    `form-dialog-footer.spec`、`dialog-geometry.spec`。審核席會做突變，**每一處都要有斷言**（#1766 被退在「元件守了、頁面沒守」）。
12. **多身分帳號會被導到 /select-role**：老師 state 要在 `origins` 補 `localStorage clessia:active-role=teacher`，**compare 用的 4310–4319 port 也要補**。
