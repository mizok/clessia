## 一、突變驗證這輪翻車三次——用腳本，不要用 shell 迴圈

- **zsh 不拆變數**：`F="a b c"; for f in $F` 是**一個**字串，`cp` 備份整串失敗、突變卻已經 `sed` 進檔案，**還原那步又失敗**（#1551）。多檔突變一律寫 Python：`orig=open(p).read(); try: open(p,'w').write(fn(orig)); 跑測試 finally: open(p,'w').write(orig)`，**逐項單獨跑**，每項印「有沒有真的改到」（`new==orig` 就報沒改到）。形狀是 `muts=[(名稱, 路徑, lambda s: s.replace(舊, 新, 1))]` 逐項迴圈、`subprocess.run` 跑 `nx test`（單檔 glob 要引號、`NO_COLOR=1`），**跑完 `git status --short` 確認只剩 spec**。
- **反向 `sed` 還原會誤傷**：我用 `s/[label]="second.label"/…mobileLabel…/` 還原，同一個檔案裡另一行（標頭用的）也被改——被 spec 抓到才發現。**還原用備份，不要用反向 sed**。
- **兩個互相抵消的突變一起下會假綠**：`[subLarge]="!!campusName()"` 與 `page-open` 內 `subLarge()` 同時反相，兩個方向的測試都沒紅。**同一條因果鏈上一次只突一處。**
- **門檻要有「門檻值與±1」的 fixture**（reviewer 這週抓了第四次）：到班句 `<= 3`（3／4／5 天）、班數（1／2）、滿分 100（99／100／101）、「今天／明天／後天」（用固定的假時鐘 `2026-04-10`，後天＝`04-12`）。**新增的每個輸入／分支，主／次×手機／桌機四個方向各要有斷言**（page-actions 的 `mobileLabel` 被擋過：只測了次要）。
- **模板裡重複一份門檻，spec 守不到**：hero 的「滿分不是 100 寫 `／50 分`」原本在模板與 util 各一份——抽成 `examUnitText`，邊界只在一處。

- **篩選有兩種稿，別混**：學生／帳單／家長三頁是「篩選：全部」鈕＋浮層（#1546）；**報名進出、請假（全部分頁）是常開的灰色圓角面板、欄位帶標籤**（`.ff`），手機用「篩選　全部 ∨」摺疊列（報名進出）或兩欄各一列。要用哪種**看那一頁的稿**。面板做法：`-mx-4 wide:mx-0 wide:rounded-lg bg-zinc-100 p-4 grid`，摺疊用現成 `filtersOpen` signal＋`wide:hidden` 按鈕＋面板 `wide:grid` 蓋掉 `hidden`——**只有一個呼叫端不抽元件**；`student-fold` 的外觀（灰底摘要列＋白底內容、`<h2>`）跟稿的摺疊列不同，**沒重用**。c5 只擋角色 feature 之間（`features/admin/**` 內互引可以，constitution.md:81-86）。

## 四、spec 的幾個寫法

- **Popover 的外點擊在 jsdom 測不到，但 `Popover.hide()` 會發 `onHide`**：`fixture.debugElement.query(By.directive(Popover)).injector.get(Popover).hide()`；頁上有多個 Popover（帳單的匯出）時用 `.queryAll(...).find((p) => p.overlayVisible)`。
- **斷點類互斥要斷言 class**：投影鈕「只在桌機」靠 `hidden` ＋ `min-[640.02px]:inline-flex`，jsdom 沒有 media query，**斷言兩個 class 都在**（拿掉斷點 class 才會紅）。`min-[640.02px]` 是 `page-actions` 托盤的斷點，**不是 `wide:`（861px）**。
- **spec 起始狀態不一定是「還沒載到」**：`beforeEach` 往往已 `ngOnInit`。測「兩個數字都沒到→退回頁名」要自己 `signal.set(null)` 起頭。

## 五、流程

- **範圍說明 gate 不能跳**：#1548 我先寫碼再開 PR，被計畫席指出。每件先貼差異清單＋範圍說明、等「過」。**gate 通常會把「要裁的事」改裁**（這輪：登記請假白底框改成「另開一支先查各頁稿」、手機篩選改裁照稿做摺疊列、托盤標籤改裁照稿縮短加 `mobileLabel`）——**先備好兩條路的成本，不要押單邊**。
- **稿標「新」的是應然規格、不是產品現況**（直接報名、列尾「⋯」、課堂清單、年級、批次請假、管道欄）：寫差異清單時先看稿的 `<template id="notes">` 的「規格 vs 現況」表，**別把「新」當成漏做**。保留類（寫入路徑）不碰。
- 二讀擋過的點可以預期：邊界缺 fixture、模板裡有而 spec 沒斷言的 class、新輸入只測一個方向。**交 PR 前先自己問一次這三件**。
