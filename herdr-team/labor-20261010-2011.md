## 二、設計決定（下一個做同類頁會再問）

- **一則聯絡簿屬於學生不屬於班**（`UNIQUE(student_id, entry_date)`）。要做「一班一列」只能以 `classes[0]` 分組，同生跨班只出現一次；列兩次會讓人以為有兩件事。
- **`signedBy` 是 `ba_user.id`**，API 沒有姓名 —— A6 的「王媽媽 20:15 簽」只能做到時間。`/missing` 也不回帶班老師、不回班級總人數 → 「游佩珊 老師」「還差 4／17」「○○班 都寫了」「提醒老師補寫」都是缺 API，不是前端能補的。凡 A6 稿上這類「看起來是文字」的東西，先查 API 回什麼。
- **日段用原生 `<details [open]="…">`**，開合狀態由瀏覽器管；`[open]` 綁定值**不變**時不會把使用者按開的又蓋回去，只有值改變（例如進入篩選）才重設。要測就讀 `HTMLDetailsElement.open`，不必模擬點擊。
- 日期下拉的選項（`missingDayOptions`）：最近 7 天的上課日＋今天（週末的今天也要能選），最後一項「其他日期…」＝只換出 datepicker、**不立即查**，等使用者挑了才查。用 `app-select-field`，value 是日期字串或 `'other'`。
- 日期區間的 `p-datepicker` 在灰底盒裡預設寬度太窄，「2026-10-04 - 2026-10-10」會被截字 —— 要 `wide:w-[300px]`（手機 `w-full`）。截圖時才看得到，spec 抓不到。

## 三、測試的坑

- **spec 要渲染出帶 `routerLink` 的 `<a>` 就必須 `provideRouter([])`**，否則 NG0201 `ActivatedRoute`（1910 §三講過，這次在「換 AuthService 重建 TestBed」的情境又踩一次）。
- 要測「權限不同 → 連結出不出現」：`TestBed.resetTestingModule()` 後用 `{ provide: AuthService, useValue: { hasPermission: (p) => p === 'manage_finance' } }` 各建一次。**欄位初始化時 `inject(AuthService).hasPermission(...)` 只讀一次**，改權限要重建元件，不是改 mock 回傳值。
- **只有負向 spec 的防護等於沒防護**：#1514 的 `canOpenInvoices` 只有「沒權限時不出現」，把權限字串改成 `view_reports` 全綠。補正向後**真的改一次來突變驗證**，再 `git checkout` 還原。
- 突變驗證這輪做了三次（分班取最後一班、篩選不展開、權限字串）—— 每次都先備份或用 `git checkout` 還原，再跑一次確認回綠。
