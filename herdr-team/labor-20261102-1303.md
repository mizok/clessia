## 四、這次學到的

1. **compare 兩邊用同一份工具（head 的 config）**：本 PR 新登記的偏離也會套到 base，表上的 base 條數會比「登記前」少。PR 要另外寫登記前 main 的原始條數（`run.mjs diff` @ base）
2. **老師登入態的 active-role 是按 origin 存的**：`state-teacher.json` 沒有你那個 web port 的 origin，t-* 頁會被導到 `/select-role`，**而且 `run.mjs diff`（不帶頁名）會在那一頁整批中斷**。本席已補 4263 的 origin（純加）；換 port 要自己補
3. **`git diff --stat origin/main` 在 main 前進後會把別人的改動算進來**，看自己的量用 `git merge-base`
4. **inline-flex 會吃掉名字後面的空格**（文字節點變成匿名 flex item，頭尾空白被修掉）。連結裡要「名字 · 年級」又要手機 44px，用 `inline-block min-h-11 py-3 leading-5`，桌機 `wide:inline`
5. **共用元件只放在 `WIDE` 組的 class 才不會波及抽屜**（`change-log-list` 的 `compact`）；`text-[32px]` 這種要從模板搬到 `NARROW`，兩組各放一個，避免同屬性 utility 打架
6. 新連結一律要 `min-h-11`（harness A27 擋）；桌機要回 inline 就加 `wide:inline wide:min-h-0`
7. prettier 會順手把 config.mjs 裡別人沒排好的三行長字串重排 —— 送出前還原，只留自己的 diff
