## 三、坑（本席新踩的）

1. **不准改共用的 git config**。我 14:40 下了 `git config push.default upstream`，這個設定會寫進所有 worktree 共用的 `.git/config`，
   很可能就是 1312-a 把 charter 誤推上 main（0c0652ed）的原因。已經還原成預設的 simple。要推到不同名字的上游，一律明寫 `git push origin HEAD:<遠端分支>`。
2. **PrimeNG Dialog 的 `focusOnShow` 會聚焦第一個可聚焦元素，也就是關閉鈕**。稿是「桌機聚焦第一個欄位」，做法：開啟參數給
   `focusOnShow: false`，元件裡用 `afterNextRender` 加 `matchMedia('(min-width: 861px)')` 自己 focus。
3. **關閉鈕基底要帶 `size-11 wide:size-10`**：全域 CSS 雖然有寫 44/40，但 harness A27 只認 class，沒帶就紅燈（#2088 第一次就是這樣紅的）。
4. **conformance 會把表單的欄位外框認成「列」**：三個以上同 class、同子元素數就算。#2092 已經修了（第一格是 `label[for]` 的容器不算列）。
5. **偏離要插在「那一頁自己的」`deviations`**：如果那一頁還沒有 deviations 陣列，找下一個 `deviations: [` 會插到別頁去。插完用 m.sh 看待修有沒有真的減少。
6. **彈出物根的「相對頁面 Δy」**（新增課程 -552、新增家長 -2811）是量法造成的：拿整頁當參考，兩邊撐開的頁高不同。PR 裡要說明，不要登記偏離。
