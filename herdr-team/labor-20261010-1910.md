## 二、會騙人的東西（實測踩到）

- **Angular 的 `[class.ring-[1.5px]]` 這種帶括號、小數點的 class 綁定靜默失效**（pill 的黑框消失，沒有任何錯誤）。要依狀態換 Tailwind class，寫成 TS 裡的 `Record<kind, '完整 class 字串'>` 再 `[class]="MAP[kind]"`；字串在 `@source` 目錄內，Tailwind 才掃得到。
- **多檔改動途中 dev server 留下舊錯誤遮罩**（`vite-error-overlay intercepts pointer events`，截圖上是已修掉的錯）。先 `for p in $(lsof -ti tcp:4200); do echo $p $(lsof -a -p $p -d cwd -Fn); done` 確認 cwd 是自己的 worktree 才 kill，再 `npx nx serve web`。這一輪遇到三次。
- **示範庫家長全沒有電話**，儀表板的「打電話」因此不會出現。補電話走 `PUT /api/parents/:id {phone}`——**回應的 `phone`／`email` 是從 row 對的、永遠看起來是 null，不能拿來驗**；要驗用 `GET /api/students/:id` 的 `parents[]`。**電話有唯一限制，重複時 PUT 仍回 200 但沒寫進去**（我先打到同名的另一位家長，才發現第二次「成功」其實是空的）。
- **示範庫的待處理請假只有 1 筆、公告 0 則、近 30 天報名 1 筆**：要看多章就用 API 建（`POST /api/leaves`）或選「不限期間」；建完用 UI 的取消流程清掉。`db:reset` 還原。
- `login-link.ts` 要帶 `WEB_URL=http://localhost:4200`，否則回「缺少環境變數」；舊的 `state-admin.json` 在 `db:reset` 後會 401。

## 三、測試與 gate 的坑

- **「拿掉防護仍全綠」要用突變驗**：reviewer 抓到儀表板 `recordCall` 的 `boardBusy` 防護沒有測試守。補測後**真的把那一行刪掉跑一次，確認它紅**再還原（#1509）。凡是「防止重複送出」的 guard，測試要用一個**不回應的 Subject** 連按三次。
- 元件用了 `RouterLink`，spec 必須 `provideRouter([])`；原本用 `{ provide: Router, useValue: { navigate } }` 的要改成 `vi.spyOn(TestBed.inject(Router), 'navigate')`，否則 NG0201 `ActivatedRoute`。
- 新增 list 端點的 query 參數要三處一起：**web service 原始碼出現該參數名**（api-param-coverage）、**`contract/list-endpoints.contract.ts` 的 `BRANCHES` 補一條**、`npm run test:contract` 跑完用 `grep "GET /api/<路徑>"` 確認新分支**真的被打到**（只看綠燈不夠）。
- harness A27：可點的 `<a>` 要靜態的 `min-h-11`（`inline-flex items-center`）；大列裡的學生名連結也算。
- `p-confirmdialog` 的 message 裡的 `\n` 預設被收成一行，要 `styleClass="whitespace-pre-line"` 才分行。
- `student-autocomplete` 的 `valueChange`：打字中是**字串**、選到才是 `Student`，清空是 `null`／空字串。要把它當「篩選」用，只在拿到物件時才帶 `studentId`（其餘都退回不篩）。

## 四、判斷依據（下一個做同類頁會再問）

- **A6 稿與全站慣例衝突時，慣例贏並在 PR 寫明**：公告時間稿用斜線，repo 有 #425 M4「完整日期一律連字號」且 spec 釘著 → 維持連字號。
- **稿上的分頁／按鈕若對應另案功能（收件匣＝#1023、批次請假、直接報名），整個不放**，不要放一個只有一個選項的分頁列。
- **數字句要的是篩選結果的聚合時，列表 API 沒有就不做**（報名頁 Hero 計數→#1507），不要拿目前這一頁的數字充當。
- **「只在某狀態才有的欄位」不編造**：報名列的經手人只有新報名有 `createdByName`，其他列不寫。
- 請假頁：`GET /leaves` 的 `dateFrom`／`dateTo` 比的是起日／迄日各自一端（`start_date >=`、`end_date <=`），**不是區間交集**；「還沒結束」用 `endFrom`。補請不是欄位，`createdAt` 的台北日期晚於 `startDate` 即是。取消請假確認文案以 rules §6–7 為準（已點名的日子不動），不是「恢復出勤狀態」。
- 台北日期一律 `taipeiDateString()`；分章／分月用它切，別用瀏覽器本地時區。
