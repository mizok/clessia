## 三、分章 × 伺服器分頁（家長頁，#1396）

列表是伺服器分頁時，**前端只能在一頁內分章**，所以後端要先依分章鍵排序（`order('status')`，enum 宣告序）章才會翻頁連續；章名人數用 `summary`（全量）；**搜尋中章名不顯示 summary 人數**（summary 不受搜尋影響會騙人），改顯示 `meta.total`。章頭用表格裡的一整列（`<th colspan="99" scope="colgroup">`），保留 `app-responsive-table` 的分頁與手機收合。後端排序那一行的 spec 要**拿掉 `order('status')` 看它紅**（stub 的 `order` 要改成會記錄欄位順序，原本是空函式）。

## 四、`<dialog>` 做抽屜／面板（#1415）與 jsdom

- 這個 repo 的面板慣例是**原生 `<dialog>` + `showModal()`**（`schedule-quick-sheet`、`score-entry`）：Esc、focus trap、背景 inert 由瀏覽器給。**jsdom 沒有 `showModal`**：spec 在 `beforeEach` 補 `showModal`（`open = true`）與 `close`（`open = false` ＋ `dispatchEvent(new Event('close'))`），`afterEach` 還原——**close 事件要補**，元件靠它回報 `closed`。
- **開關只由網址 fragment 決定**：`route.fragment` 訂閱 → signal；分享、重新整理、返回鍵自然成立。要分「點入口 push 過一筆」與「直接帶 hash 進來」兩種關閉法（前者 `location.back()`，後者 `navigate([], {fragment: undefined, replaceUrl: true})`），因為後者用返回會離開頁面。這兩路各一條 spec，**瀏覽器實測要驗 history 長度與 `p.url()`**。
- 既有頁面 spec 的 `ActivatedRoute` 是手寫 `useValue`：新增讀 `route.fragment` 之後**每個 mock 都要補 `fragment`**（兩處），否則在建構式就炸。
- 共用元件要同時放進「桌機整頁」與「480px 抽屜」時，**`wide:`（視窗斷點）不能用**：抽屜在桌機也只有 480px。做法＝`compact` input 切換整組 class 常數（完整字面量，Tailwind 掃得到），預設值＝原樣，畫面不變用前後計算樣式傾印證。

- **hash 抽屜的三種進入／離開路徑，瀏覽器實測各驗一次**（`.pw-regression` 腳本形狀）：①點入口（`history.length` +1、`location.hash==='#changes'`）→ Esc／×／背景關 → hash 拿掉；②開著按瀏覽器返回 → 關；③直接 `goto('/…#changes')` → 開，× 關後 `p.url()` 仍在原頁。再加：`dialog.getBoundingClientRect()`（桌機 `[960,0,480,900]`、手機全螢幕）、`dialog.contains(document.activeElement)`、連按 14 次 Tab 仍在內（focus trap）。
- **畫面不變的搬家用「計算樣式傾印」三個寬度**（1440／641／360）：每個寬度對 `main section/details/summary/li/span/p` 傾印 15 個屬性＋寬高，存 JSON 逐筆比；只許 `textContent` 空白類差異（傾印的 slice 含文字，模板重排會讓它不同，不是渲染差異——要看是不是只有字串不同）。

## 七、會動的元件（跑馬燈 #1417）

- **`@theme` 裡的 `--animate-*` 不能放 `var(--自訂屬性, 預設)` 當時長**：theme 變數在 `:root` 解析，元素上設的 `--ticker-duration` 讀不到，**永遠是預設值**（我的實測：手機 574px 跑 14px/s 而不是 32）。做法：theme 只放固定時長，元素上用 `[animation-duration:var(--x,40s)]` 覆寫。**預設值剛好等於量到的值時看不出來**（桌機 1270px÷32≈40s 恰好一樣）——驗時長要用兩個不同寬度。
- **量位移的形狀**（Playwright）：同一元素 `getBoundingClientRect().left` 間隔 1 秒取兩次，差＝px/s；`getComputedStyle` 看 `animationName／Duration／PlayState`；hover 暫停要 `hover({ force: true })`——會動的元素 Playwright 判「not stable」，一般 `hover()`／`click()` 會逾時；點擊同樣用 `click({ force: true })`。reduced-motion 用 `newContext({ reducedMotion: 'reduce' })` 另跑一遍，位移應為 0。
- **「無障礙停得下來」要三件都在**：動畫只掛 `motion-safe:`、`hover:` 與 `focus-within:` 暫停（`[animation-play-state:paused]`）、`motion-reduce:` 時不動且可橫捲。jsdom 量不到動畫，spec 只能斷言這幾個 class 字串都在——拿掉任一個就紅。
- **跨元件「切到那天 → 捲到那塊 → 開選單」**：等的是資料載入完的 signal（`loading()` 變 false）再 `afterNextRender` 找元素（`data-session-menu`）`scrollIntoView` ＋ `click()`，不要猜時間；找不到就靜靜不做（該堂被篩選擋住）——這是沒處理的邊界，PR 有寫。
