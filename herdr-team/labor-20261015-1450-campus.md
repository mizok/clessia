## 一、conformance 工具（`tools/a6-conformance`）實際怎麼跑

- **工具住在 `labor-20261014-1725-a6tool` 的 worktree**，不在 main。用絕對路徑跑 `node <那席>/tools/a6-conformance/run.mjs`，
  `A6_DIR` 給**絕對路徑**（稿從 reviewer worktree 複製到自己的 `.design-explorations/`，那個目錄**沒被 gitignore**，`git add` 只加指名路徑）。
  `A6_STATE`、`A6_OUT` 指到自己的 scratchpad，不要寫進別席的 `~/.cache` 預設值。
- **`compare` 自己起 web 時會逾時**（dev build 慢，它等不到就放棄，但 web 其實有起來）。改用 `--base-url/--head-url`：
  base 自己開 `git worktree add --detach <scratchpad>/base-wt <sha>`、`ln -s <自己的 worktree>/node_modules`、`nx serve web --port 4311`；
  **量完 `git worktree remove --force`**。工具自己留下的 `~/.cache/.../wt/<sha>` 是它的，失敗時那支才是你的要收。
- **「head 新增的待修」不等於退步**：part key 是結構路徑。`<nav aria-label>` 改成 `div`、`<b>` 裡多包一層 `span`，key 一變就整批算「新增」。
  先用 JSON 的 `parts[].box` **取絕對座標**比對（寫個小 `pos.py`），再下結論。
- **相對 main 的 Δy +147（1440）／+113～+175（360）是假差**：app 的 `main` 包住色面（全站 #1591），稿沒有。
- **工具量不到暫時出現的東西**（toast、打開後才有的列）：借它裝好的 Playwright（`<工具>/node_modules/playwright/index.mjs`）寫拋棄式腳本，
  **稿與 app 用同一段 `getComputedStyle` 量**。觸發 toast 用 dev 模式的 `ng.getComponent(el).messages.add(...)`＋`ng.applyChanges(el)`。
- **behave 的「捲動：A6 有、app 沒有」先看頁面能不能捲**：示範庫只有 2 堂，`scrollHeight === clientHeight`。把視窗調矮（500）再驗。
- **量正式站**：`A6_APP_URL=A6_API_URL=https://demo.clessia.cc`（API 同網域），登入態要使用者同意才借（效能席 `~/.cache/clessia-perf/state.json`），
  複製到自己的 scratchpad 再用。正式站那天沒課就只能證明工具列，回報要寫限度。
- **並排圖**：系統 Python 沒有 PIL。寫個 `side.html`（兩張 `<img>` 並排）用 Playwright `goto(file://…)` 截圖；`setContent` 讀不到 `file://` 圖。

## 二、Tailwind／harness 的坑

- **新元件目錄要登記 `@source`**（`apps/web/src/tailwind.css`）：沒登記的話**任意值 class 不會產生**，而且不報錯 ——
  toast 第一次量出來在左上角、陰影 `none`，就是 `[inset:…]`、`shadow-[…]` 都沒生成。加完要 `npm run harness:write`（掃描範圍變了）。
- **可點的 `<button>` 基底要 ≥44px**，桌機照稿再 `wide:` 縮（`min-h-11 wide:h-8 wide:min-h-0`）。A6 的 32px、40px 鈕都這樣處理。
- **對比門檻 4.5**：`zinc-500` 疊在 `zinc-100` 上 4.44 會被擋，升 `zinc-600`（工具 config 已登記這條偏離）。
- **`[class.xxx:yyy]`、`[class.duration-[140ms]]` 這種帶冒號或中括號的 class 綁定別用**：改用狀態屬性＋變體
  （`aria-pressed:bg-zinc-900`、`[attr.data-leaving]` 配 `data-leaving:opacity-0`）。
- **`display:none` 的 grid 子項不佔格子**：手機把第一欄 `hidden` 之後，三欄 grid 的內容全部往前移一欄（課表手機清單的 ⋯ 跑到班名旁邊）。
  手機兩欄、桌機 `wide:` 三欄。
- **flex 換行用的 0 高元素（`basis-full`）會多吃一次 row-gap**：手機改 `gap-y-0`，第二列的項目各自 `mt-2`。
- **要把同一組元素在手機拆到兩列**：外層 `max-wide:contents`，子項各自 `max-wide:order-*`。
- **窄格放不下日期**（360 寬一格約 38px，「10/12」會黏到隔壁）：手機只在第一格與跨月寫「月/日」；
  要保持 part 結構就用**兩個兄弟 `<b>`**（`wide:hidden`／`max-wide:hidden`），不要在 `<b>` 裡包 span。

## 三、Angular／PrimeNG 的坑

- **root 單例不要 inject 會在建構時發請求的服務**：`CampusContextService` 一 inject `AuthService`，每個接了頂欄的頁（含 spec）都多打一支
  `/api/me`，22 支 spec 紅成「Expected no open requests」。反過來：AuthService 讀到 `/me` 之後推值（`setAssigned`）。
- **元件層 `providers: [MessageService]` 會把訊息困在那一層**：全站出口收不到。spec 裡用 `overrideComponent(set providers: [MessageService…])`
  也是同一件事 —— 改成全站出口後，這種 spec 會擋住「出口收得到」的斷言，要拿掉。
- **PrimeNG Select 的 placeholder 要靠 `[placeholder]`**，無障礙名稱照 `ariaLabelledBy`（不會帶 `…`）；
  behave 會報 app 多一個「dropdown trigger」，那是下拉箭頭的 aria-label，屬原生 `<select>`／combobox 的結構差。
- **localStorage 在 spec 之間會漏**：新增 key（如 `clessia.campusContext.single`）要把**每支**有清舊 key 的 spec 都補上。

## 四、流程

- **只格式化自己改的檔**：`prettier --write apps/web/src/app/core/*.ts` 會順手改到別人的檔。用 `$(git diff --name-only)`＋新檔名。
- **prettier 會把長屬性折行**，之後用 sed 單行比對會落空 —— 改完 `grep` 確認，或用 Python 讀整檔替換並 `assert`。
- **審核席的突變**是找你的 spec 有沒有守住；補 spec 一律附「突變後轉紅、還原後綠、原始檔無 diff」三句。
- **計畫席說「工單貼範圍等過」時，回報用 issue 留言＋herdr 一句摘要**；gate 留言可能和你的提案不同（toast 的兩行／一行），以留言為準。

## 五、保留類（授權／個資）的做法（#1625）

- **授權跟著資源走**：家長個資要放進帳單回應，就放在**單張**端點、**在範圍判斷之後**才讀（`findScopedInvoice` 之後）。
  列表不帶 —— 一次幾百張不該順便帶出幾百位家長。spec 同時守「範圍外 404 拿不到」與「列表沒有那個欄位」。
- **gate 要的突變要真的跑**：把範圍判斷那一行換成 `return row;`，範圍外那條要轉紅；還原後全綠，寫進 PR。
- **抽 helper 證明「行為逐字不變」**：先查既有 spec 有沒有守到那段（學生詳情的家長清單**沒有**）。沒有就補一支描述現況的 spec，
  用 `git show origin/main:<檔> > <檔>` 換回舊版跑一次、再換回新版跑一次，兩邊都綠才算。
- **`ba_user` 是家長電話／email 的真身**（`parents` 的欄位在 unified login 拿掉了），只讀（c2）。只留電話的家長，
  email 是系統產的 placeholder（`<電話>@<PLACEHOLDER_EMAIL_DOMAIN>`）要當成沒有；env 缺席時用 `generatePlaceholderEmail` 同一個預設網域。
- **`createMultiOrgDb` 不解析 select 的 embed**：資料列直接帶嵌套欄位（`parents: {…}`、`scope_items: […]`）。
  路由多查一張表，其他 spec 的種子沒有那張表也不會壞，但 `c.env` 在沒傳 env 的 spec 裡是 undefined。
- **sms 連結**：計畫席要先試 `sms:<號碼>?&body=<encode>` 兩邊通吃，不判 UA；實機驗證要排在部署後請使用者點。
