## 一、實機才抓得到、spec 與 CI 全綠也抓不到的兩個 bug

- **重用別頁的 dialog 要查它 `inject()` 了什麼。** 學生檔案的帳單章直接開 `payments` 的 `InvoiceDetailDialogComponent`，spec 把 `DialogService` mock 掉所以全綠；實機開 dialog 丟 `NG0201: No provider for MessageService`，畫面只剩一條白條。payments 頁自己 `providers: [MessageService, DialogService]` 還有 `<p-toast>`，學生檔案頁沒有。做法：**要開別頁的 dialog，就把那頁的 providers 與 toast 一起帶**，並補一條 `fixture.debugElement.injector.get(MessageService)` 的 spec 釘住。
- **後端新增 `order('subjects(sort_order)')` 但 embed 只選 `subjects(name)`** → 真 PostgREST 回 400（`column courses_subjects_1.sort_order does not exist`），#1423 合進 main 後課程頁整頁「載入失敗」。後端 spec 的 stub 看不出來。**後端新增排序／篩選一律實機打一次**；前端做章節前先 `curl`／`page.on('response')` 看 200。這一輪是前端實機拍照時抓到的，已有 #1430、#1436 補。

## 二、驗證的假陽性

- `p.getByText('作廢').count() > 0` 會被「作廢／列印收費單」那顆**按鈕**命中，我一度誤判 dialog 已開。**驗 dialog 開了要找元素**（`app-invoice-detail-dialog` 的 count、或 dialog 內獨有的字），不要找可能同時在觸發鈕上的字。
- 動態編譯錯誤會讓 vite 蓋一層 `vite-error-overlay`，Playwright 的點擊被它擋住（「intercepts pointer events」）。**多檔改動中途截圖就會撞到**：改完等 web.log 沒有新 ERROR 再拍，不要把這當成頁面壞了。
- 重跑截圖腳本前，`sed 's/\x1b\[[0-9;]*m//g' $TMPDIR/web.log | grep -c ERROR` 看一次。

## 三、分章 × 一次拿全部（人員）與 × 伺服器分頁（課程）

- **資料量小就用 `pageSize=0` 前端分章**（人員頁，#1424）：章永遠在（A6 在篩選下也是分章），不需要 1507 帳單頁的「無篩選才分章」雙模式；章名張數讀後端 `summary.byRole`（它**走同一組篩選**，所以搜尋時章名也對）；沒有列的章不顯示。**上限註記**：`pageSize=0` 沒有 max_rows 保護，超過 1000 會被靜默截斷（`ponytail:`）。
- **章名張數的來源要跟列表同一組篩選**（課程，#1431）：`summary.bySubject` 一開始不吃 `isActive`／`search`，預設畫面（只列啟用）章名會比底下列的多（國文 8 門、列出 6 門）。**先拿「預設畫面」跟「搜尋中」兩個情境對 API 計數**，不對就先請後端改，別在前端扣。後端在 #1428 補了，實機 `search=國` 時各科 23／2／2／1 合計＝`meta.total`。
- **前端在頁內再濾的條件（老師篩選）會讓 API 的章名數字對不上**：這時不顯示張數，不要編。需介入模式（全量）直接數手上的群組。
- 課程頁的章排序：連續同 `subjectId` 歸一章（後端先依科目排序），換頁時章可能在頁首接續，章名照寫。

## 四、搜尋框（`shared/components/search-field`）

- **中文輸入法：`isComposing` 時不送、`compositionend` 才送**，再 debounce 300ms；跟目前生效的查詢相同不發；**外部清除篩選時，輸入框要跟著清**（`value` input 綁到 `<input [value]>`）。既有的 `ime-filter-input` 是 PrimeNG 外觀、沒有外部 `value`，A6 的 44px 欄位另寫了這個。
- 搜尋只影響列表，**不影響頁首的「這個月 N 則」**（它回答的是另一個問題）；清除篩選要連搜尋一起清。
- 元件 spec 用假時鐘時，收尾要 `if (!alreadyFake) vi.useRealTimers()`（1507 §五；`test:timetravel` 會把時鐘推到未來，無條件還原會污染後面的測試）。

## 六、gh 與作業小坑

- `gh issue comment --body-file "$TMPDIR/x.md"` **用絕對路徑**；我一次用 `cd $TMPDIR` 加相對檔名，輸出被「Shell cwd was reset」吃掉、看不到 URL、事後 `grep -c` 才發現沒貼（貼文要看回傳的 URL，沒有就是沒貼）。三則一起貼之前先 `ls` 確認、貼完 `gh issue view --comments | grep -c <關鍵字>` 數一次，免得重貼成雙份。
- 計畫席訊息說「main 還沒有 X」時，**先 `git show origin/main:<path> | grep` 驗**再回；這一輪它講的是舊狀態，我拿 `merge-base --is-ancestor` 當證據更正，沒有多做一次 merge。
- 一次改 service 簽名、元件還沒改完的中途，web dev server 會編譯錯誤並蓋遮罩；**同一個指令裡改完兩邊**，或兩邊都改完再存。
