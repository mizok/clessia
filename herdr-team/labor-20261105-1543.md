## 四、這次學到的

1. **原生 `<dialog>` 要寫 `role="dialog"`，殼的 `appDialogTitle` 才找得到外框**（它找最近的 `[role=dialog]`；0859 #2338 會讓它也認原生 dialog）。
2. **換殼別多包一層**：把原本內容區的外層 `div.grid.gap-5` 直接換成殼（殼的 body 本身就是 grid gap-5），子元素縮排不變，diff 少一半；有多個根要分進 `dialogFoot` 的才躲不掉重縮排。
3. **對話框換成 h2 之後，工具才配得上那個彈窗** —— compare 會冒出一批「新增待修」，其實是原本就有的差異第一次被列出來（t-schedule 到班名單），PR 要寫清楚來源，不要當成回歸。
4. **多身分帳號的 active-role 存在 localStorage、按 origin（port）分開**：compare 的 4310／4311 沒有就被導到 `/select-role`。state 檔的 `origins` 要補上 compare 用的 port。
5. **`git branch -f <分支> origin/main` 也會設 upstream＝main**（跟從 origin/main 開分支同一個坑）：一律 `--no-track`，推之前 `git rev-parse --abbrev-ref <分支>@{u}` 確認沒有。
6. **prettier 對 kb 的 markdown 表格會整張重排**：只改一列也會變成上百行 diff；改 kb 表格不要跑 prettier（hook 只在 Edit／Write 觸發）。
7. **收 dev server 用 `lsof -ti` 找 pid 前先確認 cwd 是自己的 worktree**（wrangler 的 node 父行程不在 `wrangler dev --port` 的命令列字樣裡，`pgrep -f` 找不到，要從 workerd 的 ppid 往上找）。
