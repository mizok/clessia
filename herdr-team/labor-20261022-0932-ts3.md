## 二、會再撞到的坑

0. **訊息裡的值要先查到再寫**：不要把「查 sha」跟「送訊息」放在同一批平行呼叫，會送出猜的值（本席退場的直接原因）。

2. **組列規則放純函式 lib**（`lib/parent-attendance-days.ts`、`lib/session-arrivals.ts`），不變式（每筆紀錄恰好一次、列都在窗內）在 lib spec 釘；路由 spec 用 `createMultiOrgDb`（真的照條件過濾）。固定回列的替身驗不出查詢條件，審核席一定會跑突變。
3. **審核席的突變清單**：每個存活突變補一支「拿掉它會紅」的 spec，並自己套回去跑一次確認（`python3` 換字串→跑 vitest→還原）。select 字串類用「替身記下送出的 select」斷言。
4. **新 GET 端點**：`list-endpoints.contract.ts` 的 REQUIRED 表要登記必填 query；harness `api-param-coverage.mjs` 前綴碰撞要加豁免。本機跑：`cd apps/api && eval "$(npx supabase status -o env | grep -E '^(API_URL|SERVICE_ROLE_KEY|DB_URL)=')" && SUPABASE_URL=$API_URL SUPABASE_SERVICE_ROLE_KEY=$SERVICE_ROLE_KEY DATABASE_URL=$DB_URL npx vitest run --config vitest.contract.config.mts`。
5. **家長端時間**：一律 `SystemClockService`＋`taipeiWallClock`（已搬到 `core/system-clock.service.ts`），不用 `new Date()`／`todayLocal()`。spec 用固定假時鐘、日期相對它。
6. **`<button>` 不繼承字型**（13.33px、line-height normal）：Tailwind 按鈕要 `[font:inherit]`。
7. **zsh**：`$B:a` 會被當修飾符，變數接冒號要寫 `"${B}:path"`；`--include` 的 glob 要加引號。
8. **`ba_user.id` 是 text**（Better Auth 的 id 不是 uuid）：記錄執行人的欄位一律 `text REFERENCES public.ba_user(id) ON DELETE SET NULL`（#1827 計畫席抓到）。
9. **新路由／新表要登記**：`mount-authz.spec.ts` 的掛載表、`lib/org-scope.ts` 的 `OrgTable`、`list-endpoints.contract.ts` 的 REQUIRED（GET 有必填 query 時）、`audit_logs` 的 resource_type CHECK＋`utils/audit.ts` union（兩份清單一起改）。
10. **compare 工具**：新頁要先在 `tools/a6-conformance/lib/config.mjs` 的 `PAGES` 加設定；登入帳號本週沒資料時量不到改動，PR 要寫明，並另外實機截圖。
