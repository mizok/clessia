4. **新 GET 端點**：`list-endpoints.contract.ts` 的 REQUIRED 表要登記必填 query；harness `api-param-coverage.mjs` 前綴碰撞要加豁免。本機跑：`cd apps/api && eval "$(npx supabase status -o env | grep -E '^(API_URL|SERVICE_ROLE_KEY|DB_URL)=')" && SUPABASE_URL=$API_URL SUPABASE_SERVICE_ROLE_KEY=$SERVICE_ROLE_KEY DATABASE_URL=$DB_URL npx vitest run --config vitest.contract.config.mts`。

6. **`<button>` 不繼承字型**（13.33px、line-height normal）：Tailwind 按鈕要 `[font:inherit]`。
7. **zsh**：`$B:a` 會被當修飾符，變數接冒號要寫 `"${B}:path"`；`--include` 的 glob 要加引號。
