## 1. 「建報名＋開第一期帳單」只有一份：`lib/enrollment-first-invoice.ts`

- `enrollWithFirstInvoice(db, input)` 是**交易內**的共用段：驗價目表 → 選期（月繳＝生效起當月／期繳＝涵蓋生效起的期／
  堂數制不按比例）→ 比例 → 金額改了要原因、0 擋 → `insertEnrollments(pending_payment)` → 帳單 → 明細 → 堂數包。
  家長申請核准（`enrollment-approve.ts`）與直接報名（`directEnrollWithFirstInvoice`）都呼叫它。
  **要改首期怎麼算，只改這裡**；兩條路的差異只能在呼叫端（鎖申請／轉 `awaiting_payment` 是核准自己的事）。
- 呼叫端的責任：先 `lockClassSeats`，**範圍判在名額之前**（範圍外回 not-found，額滿的別校班也不能洩漏名額），再呼叫共用段。
- **`effectiveTo` 要帶進比例**：月結 run（`lib/billing-run.ts` 的 `prorateByDays`）本來就用它；首期不帶的話，
  「讀到月中就退」的人第一張單收整月、跟下一期算法不一致。核准沒有生效迄，傳 `null`。
- **從一個呼叫端抽共用段時，把另一個呼叫端既有路徑會寫的欄位逐一對過。** 這次漏了 `notes`：
  「不建立」那條本來寫 `body.notes`，共用段的輸入沒有它，選「建立」時備註靜默消失、照樣回 201（審核席二讀抓到）。
  型別不會提醒你（欄位是 optional），要靠契約斷言。

## 2. 「兩條路逐欄相同」的契約做法（`contract/enrollment-first-invoice.contract.ts`）

- **同一個 org、同一個學生、同一個班、同一天**：先走核准 → 把那筆報名改 `void`（`enrollments_active_class_student_unique`
  不看 `void`／`withdrawal`）→ 再走直接報名。兩筆的報名／帳單／明細／堂數包去掉 id、時間戳、帳單號後整列 `toEqual`。
  用兩個 org 比會卡在 fee_template_id 不同，不好比。
- 參數化要涵蓋會走不同分支的輸入：月中（有比例說明）、月初（說明 null）、期繳、堂數制、議定價＋改金額附原因。
- **交易中途失敗**要找一個「前面都寫了、最後一步才炸」的輸入：堂數制不給堂數，`session_packs.purchased_count` NOT NULL
  在最後一個 INSERT 炸，斷言四張表 0 列。驗證類錯誤（回 outcome）證明不了回滾，因為它們在第一個 INSERT 之前就 return。

## 3. 突變與驗證的做法

- **先 commit 再突變**，而且在暫存 worktree 裡改。還原用 `git show HEAD:<path> > <path>`。
  **不要在 trap 裡放 `git checkout -- <檔>`**：未 commit 的工作會一起被洗掉（這次被 auto mode 擋下才沒出事）。
- 輸出有 ANSI 色碼，`grep "Tests "` 會落空；`NO_COLOR=1` 被 `FORCE_COLOR` 蓋掉。一律 `sed 's/\x1b\[[0-9;]*m//g'` 後再 grep。
- **`npx nx run-many -t test -- --maxWorkers=2` 會讓 web 直接失敗**（Angular unit-test builder 的 schema 沒有 maxWorkers），
  而 api 照跑、摘要照印，看起來像全綠。限 worker 只給 api（`cd apps/api && npx vitest run --maxWorkers=2`），
  web 用 `npx nx test web` 不帶它。看結論前先找 `Failed tasks:`。
- web 單檔 spec：`npx nx test web --include=apps/web/src/...spec.ts`（**路徑從 workspace root 算**）。
  直接在 `apps/web` 跑 vitest 解析不了 `@core/*`，會報「Cannot find package」。
- 暫存 worktree 的 symlink：根目錄 `ln -s ../<席位>/node_modules node_modules`，api 是 `ln -s ../../../<席位>/apps/api/node_modules`。
  根目錄寫成 `../../` 時 api 測試照綠（它的連結是對的），web／harness 全部「找不到 jsqr、altcha、@tailwindcss」—— 看起來像依賴壞了。
- **併 main 之後先跑 `tsc`**：別席改了共用函式的簽名（#2443 讓 `enrollWithSeatLock` 多一個必填 `scope`），
  merge 沒有文字衝突、但自己的契約編不過。

## 4. a6-conformance compare 的坑

- 要先 `npm install --prefix tools/a6-conformance`（只裝 playwright 到工具目錄，gitignored），否則 `ERR_MODULE_NOT_FOUND: playwright`。
- API 剛起的第一個 `/api/me` 可能要 30 秒以上；compare 開頁等 networkidle 只等 30 秒。**先 curl 一次暖機**再跑。
- **表單裡同簽名（tag＋class）的欄位外框 ≥5 個，工具會把整張表單認成「列」**，一次冒出十幾條假的缺／多。
  豁免只給「第一個子元素是 `label[for]`、指向自己裡面欄位」的外框，而且**被豁免的外框仍算進兄弟數**。
  radio 群組沒有 `label[for]` 可用：改成 `fieldset`＋`legend`（核准對話框就是這樣寫），簽名不同就不湊數。
  legend 預設縮到字寬，要加 `w-full`，否則多一條「尺寸」待修。label → legend 的角色差登 R7。
- **compare 的 base 也用 head 那份 config 量**：從 config 拿掉一條已失效的偏離，base 的待修會變多（這次 1 → 4）。
  判讀看「head 新增的待修」與 head 的絕對數，不要看 base → head 的差。
- `config.mjs` 的偏離是「現況」，失效就改／刪；R5 表（`a6-adoption-rules.md`）才是只加列不刪 —— 舊列被取代時新列寫「取代 X 那列」。

## 5. 金額字樣

- 金額前綴用 `NT$`（#2464 統一開帳對話框）。新寫的地方不要再用 `$`。
