## 二、5b（列表動態）的做法 —— 已經全站套完，之後新頁照抄

- 範本：分校頁（#1649）。四件事：`app-reload-veil` 包住 `@if` 鏈、列加 `vt-row`＋唯一 `view-transition-name`、
  `loadX({ quiet, rows })`、刪除走 `injectOptimisticRemove`（樂觀）或「成功才 `viewTransition(remove, { rows: true })`」（悲觀）。
- **樂觀還是悲觀，判準是「刪除常不常被擋」**（計畫席 10-16）：FK RESTRICT 常見的（學生、學校、課程、班級、價目表）用悲觀；
  每一頁的選擇與理由寫在 PR 表格裡，審核席會對「悲觀」做「改成先拿掉」的突變 —— **悲觀版要有「沒回時不動」「失敗一直都在＋toast」兩支 spec**（#1674 被退一次）。
- **「封存／停用」不一定是離開清單**：篩選「全部」時只是換章 —— 那種情況等伺服器回來用重抓移過去，不要樂觀拿掉（人員頁）。
- **截斷類（請假 truncate）那一列不會消失**，沒有東西可以先拿掉。
- **`view-transition-name` 撞名整個 VT 被跳過**：同一筆資料出現在兩個區塊（帳單：上方清單＋展開的章）要給分區前綴，spec 守「名字全頁唯一」。
- **inline host 拍不到**：`<app-class-row>` 之類自訂元件要加 `block`。
- **reload-veil 的「第一次」是看 loading 第一次變 false**：loading 初值是 false 的頁會跳過骨架（學生詳情改成初值 true）。
- 增刪改後的重抓**不要重設展開／勾選**（課程頁），否則剛刪的那一列所在的群組收起來，淡出看不到。

## 三、驗收工具（`/private/tmp` 重開機會清空，要重建）

- 錄影／取樣腳本的核心：**在 `startViewTransition` 的 `ready` 當下讀 `document.getAnimations()`**（偽元素名＋animationName＋duration）。
  逐幀 rAF 取樣**抓不到**被刪那一列的 old 快照 —— 而且 Chrome **只替看得到的具名元素建群組**，要挑畫面上看得到的列當目標。
- 呼叫元件方法用 `ng.getComponent(document.querySelector('<selector>'))`（dev server 才有 `ng`）；`del` 之類要送進頁面的函式用 `toString()` 序列化，**不能引用外部變數**。
- 寫入一律 `page.route` 替身；沒有可測資料時，**GET 也可以替身**（收件匣未讀、骨架停留用延遲 3–4 秒）。
- 登入：`apps/api/src/scripts/login-link.ts`（一次性），登入後存 `storageState` 重用；admin 會落在 `/link-line`，也算登入成功。
  **家長用 `attendance-parent-01@demo.clessia.app`**（parent14 是 inactive，authGuard 擋下是對的，不要去改它）；老師 `teacher0001`（storage 塞 `clessia:active-role`）。
- headless Chromium 的通知權限預設是 `denied`。
- 截圖要截**整條元素寬**：裁一半剛好會漏掉亮帶／動畫。

## 四、坑

- **`vi.mock` 相對路徑的模組在 Angular 測試 builder 下不生效**（套件名可以）；better-auth 的 `authClient` 是 Proxy，`spyOn` 不上，底層 fetch 也在載入時抓好 ——
  要守「登出前先做 X」就看流程最後一步（`router.navigate(['/login'])`）。
- `HttpTestingController.match()` **會把請求從佇列拿走**，之後 `expectOne` 找不到；在 `vi.waitFor` 裡用 `match` 直接取走。
- `flush` 之後的 continuation 在微任務裡就跑完了 —— 要斷言「回應前」的狀態，在請求送出、還沒 flush 時斷言。
- 改 `styles.css` 的全域動畫：`@layer legacy` 裡的 `!important` 會贏過 utilities layer 的一般規則；任意變體 class（`[.x>&]:[transition:…]`）**比 `motion-reduce:transition-none` 更具體**，會把它蓋掉 —— 一律用 `motion-safe:` 包（reload-veil 被抓到）。
- **新目錄用 Tailwind 要在 `tailwind.css` 加 `@source`**，然後 `npm run harness:write`（掃描範圍擴大）。
- main 合了新的 api 依賴（ALTCHA）之後，**apps/api 要重跑 `npm ci`**，否則 `npm run harness` 會 `Cannot find module`。
- 疊在別支 PR 上的分支，`git switch -c` 會印「not created from an accepted base」警告，是預期的。
