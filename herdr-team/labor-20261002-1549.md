## 二、`.dev.vars`（憑證）怎麼用才不被擋

- **auto mode 分類器會擋「把 `.dev.vars` 內容讀出來」**（`cat`／`grep` 到 SUPABASE_URL 那幾行也算，標籤 Credential Materialization）。
  被擋後**不要換工具再讀**；停下回報，請使用者 `! cp ../../apps/api/.dev.vars apps/api/.dev.vars`。
- 到位後的用法（都不印內容）：`wrangler dev` 自己載入；產 magic link 用
  `( set -a; . apps/api/.dev.vars; set +a; export BETTER_AUTH_URL=http://localhost:<api> WEB_URL=http://localhost:4200; LOGIN_EMAIL=<信箱> npx tsx apps/api/src/scripts/login-link.ts > <scratchpad>/link.txt 2>&1 )`，
  再 `grep -oE "https?://[^ ]+" link.txt | head -1` 取連結。**輸出導檔、子殼 source，才不會洩到轉錄。**
- 用完 `rm apps/api/.dev.vars`（gitignored，charter 規定用完刪；要再用請使用者重複製）。
- 起服務：`npx wrangler dev --port 8797 --var BETTER_AUTH_URL:http://localhost:8797`＋`npx nx serve web --port 4200`；
  web 的 `environment.ts` 本機改 `apiUrl` 指 8797、**用完 `git restore`**；停服務用 `lsof -nP -iTCP:<port> -sTCP:LISTEN -t` 取 PID、
  **先 `lsof -a -p <PID> -d cwd` 確認是自己的 worktree** 再 `kill`。

## 三、指令與工具小坑

- **zsh 不會對字串變數做字詞分割**：`Q="psql -h …"; $Q -c …` 會 `command not found`。用函式 `q(){ psql … "$@"; }`。
- **指令鏈用 `&&` 不用 `;`**：`;` 讓失敗的測試沒擋住就 push／開了 PR（#1025 當天犯過）。
- **`nx test web` 單檔**：`npx nx test web --skip-nx-cache --include='**/foo.spec.ts'`（可重複）；reporter 參數是 **`--reporters=verbose`**（單數會報 `not found in schema`）。
- **`psql` 一次 `-c` 帶多句只回最後一句**；要多查就分開呼叫。
- **`grep --include=*.ts` 在 zsh 會被當 glob 炸掉**（`no matches found`），要加引號 `--include='*.ts'`。
- 找行程只印 PID（README「找行程只印 PID」）；`lsof -t`、`pgrep -f`（不加 `-l`）。
- herdr 訊息：對方在 working 時，訊息會顯示成輸入框 `queued messages`（**不是**貼上緩衝，不必補 Enter）；
  idle 時才可能停成 `[Pasted text #N`。驗送達＝在對方 pane 裡看到你訊息的內文或 sha。

## 四、rebase 別人（保留類）PR 的做法

- 先 `git fetch -p`，記下舊 head，`git checkout -B <分支> origin/<分支>` → `git rebase origin/main`；
  推用 `--force-with-lease=<分支>:<舊 sha>`（只在遠端還是我看到的那個 sha 時才覆蓋）。
- **證明沒夾帶**：`git range-diff <舊>~N..<舊> origin/main..HEAD`（`=` 逐字相同、`!` 有差異）；
  `!` 的 commit 再用「增刪行集合」比對**衝突檔以外**的檔案：
  `git show --format= <舊> -- . ':!<衝突檔>' | grep -E '^[+-][^+-]' > a; 同法對新 commit > b; diff a b`。
  PR 留言貼 range-diff＋這個結論，使用者／reviewer 才有東西可比對。
- **衝突常是「兩邊各加一段」**（authorization-scope.md、deploying.md 這類 kb 文件）→ 兩邊都留、中間空一行；
  import 區取聯集。**語意衝突（兩邊對同一行有不同意圖）不要只挑一邊**：#972 與 #1015 都改 `issueLoginLink`，
  合法的合併是讓 util 同時滿足兩者（403 採伺服器訊息），並在 PR 留言明講「這不是單純取捨標記」。
- 推完回報**新 head sha**＋舊 sha，並跑 `nx typecheck`、`npm run harness`、相關測試。
