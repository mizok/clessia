## 四、這次學到的

1. **收自己的 dev server 要按 cwd 篩到 `apps/api`，不要篩 worktree 根目錄**：根目錄會連本 session 的 MCP server（nx、codex）一起殺掉。wrangler 只殺 8795 監聽者沒用，父行程會把 workerd 重生、還佔著 inspector port
2. **compare 的 base 會跟著 origin/main 走**：分支沒併 main 時，表上的差可能是別張 PR 造成的（#2171 第一次量到的是 #2161 的差）。量之前先 merge main
3. **桌機高度不同是待修，不是偏離（R3）**：補 44px 一律帶 `wide:` 照稿縮回去。句中連結沒帶的話，段落會被撐高 23px
4. **`vector-effect` 寫在 `<defs>` 的 path 上，經 `<use>` 引用時不生效**：線寬會跟著 viewBox 縮放
5. **移除開站畫面別用固定延遲**：NavigationEnd 到畫面 render 的間隔不固定（guard 轉址時更長），要等 `transitionend`
6. **compare 拿到的 admin 頁若有「待修」大增，先看 app 是不是被導去 /login**（登入態過期時工具會報錯，但同時間跑的 teacher 頁可能還正常）
