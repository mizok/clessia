## 二、會再撞到的坑

1. **多步寫入要原子 → `withTx`，不是 RPC、不是補償**（`kb/wiki/architecture/pg-pool-writes.md`）。
   名額這種「先數再寫」的守門，**數和寫要在同一個交易、`FOR UPDATE` 鎖父列**，而且**所有寫入路徑都要拿同一把鎖**
   —— 只有一條路拿鎖等於沒鎖（#1758 審核席抓到的矛盾 → Q9 → `lib/class-seats.ts`）。
2. **併發測試要確定性**：`Promise.all` 兩個交易常常剛好不交錯，拿掉 `FOR UPDATE` 也綠。
   寫法：A 連線 `BEGIN` 拿鎖不放 → 啟動 B → 等 200ms 斷言 B 還沒完成 → A 寫入＋COMMIT → B 應該 over-quota
   （`contract/class-seats.contract.ts`）。
3. **partial unique 的 `ON CONFLICT`**：`ON CONFLICT (class_id, student_id) WHERE status NOT IN ('withdrawal','void') DO NOTHING`
   要跟索引 predicate 一字不差才推得到 arbiter；用它代替 23505，交易才不會被一筆重複拖垮。
4. **子代理（含 `enrollment-domain`）報的 schema 事實要自己對一次**：它說 `classes.max_students` 可空，
   實際是 `NOT NULL DEFAULT 20`；`parents.user_id` 也是 NOT NULL。寫 fixture 前 `information_schema.columns` 查一次。
5. **契約測試要的 `ba_user`**（`enrollment_requests.requested_by`、`parents.user_id`）借 seed 既有帳號
   （`SELECT id FROM ba_user … LIMIT n`），c2 不能自己建。`parents` 有 `UNIQUE(user_id, org_id)`，同 org 不能重用同一帳號。
6. **審核席的突變會打「金額路徑的每一個條件」**：期繳查期的 `end_date`、價目表 `is_active`、0 元、`invoice_due_days`、
   `agreedAmount` 優先 —— 每個 `WHERE` 條件、每個 `??` 都要有一支會紅的契約。前端同理：試算帶不帶議定價、選單濾不濾模式、
   重疊期取哪一期（要跟 API 的 `ORDER BY` 一致）、其他錯誤會不會清掉撞課清單。
7. **錯誤注入**：`createMultiOrgDb` 沒有錯誤注入，照 `trial-requests.spec.ts` 的 `failCampuses`
   （`vi.spyOn(client,'from')` 換掉某張表的 `select`，回 thenable 的 `{data:null,error}`）。讀失敗要 fail-closed 500，
   不要回「沒有帳單、沒有帳戶」讓家長以為不用繳。
8. **家長端不能拿原始 client**：harness A19 擋 `c.get('supabase')`；帳單、帳戶一律 `childDb`（`from(table,'student_id')`、`orgRef`、`orgPaymentInfo`）。
9. **`white-space: pre-line` 的段落要 `<!-- prettier-ignore -->`**，否則 prettier 折行多出空白行（同 payments 頁）。
10. **新增帶 `org_id` 的表，同一張 migration PR 要在 `lib/org-scope.ts` 的 `OrgTable` 登記**（harness A23 會紅；前例 #1668、#1690、#1765）。
11. **squash 合併後疊在上面的 PR merge main 會在同一行衝突**：取自己這側，再用 `git diff origin/main -- <檔>` 確認只剩自己的改動。
    `a6-adoption-rules.md` R5 表兩邊都會被 prettier 重排 → 取 main 版、把自己的列 append 到表尾再 prettier。
12. **`gh pr checks --watch` 剛 push 完會回 exit 1「no checks reported」**：還沒掛上。改用
    `gh run list --branch <b> --limit 1 --json status,headSha` 等到 `completed` 且 sha 對上。
13. **`gh pr edit --body "$(… | sed …)"` 的 sed 失敗會把描述清空**：一律寫檔用 `--body-file`。
14. **web 單檔測試**：`npx nx test web --skip-nx-cache --include='**/<路徑>/<檔>.spec.ts'`（沒有 positional 參數）。
15. **計畫席常 blocked（等使用者互動）**：`herdr agent prompt` 會回 `agent_blocked`。背景
    `herdr agent wait <計畫席> --until idle --until done --until working` 後再送。
