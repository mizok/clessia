## 一、本機實打公開端點的速率限制

- **`wrangler dev` 不會覆寫你自帶的 `CF-Connecting-IP`**：`curl -H "CF-Connecting-IP: 203.0.113.x"` 進得去，
  `client_ip_hash` 跟著變。所以「同來源」與「同聯絡方式」兩條限制可以在同一輪各用不同 IP 分開驗，不互相污染
  （用 203.0.113.0/24 文件網段，不會撞到真的 IP）。
- **Turnstile 有官方測試金鑰**，不用真帳號：`--var TURNSTILE_SECRET_KEY:1x0000000000000000000000000000000AA`（必過）、
  `2x…AA`（必敗），token 隨便給（`XXXX.DUMMY.TOKEN.XXXX`）。**「有 token 但驗證不過」回的是另一句訊息**
  （「機器人驗證沒有通過」vs「請完成機器人驗證」）—— 看到它才證明真的打到了 `siteverify`，而不是在沒 token 那一步就擋了。
- `siteverify` 打不通 → 503 本機造不出來，以 spec 為證並在留言寫明。
- 三種設定各起一次 `wrangler dev`（`--var` 換值要重起），**一支腳本分三段**、每段印「預期 N 列」對照實際列數。

## 二、spec 替身造不出查詢 error：用 Proxy 包一層

`multi-org-db` 的查詢永遠回 `error: null`，所以「查詢出錯時不可吞成 0 放行」這種 fail-closed 測試寫不出來。
**不改替身**（全 repo 共用），在單支 spec 裡包：

- 外層 Proxy 攔 `client.from(table)`，只對目標表回包過的 builder；
- builder 的 Proxy 攔 `select(cols, opts)`：`opts.head === true`（計數那支）才回一個「任何方法都回自己、`then` resolve
  `{ data: null, count: null, error }`」的鏈；其他方法 `bind` 回原 builder，**寫入照常** —— 這樣修前的紅才會紅在
  「寫進去了」而不是 500。範例 `routes/public/abuse-guard.spec.ts` 的「計數查詢出錯」那條。
- `db.client` 型別是 `unknown`，`new Proxy(db.client as any, …)`（TS2345）。

## 三、合後實打的取材

- **分校範圍在 `staff_campuses`（`staff_id`→`staff.user_id`）**，不在 `user_roles`（那張只有 user_id／role／permissions）。
  seed 的 `admin02` 只綁「示範分校02」，而 demo 的班多在另一個分校 —— **拿 admin02 打課堂類端點就是現成的別校 403**。
- **seed 沒有未來的 `billing_periods`**（兩期都已開始），「待開單」視窗的實打要用真路徑 `POST /api/billing-periods`
  造暫用期、最後 `DELETE`（audit_logs 會留 create／delete 兩列，登記給 db-reset）。
- 批次改期要「撞同班」但同週沒別的堂時，用 `dayOffset: 7` 讓一堂落到下週那堂上，走的是同一條 `class_conflict` 分支。
- psql 直套還沒合的 migration（`BEGIN; <檔>; COMMIT;`）**不進 `schema_migrations`**：下次 reset 是整個消失不是回滾。
  實打完把建了什麼逐樣列（欄位、索引、CHECK、trigger、function、資料列）給 db-reset 驗歸零。

## 四、跨席訊息：判斷對方輸入框是否為空

`herdr agent read <席> --source recent | tail -7` 裡的 `❯` 那一行。**`grep -q '❯ .\+'` 在 macOS 上判不準**（多位元組字元），
等到的「空」是假的。用：

```sh
L=$(herdr agent read <席> --source recent 2>&1 | tail -7 | grep '^❯' | sed 's/^❯[[:space:]]*//'); [ -z "$L" ] && echo EMPTY
```

背景跑 `until` 迴圈等它空，不要 `sleep` 前景等。使用者在計畫席框裡打到一半的字可能放好幾分鐘 —— 照送會把兩段拼成一則送出。
