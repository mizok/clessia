## 三、這次學到的

1. **conformance 偏離的 `status`、`pop`、`kind` 是全等比對**，只有 `detail／a6／app／host` 是 regex（`diff.mjs` `classify`）。寫成 `status: '^(多|文案)$'` 一條都不會命中 —— 每個狀態各一條（`[...].map((status) => …)`）。README 已更正
2. **compare 的 head 要先 merge 最新 main**：head 分支比 main 舊時，main 新進的改動會被算成「反向差異」（#2404 第一次 compare 多出產生課堂、摘要區 4 條）
3. **分步會讓工具配錯對**：新加的步驟標示 `<p>` 被依 DOM 順序配到稿同層的 `<p>`（「還沒填」），手機第二步藏起來的欄位報「缺」、稿的標籤被配到第一步的標籤。步驟標示用 `host: '^app-dialog-steps$'` 全站偏離；藏起來的第二步要逐頁登（請假頁 `new-leave`）。**工具限制**：手機寬度量不到第二步（要另加 prep 操作到第二步）
4. **不要用一個 `<form>` 包住整個對話框內容來接 Enter**：conformance 每個 part 多一層 `landmark:form`，跟稿整片對不上（#2405 第一版 leave 1440 新增 20 條）。改成**空的 `<form id>`＋欄位 `form="<id>"` 屬性**，Enter 一樣送出、結構不變；spec 用 `input.form` 驗 owner（兩種模式都要驗，#2405 突變 N8）
5. **`[class.max-wide:hidden]` 這種帶冒號的 class 綁定 Angular 吃得下**（spec 有驗 classList），手機分步不用新增斷點 signal；`dialogStepsActive()`（matchMedia）只在送出那一刻判斷
6. **zoneless 下直接呼叫元件方法改 signal、但模板讀一般欄位** → 只做局部刷新，開發模式二次檢查報 NG0100。實際是事件觸發不會發生；spec 裡直接呼叫時補 `fixture.componentRef.changeDetectorRef.markForCheck()`
7. **新的共用元件目錄要加 `tailwind.css` 的 `@source`**，harness 會擋；加了之後掃描範圍變大，要 `npm run harness:write`
8. **外框搬進子元件會讓整段模板重新縮排**（#2401 原始 691 行／不計空白 239 行）：PR 附兩個數字、請審核席用 `?w=1` 看
9. **SHA 一律貼 git 輸出**（11-06 一次憑印象寫了不存在的 SHA，計畫席已立規）；herdr 回報別在指令建立前先送半句
10. **驗證腳本防呆**：暫存 worktree 併 main 有衝突就不跑；**背景執行中的 bash 腳本不要編輯**（bash 邊跑邊讀，前面插行會讓後面的指令讀錯位）—— 要改先 TaskStop、確認鎖已釋放
11. **apps/api 有自己的 package-lock**：根目錄 `npm ci` 不裝它，缺 `pg` 時 harness 紅；暫存 worktree 也要 symlink `apps/api/node_modules`（和 `tools/a6-conformance/node_modules`）
