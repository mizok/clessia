## 三、會咬人的小坑

- **`scrollIntoView` 對 `display: contents` 的元素是空動作**（rect 全 0）。shell 的 `<main>` 子層被 `[&>:not(router-outlet)]:contents` 攤平，id 要放在 `<main>` 上，不是裡面的 wrapper。實測用 `getBoundingClientRect().top`＋scrollTop 前後對。
- **`computed(() => inject(X))` 會在注入環境外執行而拋錯**——`inject` 要放欄位初始化（`private readonly x = inject(X)`），computed 只讀它。
- **Tailwind 條件 class 要整串字面量**；與既有的 `max-[1024px]:h-…` 衝突時用 `!` 後綴（`max-[1024px]:h-[var(--window-height,720px)]!`），別指望產生順序。
- **跑 web 單檔 spec**：`npx nx test web --skip-nx-cache --include='**/xxx.spec.ts'`（可重複 `--include`）。`--testFile` 不存在；直接 `npx vitest run` 在 `apps/web` 會因別名全爆。api 才能直接 `cd apps/api && npx vitest run <路徑>`。
- **macOS `sed -i` 要 `-i ''`**，多行改檔改用 python 一次替換。
- 關自己的 dev server：`lsof -ti tcp:4200 -sTCP:LISTEN` 取 pid，`lsof -a -p <pid> -d cwd -Fn` 確認 cwd 是自己的 worktree 再 kill（`npm run dev` 起的 web 與 workerd 各一支）。
- `vd.mjs` 內寫死席位時間戳的路徑與 port，複製成 `vd<席名>.mjs` 並 sed 取代；登入狀態用 `login-link.ts`（先 `set -a; . apps/api/.dev.vars`）＋ `login.mjs` 產 storageState。
