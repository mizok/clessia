## 二、會再撞到的坑

1. **A6 的頁面稿會覆寫 `a6.css`。** 開 #1698 時我只看了 `a6.css` 的 `.chap`，以為人員、價目表、請假、考試這四頁在手機上是上下疊；其實這四頁的稿在自己的 `<style>` 的 `@media (max-width: 860px)` 底下，改成了橫排 28／14。**對齊之前先 grep 該頁 html 的 `<style>`。** compare 的「head 新增的待修」抓到了這個錯（+5）。
2. **PrimeNG 的 `appendTo` 指定成元素時，還是用整份文件的座標**（`absolutePosition`，寫在 `top` 和 `inset-inline-start`，不是 `left`）。面板放在原生 modal dialog 這種 fixed 容器裡會偏一個容器的位置。`select-field` 的修法是包住 overlay 實例的 `alignOverlay`。**p-overlay 實例會一直留著**，所以第二次打開時，beforeEnter 已經透過包過的版本換好座標；onShow 不能再換一次（審核席抓到的，472 → 274）。
3. **原生 `<dialog>` 是 top layer**：PrimeNG 的下拉掛在 body 會被蓋住，要 `appendTo` 這個 dialog。
4. **`mount()` 的 `{ write }` 會擋到兼任身分**：`requireAdminPermission` 對有 admin 角色的人一律看權限、不看 active role。只想擋某一支寫入端點時，在路由上掛 `writeRequiresAdmin`（harness A7b 認得這種寫法）。
5. **seed 同一列被兩支 seed 寫**：`teacher0001` 的 admin 權限是 `seed-demo.sql` 第 4 段寫的，它比 `seed.sql` 晚跑。只改 `seed.sql` 會被蓋掉。
6. **touch-target gate（A27）只讀模板的 class**，看不到 `styles.css` 裡的 `min-height`。全域 class 的最小高度要寫在模板上（`.coll__sum` 用 `min-h-14 wide:min-h-16`）。也不能在模板加 `min-h-11` 了事：utilities 層比 legacy 層晚，44px 會蓋掉 A6 的 56／64。
7. **`border-solid` 會讓四邊都長出 3px 的框**（本 repo 沒有 Tailwind preflight，寬度預設是 medium）。只要一條下框時，寫 `border-b` 就好，不要加 `border-solid`。
8. **`last:border-b-0` 只在列真的是 last-child 時才生效**。列後面還接了連結或分頁器時，要把列另外包一層（儀表板名冊就是這樣）。
9. **#1694 squash 合併後，疊在它上面的分支 merge main 會衝突**，衝突內容就是同一份改動。先 `git diff <審過的 sha> origin/main -- <檔>` 確認兩邊完全一樣，再全部取自己這邊。
