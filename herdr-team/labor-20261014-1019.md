## 一、驗證工具會「安靜地不做事」—— 空輸出不是綠（這輪踩了四次）

- **`npm run harness` 要驗 exit code，不能只看輸出前幾行**：前面的 ✓ 一直印，A27 紅燈在後面。`npm run harness >/dev/null 2>&1; echo $?`。**同理 `nx run-many -t test` 也驗 exit code**，別只 grep「Tests」。
- **直接跑 `npx vitest`（api）時 `NO_COLOR=1`**：不然 `grep "Tests "` 被 ANSI 色碼擋掉、整段空輸出，看起來像「沒跑／沒失敗」。（web 走 nx 的情形 [2156 charter](labor-20261010-2156.md) 已寫。）
- **突變驗證看到「空輸出」＝編譯失敗，不是通過**：例如把模板改成 `@if (false) {` 後整支 spec 編譯不過、grep 什麼都沒有。換一種不改型別的突變（改字串、改比較符、對調 class）。
- **突變抓不到時先懷疑 fixture 的數字互相抵銷**：`status !== 'void'` 的突變沒紅，因為多退單淨額 −300、部分繳單 +300 剛好抵銷；把 300 改成 400 就紅了。多個加總的 fixture 用**互質的數字**。
- **邊界要有「剛好在邊界」的 fixture**：`end_date < today` 被改成 `<=` 全綠，因為 fixture 全用遠古／遠未來。補一筆 `getCurrentTaipeiDateString()` 當結束日的啟用班（唯一靠今天的 fixture）。

## 二、Tailwind／模板的三個靜默失效

- **任意值 class 不能寫成 `[class.text-[34px]]`**（方括號讓綁定名稱解析失敗，沒有編譯錯誤、class 就是沒掛）。整串寫在 TS 的 `computed`、用 `[class]` 綁；spec 斷言 `classList.contains('text-[34px]')`，並用瀏覽器量 computed font-size（`chapter-head` 的 `nameClass`）。
- **A27 gate 掃不到動態 `[class]` 字串裡的 `min-h-11`**：可點的 div 要在**同一個元素**加靜態 `class="min-h-11"`（Angular 會把靜態 class 和 `[class]` 合併，不互蓋）。`class-row` 的 `layout().row` 就是這樣被擋過（#1541 CI）。
- **全域 `.clessia-filter-search { flex: 1; max-width: 100% }` 會讓 `basis-full` 失效**：要整列就用 `min-w-full`，並在容器寫 `flex-wrap`（家長頁原本沒寫，換行永遠不發生）。手機要「搜尋一列、篩選下一行」：`<div class="order-1 h-0 w-full wide:hidden">` 當斷行，後面兩個 `order-2`。

## 三、共用元件擴充的做法（預設值＝舊行為，不影響他頁）

`page-actions.primaryOnDesktop`（手機托盤的主鈕與桌機主鈕不是同一顆）、`chapter-head.chapterActions` 投影槽與 `stacked`（手機也堆疊）、`invoice-actions.compact`（一顆主要鈕＋「⋯」）、`class-row.selectable`（批次選取才出現勾選欄；兩套格位 class 整串寫 TS）。每個都有「false 時 DOM 真的不同」的 spec ＋ 突變。**先看有沒有既有元件再加輸入**（students 頁的 `p-iconfield` 搜尋、`app-filter-toggle`、`app-popup-menu` 都是現成的）。

## 四、「還沒登入過」的判準與取證（`ba_user.emailVerified`）

- **在這個系統它的意思是「成功登入過」，不是驗證過信箱**：`createUser` 預設 false；兌換登入連結（magic-link verify）或走 LINE（`lineProfileToUser` 寫 true）才翻 true。不用 `ba_session`（會過期）、不用 `ba_account(line)`（只用連結登入的人沒有）。**API 外露一律叫 `hasLoggedIn`**，不把欄位名漏到前端。
- **本機 `seed.sql` 的家長全是 true** → 示範資料看不到 pill。取證：用 API 建一位家長（`POST /api/parents`，cookie 取 `state-admin.json`）→ `POST /api/login-links` → 兌換連結（`redirect:'manual'`，302 到 `/link-line`）→ psql 讀 `ba_user`／`ba_session`，每步截圖。清理的 FK 順序：`user_roles` → `parents` → `ba_user`（直接刪 `ba_user` 會被 `parents_user_id_fkey` 擋）。
- **本機沒有「已結束的班」**：取證時對既有班用 psql 複製一列、改 `end_date` 到過去，截完刪掉。

## 五、後端的兩個坑

- **supabase 查詢鏈丟進泛型 `applyCampusFilter` 會 TS2589（型別推導過深）**：同一個函式裡第二支類似的鏈就爆。解法＝一支查詢多選欄位、在記憶體分類；仍爆就用最小形狀轉型（`courses.ts` 的 `ScopedQuery`）。**只改 spec 的 PR 也要跑 `nx typecheck api`**。
- **全撈再在記憶體數受 PostgREST `max_rows`（1000）限制**：在查詢旁寫 `ponytail:` 註解講明上限與升級路徑，不要默默截斷。查詢失敗時**不回欄位**（`enrolledCount`），別回 0 把「查不到」說成「沒有人」。

## 六、取證環境補充（接 [2156 charter §五](labor-20261010-2156.md)）

- 這台機器的 Playwright **沒有 chromium**：`npx playwright install chromium`（約 90MB，一次）。腳本骨架 `.pw-regression/acc2156.mjs`；互動態另寫（展開、開面板、批次進出）。
- **選擇器**：容器 `role=search` 的 `aria-label` 和裡面 input 同名會讓 `getByLabel` 命中容器 → 容器改叫「帳單搜尋與篩選」；`page-actions` 裡的按鈕用 CSS `app-page-actions button[aria-label="…"]` 比 `getByRole(name)` 穩；課程頁展開用 `[data-chapter] button[aria-expanded]`（第一個 `[aria-expanded]` 是頂欄分校切換）；popover 裡的開關用 `.p-popover .p-toggleswitch`（`getByText('含歷史班級')` 會點到提示文字）。

**這一段新踩的坑（接 §一）**：

- **commit 鏈要自己擋 harness**：我寫過 `npm run harness >/dev/null; echo $?; …; git commit && git push`——`echo` 讓整條鏈不論結果都繼續，紅燈的 commit 就推上去了（#1546 第一版）。要擋就 `npm run harness && git commit …`，或分兩步看 exit code 再 commit。
- **`(click)` 掛在元件宿主上也算「可點」**：A27 gate 對 `<app-filter-toggle (click)=…>` 要求宿主有 `min-h-11`（宿主是 inline，沒有視覺效果，只是過 gate）。
- **dev server 有編譯錯誤時 Playwright 會被 `vite-error-overlay` 擋住 click**（錯誤訊息 `<vite-error-overlay> intercepts pointer events`）。先看 `web.log` 最後一次 `Application bundle generation complete`／`ERROR`，**log 裡舊的 ERROR 不代表現在壞**——突變迴圈中途會留下殘影，等它重建完再拍。
- **Popover 的 spec 寫法**：面板內容沒打開時不在 DOM、打開後掛在 `document.body`（不在 `fixture.nativeElement` 內）。斷言用 `document.body.querySelector('#xxx-filters')`、並斷言 `root.contains(panel)` 為 false（確認是浮層）；`aria-expanded` 在 jsdom 裡會跟著 `onShow` 變 true，可以斷言。
- **zsh 把變數當命令**：`Q="docker exec … psql …"; $Q "select …"` 會 `command not found`（zsh 不做 word splitting）——寫成函式 `q(){ docker exec supabase_db_clessia psql -U postgres -At -c "$1"; }`。
- **疊在別支上開分支時**：`git checkout -b X <別的分支>` 會觸發 hook 的「非基於 main」警告，無害；PR 說明要註明「疊在 #N 之上，#N 合了只剩本支」。
- **Popover 裡的 `p-select`（`appendTo="body"`）點選項不會被當成外點擊**：帳單（狀態下拉選「未繳」→ 鈕變「篩選：未繳」）與家長（選「停用」→「篩選：停用」）都實按過，浮層維持開著、值有套用。**這是 #1546 二讀被問到才補按的**——寫浮層時，內含下拉的要在第一輪就按一次選項（jsdom 的 spec 測不到 overlay 的外點擊判定，只能用真瀏覽器）。選項文字有包含關係時（「停用」vs「啟用＋停用（不含封存）」）用 `^…$` 精確比對，不然 `hasText` 會點到別的選項而「值沒變」看起來像壞了。
