## 四、這輪學到的

- **config 的頁面 id 要用 seed.sql 寫死的固定 id**（seed-demo 是 gen_random_uuid，共用 DB reset 一次就變，量到的是「找不到」）。旁邊註明出自哪支 seed
- **psql `-c` 帶多句只印最後一句的結果**，前面看起來是空的不代表沒有 —— 逐句查
- deviation 的 `status` 是逐字比對，不能寫 regex；同一條要多個 status 用 `...[a, b].map()`
- Angular unit-test builder 不吃 runnerConfig 的 `sequence`／`maxWorkers`；要讓幾支 spec 固定順序跑在同一個環境，寫一支暫存 spec 依序 `import` 它們
- 「這學期的課」那一列是 `role=button`＋Enter／Space（#722 有 spec 釘著），不要為了貼稿改成 h3／link
- 「傳 LINE」不做（`kb/wiki/architecture/a6-adoption-rules.md:108`）；「打電話」是 `tel:`，家長沒電話不顯示
- flex 子元素的 display 會被 blockify（inline-flex→flex、inline→block），工具量成樣式差，畫面一樣
