## 0. 回寫稿的一批 = 三件事一起改

1. 改稿（`.design-explorations/973-layout/a6-editorial/`）照 **app 現在的樣子**畫：值、字、結構都對 app 的模板，不對 R5 的文字描述
   （R5 寫的是當時的裁定，app 之後可能又動過，例：帳戶選單手機抽屜 R5 說灰底，app 量到白底）。
2. `config.mjs` 拿掉不再需要的偏離；**拿掉前先在「前」的報告裡 grep 那條的理由字串**，0 次命中的就是死條目。
3. R5 列尾註明「已回寫稿（#2495 Bn），列保留」——只加不刪。

`a6.css` 的慣例是**依日期分段往檔尾追加**（「═══ 11-13 #2495 Bn：…」），不要改前面的歷史段。代價：並行的幾張 PR 都在檔尾追加，
後合的那張一定撞檔尾衝突；解法固定是兩段都留（先合的在前）。PR 內文先寫好這句，代合鏈照做。

## 1. 量「稿的改動」：同一個 app、換稿

- compare 的 `--base/--head` 換的是 **app** 版本；這裡要換的是**稿＋config**。做法：web／API 起一次（自己的 port），
  「前」在暫存 worktree（`git merge-base HEAD origin/main`）跑 `run.mjs diff <頁>`，「後」在座位跑，`A6_OUT` 各指一個目錄。
- 負載高時（卡巴斯基 kavd、FVG 的 VM，load 15～22）稿頁或 app 頁會撞 30 秒載入上限、整批中斷。**一頁一頁跑、逾時重跑該頁**，
  已量完的頁保留。單獨開稿頁 0.5 秒載完＝不是稿的問題，不要去改工具的逾時。
- 比前後待修：抓 `### 待修` 段逐行 diff。**數值變了的同一條也會顯示成「新」**（Δx +46 → +76），先看「前」有沒有同 key 的列再判斷。
- 摘要用 `bash -c`：zsh 不分詞，`for p in $P` 會把整串當一頁；`git show "$B:path"` 在 zsh 會被當成 `:t` 修飾子吃掉，要寫 `"${B}:path"`。

## 2. 回寫後會冒出來的東西（這批踩過的）

- **拿掉一條寬的偏離會露出它順帶蓋住的差**：全站「手機 Δx −8」那條連 Δy 一起放過；Δx 回寫成 0 後 Δy −53 露出來（後來查是 seed 沒課程簡介）。
- **欄位數差一欄，工具就把一邊認成「列」**（≥5 個同形容器＝列）：帳號設定 app 5 欄、稿 4 欄 → 整組變缺＋多。補齊欄數（稿補「對外暱稱」）比登偏離乾淨。
- **改根的角色會讓既有偏離的 key 失效**：稿的篩選浮層改成 `dialog[篩選]` 後，各頁寫死 `landmark:popover\[\]` 的 R2 條目全比不中。改成 `landmark:(popover|dialog)\[(篩選)?\]`。
- **選擇器範圍**：`.tbar .btn` 會打到長在工具列裡的篩選浮層按鈕；`.xp` 改白會連手機登入彈窗（app 灰底）一起改。用 `.tbar__in > .btn` 這種直接子代。
- **標題文字改了，彈窗配對整個位移**：收款彈窗標題加期別後，工具配對全歪、待修暴增；這種就留偏離不回寫（R5「帳單列寫期別」只回寫了逾期列）。
- **conformance 的 spec 拿真 config 當測資**：`normalize.test.mjs` 有兩條借 notifications-publish 的偏離（含 `whole` 機制）。刪偏離前 `grep -n "PAGES\['<頁>'\]" lib/*.test.mjs`。
- R5 表的欄寬由**最長那列**決定：在最長列（「灰帶工具列控制項高度」「新增考試…」「品牌 mark 進 app 內」）的裁定欄加字，prettier 會重排整張表（diff 260 行以上）。
  先量寬度（`unicodedata.east_asian_width`，W/F 算 2），超過就把註記寫在「項目」欄。

## 3. 量測環境

- 登入態會過期：`state-multi.json`（select-role）11-11 就過期，前後都在那頁中斷。重產：`login-link.ts` 帶 `BETTER_AUTH_URL=<自己的 API>`、`WEB_URL=http://localhost:4200`，
  再 `A6_API_URL=<自己的 API> node tools/a6-conformance/login.mjs '<連結>' <state>`（驗證 `/api/me` 200 才蓋檔，失敗不動原檔）。連結寫進 worktree 的 tmp/，用完清空。
- `state-teacher.json` 的 active-role 綁 origin：用自己的 web port 量老師頁前，在 `origins` 追加一筆自己的 port（只加不改，別席也是這樣）。
- 全套鎖：只用 `until mkdir $L` 排隊，pid 檔寫純數字、席名寫 `who`；`trap … EXIT` 收鎖，**另外** `trap 'exit 130' INT TERM HUP`——
  只掛一個 trap 處理 TERM 時，trap 跑完腳本不會結束，會繼續跑後面、而鎖已經收掉。
- 自己起的 wrangler 會被外部收掉（11-13 兩次，log 無錯誤）；app 被導到 `/login?reason=connection-error` 就是 API 不在，重起續跑。
