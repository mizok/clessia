# Clessia 管理端：「產品裡已經有正確答案」橫掃清單

格式：**哪一頁做對了 → 哪些頁沒跟上**。修法是照抄，不是重新設計。
唯讀取得，2026-09-05。

## 1. 破壞性動作 —— 四層做法，而且**風險與防護成反比**

### ✅ 做對了：學生管理 `/admin/students`

每列 ⋮ 選單：

```
學生詳情
編輯
停用
─────────────────────────
🗑 已有報名紀錄，無法刪除    ← 灰色、不可點、直接說出原因
```

**為什麼這是最佳解**：它不是把刪除藏起來，而是**保留位置、灰掉、並說明為什麼不能刪**。
使用者不用猜「刪除在哪」、不用試了才被拒絕、也不會以為系統少做了功能。

### 沒跟上的（由好到壞）

| 頁面 | 做法 | 差距 |
|---|---|---|
| 家長管理 | ⋮ 內「停用帳號 / 封存帳號」，無刪除 | 沒說明「為什麼沒有刪除」 |
| 人員管理 | ⋮ 內「停用帳號 / 封存帳號」，無刪除 | 同上 |
| 課堂管理 | ⋮ 內「停課」，無刪除、無紅色 | 尚可 |
| **分校管理** | ⋮ 內「刪除分校」，**黑字、無紅色、無警示、與「編輯」同權重** | 見下表 |
| **課程管理** | 每列裸露紅色 🗑 | 無防護 |
| **科目管理** | 每列裸露紅色 🗑 | 無防護 |
| **學生請假** | 「操作」欄**只有**紅色 🗑（連編輯都沒有） | 無防護，且打錯只能刪掉重建 |

### 風險反比表 —— 這是本條的重點

| 刪除對象 | 連動範圍（推測，未驗證） | 實際防護 |
|---|---|---|
| **分校** | 課程／班／課堂／學生／人員／報名／繳費，全部 | 選單裡一行黑字 |
| **科目** | 所有綁該科目的課程 + 老師資格篩選 | 列上裸露紅圖示 |
| **課程** | 底下所有班與課堂 | 列上裸露紅圖示 |
| 請假 | 單筆 | 列上裸露紅圖示 |
| 學生 | — | **禁止，且說明原因** ✅ |

**連動最廣的分校，防護最弱；完全沒連動的學生，防護最強。** 順序是反的。

→ **照抄對象**：學生管理的「灰掉 + 說出原因」。分校、科目、課程至少要先收進 ⋮ 並加確認。

## 3. 同名不同能力（最危險的一類）

### 已確認一組

| 入口 | 字面 | 能力 | 可發現性 |
|---|---|---|---|
| 學生管理頁按鈕 | **「新增學生」** | 不帶 `parentId`，**建出來必是孤兒** | 高 |
| 家長列 ⋮ 選單 | **「新增學生」** | 帶 `parentId`，會綁定 | 極低 |

**可發現的那條是能力較差的那條，而且兩條同名。**

### 同形不同行為（圖示版的同名問題）

課程管理列表裡，**同一個 `›` 圖示有兩種行為**：
- 課程列的 `›` → 就地展開
- 展開後班級列的 `›` → **跳頁**到班級詳情

點之前無法預測。

### 儀表板兩個「前往」，落地品質不同

- 「成績待登錄 1」→ 前往 → `/admin/grades/exams`，對得上 ✅
- 「未點名課堂 15」→ 前往 → `/admin/sessions`，**對不上** ❌

同一個元件、同一個字，一個可信一個不可信。

## 5. 稽核紀錄（操作紀錄）覆蓋範圍是反的

### ✅ 有「操作紀錄」按鈕
課程管理、課堂管理、學生請假、人員管理、分校管理

### ✗ 沒有
學生管理、家長管理、考試管理、**繳費紀錄**、**餐費管理**、**費用方案管理**、報名進出、聯絡簿、通知中心、營收報表

**跟錢有關的三頁（繳費、餐費、費用方案）全部沒有操作紀錄**，而課程管理有。
補習班真正會發生爭議的是「這筆錢誰改的」，不是「這門課誰建的」。覆蓋順序是反的。

→ **照抄對象**：課程管理／人員管理的頁層級「操作紀錄」按鈕，優先補到三個金流頁。

## 12. 點名的入口深度（順帶發現）

點名是全站核心動作，實際路徑是：

```
儀表板「未點名 15」→ 前往
  → /admin/sessions（無篩選，本月 19 堂）
    → 自己找到那一列
      → 點 ⋮
        → 「管理出勤狀況」
```

**核心動作藏在每列的 ⋮ 選單第二項，而且中途的落地頁篩選還對不上。**
（老師端是否相同未知——目前只評管理端。）

## 建議的照抄優先序

1. **學生管理的「灰掉 + 說出原因」刪除** → 推到分校、科目、課程、請假（風險反比最嚴重）
2. **成績班級視角的「告警＋篩選＋列上標記」三件套** → 推到課程管理、課堂管理、儀表板
3. **「新增學生」同名不同能力** → 讓兩條路徑能力一致（`parentId` 只當預填），或至少改名
4. **金流三頁補「操作紀錄」** → 照抄人員管理的頁層級按鈕
5. 統計 strip 統一 → 學生管理的 hero banner 改成 strip（或反之，但要選一個）
6. 日期範圍欄寬 → 照抄餐費管理
