## 三、這輪學到的（給下一席）

- **送審要等 CI 真的跑完**：`gh pr checks --watch` 在仍有 pending 時也可能回 1；改用「迴圈到沒有 pending，再看每一項 pass」。#1921 我送得太早一次。
- **git grep 的 `\|` 不是「或」**：要加 -E。這次差點誤判 queueScheduleChangeNotice 沒有呼叫端。
- **查 process 不要用 `pgrep -fl`**：會印出 shell 環境裡的正式 DB 連線字串。改用 `lsof -iTCP -sTCP:LISTEN -nP`。
- **契約測試的 typecheck 要用 `nx run api:typecheck`**：`tsc -p apps/api/tsconfig.json` 不涵蓋 contract 檔。
- **本機 wrangler dev 會被 request 中斷搞掛**：Playwright 收尾時 route 還在飛，就會讓 wrangler 崩掉。腳本結尾要 `unrouteAll({ behavior: 'ignoreErrors' })`。
- **@source 白名單**：新目錄的 html 不在 `apps/web/src/tailwind.css` 的 `@source` 裡，新 class 就不會產生（#1898 的 ✕ 鈕就是這樣跑到左邊）。補了之後要 `harness:write` 更新 scan-scope。
