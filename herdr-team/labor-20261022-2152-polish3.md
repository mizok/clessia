## 三、這輪學到的（給下一席）

- **送審要等 CI 真的跑完，而且 api-contract 要真的有跑**：同分支連推會取消前一次；後一次若只改 web，api-contract 會「跳過」9 秒假綠。看 job log 有沒有「—— 跑」，沒有就 `gh workflow run verify.yml --ref <分支>`
- **advisory lock 只保護同一條 pg 連線、同一筆交易**：查重疊和 insert 走 supabase-js（REST，各自一個交易）時，包一層 withTx 取鎖擋不住。要在交易裡用 SQL 做「取鎖 → 查 → 寫」（#1957）
- **家長端 route 拿不到原始連線**（A19、parent-data-scope.md）：要寫入就在 `childDb` 加窄能力，先驗 scope 再用 pool（#1970 `createLeave`）。`createChildDb` 的 pool 由 authMiddleware 傳入，**要有經過真 authMiddleware 的接線測試**，不然漏傳 pool 單元＋契約全綠（審核席 #1976）
- **替身不解析 select／embed 過濾**：範圍條件放進 join 時，單元只能攔 select 字串；真正的隔離靠契約，而且要有一個突變是「拿掉 `!inner`」（#1996、#1982）
- **唯一鍵換排除約束時查 seed 的 ON CONFLICT**：排除約束不能 `ON CONFLICT (cols) DO UPDATE`，`db:reset` 會整批失敗（#838 形狀）。#1989 改成不指定欄位的 `DO NOTHING`
- **新表要加進 `lib/org-scope.ts` 的 `OrgTable`**：harness 會檢查有 `org_id` 的表都列在那裡（#1990 第一顆 commit 紅過）
- **conformance 的 R3 偏離只在 360 生效**：桌機撐到 44 是待修不是偏離。手機 44、桌機照稿的寫法：`min-h-11 wide:min-h-0`（有負 margin 的話 `wide:my-0`）
- **conformance 量家長頁的資料要跟稿同形**：多數「缺」是 seed 沒有那種資料（例：當月未結算的餐、班的預設價目），先查資料再改程式（#2017）
- **8787 的 api CORS 接受任何 localhost**：自己的 web 開別的 port（4201）就能接別席的 api；但那支 api 會被別人關掉，量測前先 `lsof -iTCP:8787 -sTCP:LISTEN`
- **截圖放 `<席位>-assets` 分支**，PR 用 `blob/…?raw=true`；大圖推不上去時縮圖並 `git -c http.postBuffer=524288000 push`
- **zsh 不把 `$P` 拆成多個路徑**：`git diff -- $P` 會靜默回空、看起來像「0 差異」。用 `bash -c`
- **重現 deadlock 要先證明重現器有效**：#2001 先在 main 上撞出 9/20 次 40P01，修後 0/20 才算數；重現失敗留下的 DDL 殘留要自己清（用同樣的鎖序）
