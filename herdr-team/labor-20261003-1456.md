## 一、A6 的 IA 跟現有頁面不同形狀時：先寫範圍說明，把「換外框」跟「換檢視」拆開

做法（#1179／#1174）：

1. 範圍說明（STOP gate）列一張「A6 每一塊 → 現有回應有沒有那份資料」對照表。**有**的照 A6 排、**沒有**的寫成「A6 要什麼 → 缺哪份資料／哪支 API」。
2. 拆兩支：先換外框（色面、灰工具列、清單樣式），IA 換掉另開一張。使用者對「取代還是並存」的裁決要時間，外框那支不用等。
3. **IA 換掉時，先找「誰帶著條件連進來」**（`grep -rn "admin/<頁>" --include=*.ts`）。課表的清單之所以是日期範圍，是因為儀表板（近 7 天未點名）、開課班（整期、未指派）帶範圍連過來 —— 單日甘特接不住，所以有了「篩選結果」檢視（Q1 A）。
   - 順手抓到：開課班帶的 `classId/from/to/assignmentStatus` **之前根本沒有人讀**（`sessions.page.ts` 只認儀表板那組）。**連過去的一方寫了參數，不代表落地頁讀它** —— 兩邊都要 grep。

## 二、甘特版面計算放純函式，模板只畫結果（`sessions/schedule-day.util.ts`）

- `layoutDay(sessions)`：軸＝最早開始的整點到最晚結束的整點；一列一位老師（`teacherId === null` 收最後一列）；
  車道＝依開始時間排、放進第一條「結束 ≤ 我開始」的車道；撞堂＝**同一位老師、都不是停課**、時間重疊（停課照樣佔車道，看得到它在哪）；
  最滿＝每 15 分鐘數同時幾班（不含停課），取第一段最大值的連續區間，**不到 2 班不標**。
- 「上課中」只能用時間判斷：`Session.status` 沒有 `in_progress`（A6 稿自己也這樣寫）。「現在」在每次取數時取一次，不掛計時器。
- 一天／一班整期／一個月未指派都遠小於 500 堂 → 不分頁、`pageSize: 500` 一次拿（後端 `/api/sessions` 的 `pageSize` 沒有上限）。上限寫成 ponytail 註記。
- **測試 fixture 的中文排序**：`'甲'.localeCompare('乙')` 不是你以為的順序（乙在前）。排序測試用 ASCII 名字。

## 三、Angular 模板與 PrimeNG 21 的小坑

- **`[class.x]` 的 x 不能有 `[` `]` `!`**：`[class.border-[1.5px]]`、`[class.!bg-zinc-100]` 都不行。改成互斥的布林條件（每種狀態只開自己那組 class，選取時把底色條件排除）；選取外框用 `ring-2 ring-offset-2`。
- **`p-datepicker` 的 host 就是 root**：在 host 上寫 `md:block` 會蓋掉它自己的 inline-flex，圖示鈕掉到下一行。要顯示用 `md:flex`；`styleClass="w-full"` 也不需要。
- **`<label>` 包兩支輸入時，點標籤會導到第一支** —— 長短版兩支 datepicker（`md:hidden`／`hidden md:flex`）就中了：桌機點「日期」聚焦到隱藏的那支。改 `<div>`＋`aria-labelledby`。
- 頁面的 spec：TestBed 的系統時間是假的（2026-04-15），而且 campuses mock 是空的 → `ngOnInit` 不會觸發載入。**斷言查詢參數要從動作方法進**（`setDay()`、`onStatusesChange()`），不要從 init 斷言。

## 五、疊三層的轉 base 順序（#1179 外框 → #1184 G1）

- 下層 rebase 到 main 之後，上層用 `git rebase --onto <下層新 head> <下層舊 head>` 搬過去，**不要** `rebase origin/main`（會把下層的 commit 再套一次）。
- 整理 WIP 成一筆：**先 rebase 到最新 base，再 `reset --soft <base>`**。直接 `reset --soft origin/main` 而 origin/main 剛前進，index 會把別人剛合的東西一起倒退（2335 charter 一，這一席差點又中 —— `git diff --cached --name-only` 看到 api／parent 的檔就知道了）。
- 多支頁面 PR 都會改 `tailwind.css` 的 `@source`、`scan-scope.json`、`scss-ledger-baseline.json`：衝突永遠在那三處、兩邊都留、`harness:write` 重生成。喚醒比對要重跑（別頁先合，新增的 utility 數會變）。

## 六、小坑

- **herdr 送出前先讀對方輸入框**：計畫席的輸入框裡有使用者打到一半的字，我的回報被接在它後面一起送出了。送之前 `herdr agent read <席> --source recent | tail` 看 `❯` 行是不是空的；不是空的就等，或在訊息開頭說明。
- zsh 的 `git show $r:path` 會把 `:t` 當成修飾字（`$r:tools/…` → `mainools/…`）：寫 `"${r}:path"`。
- 不加引號的 heredoc 會吃掉 `$=`／`$"` 這類字元（Playwright 的 `[aria-label$="…"]` 變成無效 selector）：腳本 heredoc 一律 `<<'EOF'`，要帶變數用 sed 換佔位字。
- worktree 只裝了 root 的 `npm ci` 時，Stop hook 的 harness 會因 `apps/api` 缺 `pg` 紅燈 —— `apps/api` 也要 `npm ci`（README 通用協定寫了，上任提示沒寫）。
