## 一、頂欄分校：`CampusContextService` 的接法（#1138 H2，#1215 課表、#1226 課程）

- 一頁接上＝三件事：建構時 `campusCtx.use()`（頂欄只在**有人 use** 時才出鈕 —— 過渡期不讓頂欄跟頁面說不同的分校）、頁內分校改讀 `campusCtx.id`（`null`＝全部）、拿掉頁內的分校下拉／tabs。
- 換分校的反應用 `toObservable(campusCtx.id)`：初次載入已經有人做（`ngOnInit`）就 `skip(1)`；課表是「第一次發就是初次載入」。
- **換分校時把篩選裡「不屬於新分校的」拿掉，不要全清**：手機篩選對話框可能同一次也選了新分校的課程，全清會把它一起吃掉。
- 頁面的 filter 快照（離開再回來還原）**不要再存分校** —— 它本來就是全站一份。
- 測試：`CampusContextService` 讀 localStorage，spec 的 `beforeEach` 要先 `localStorage.removeItem('clessia.campusContext')`，不然上一條選的分校漏到下一條。換分校後要 `fixture.detectChanges()`，`toObservable` 才會發。

## 二、原生 `<dialog>` 裡放 PrimeNG 下拉：`appendTo` 要給 dialog 元素本身

modal `<dialog>` 在 top layer。`p-select` 預設掛 body → 被 dialog 蓋住、點不到；給 `'self'` → 被 dialog 的捲動區裁掉，**也沒有手機底部選單**。
給 **dialog 元素本身**（`[appendTo]="dialogRef"`）才對：PrimeNG 當成 portal、照樣出手機底部選單、疊在面板上面。`SelectFieldComponent` 有 `appendTo` input（#1210）。
同理：從 modal `<dialog>` 開 PrimeNG `DialogService` 的對話框之前，**先把自己的 dialog 關掉**（課表快速選取面板 `onSheetAct`）。

## 三、觸控 gate（A27）看的是「有 `(click)` 的元素」

- 原生 checkbox 掛 `(click)` 就會被當成 16px 的可點元素紅燈。**把 handler 掛在外層 44px 的 `<label>`**，只處理 `event.target` 是 input 的那一下（點 label 空白處瀏覽器會再對 input 補一次 click，不過濾會勾兩次）。
- 要 Shift 範圍勾就得在 click 上 `preventDefault()`、勾不勾由狀態決定：範圍勾按在已勾的那格，狀態不變、瀏覽器卻先把它取消勾，`[checked]` 沒變 Angular 不會改回來（`schedule-gantt.component.ts` 的 `pickEvent`）。
- 列整列可點（勾選）就給列 `min-h-11`；列裡 checkbox 不掛 `(click)`，在列的 handler 裡忽略 target 是 input 的那一下。

## 四、Tailwind 的兩個 grid 坑

- **`col-start-2 col-span-2` 會失效**：`col-span-*` 產生 `grid-column` 簡寫，排在後面蓋掉 `grid-column-start`，元素掉回自動擺放（課程班級列的日期跑到勾選欄）。寫成 `col-[2/span_2]`。`row-start`＋`row-span` 同理。
- 混用「鎖欄不鎖列」（`col-start-1`）與自動擺放的元素時，鎖欄的那個會先佔走第一列 —— 手機課程列的「分校·科目」跑到名稱上面。兩個都寫死 `row-start-*`。
- `[class.x]` 的 x 不能有 `[` `]`（1456 charter 三）：條件格線改用靜態 `grid-cols-[auto_minmax(0,1fr)_auto]`，讓欄寬跟著內容（不放的那欄就是 0）。

## 五、跨天的勾選（課表 G3）

快速選取勾的是畫面外的課（某老師這週、某班整期），所以**換天不放勾**，批次列寫「畫面上看得到 N 堂」。批次對話框要的資料（有沒有停課、能指派誰）從**勾的當下記下來的那份**補（`known` map），不然停課那堂不在畫面上，「恢復課堂」那顆就消失。

## 六、喚醒比對對「沒動 `@source`」的 PR 也要跑

新元件掛在已經在 `@source` 裡的目錄，一樣會產生新的 utility。比法：`git archive <base> apps/web/src | tar -x -C <快照>`、快照裡 `ln -s <repo>/node_modules`（不然 `tailwindcss/theme.css` 解析不到）、兩邊各 `compile`＋`Scanner` 取 selector 差集。腳本是拋棄式的放 scratchpad；**刪快照目錄的 `rm -rf` 會被安全檢查擋**，每次開新的時間戳目錄就好。
